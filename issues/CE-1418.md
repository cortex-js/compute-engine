The Epsil guide says that a returned value is not checked against the declared return type, but it is.

## Witness

`src/epsil/docs/control-flow.md` line 36: "the current runtime does not
validate the inferred type of every returned value against that annotation".
Epsil CLI, main 3400041f5: `function g(n: integer) -> integer { n / 2 }; g(5)` gives
"Runtime error: expected `integer`, got `rational<2.5..2.5>` at `5 / 2`".

## Cause and options

The text predates the check. Fix: say what is checked (a returned value that
is not of the declared type is a runtime error) and when, with this example;
the cortexjs.io site copies this page.
