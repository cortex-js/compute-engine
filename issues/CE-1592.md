A Tycho user cannot write a Chebyshev, Legendre, Hermite or Laguerre polynomial by name.

## Request

Library operators, with LaTeX and Epsil names, that evaluate for an integer
degree (symbolically to the polynomial, numerically for a number) and compile
to JavaScript and GLSL:

```
ChebyshevT(n, x)   ChebyshevU(n, x)   LegendreP(n, x)
HermiteH(n, x)     LaguerreL(n, x)
```

`HermiteH` is the physicists' polynomial. The three-term recurrences give the
numeric value and the compiled loop.

## Witness

On 0.194.3 `ce.lookupDefinition()` returns nothing for each of the five
names, and `ChebyshevT(3, 0.5)` stays unevaluated (expected −1). Control:
`Hypergeometric2F1(1, 1, 2, 0.5)` evaluates to 2 ln 2 and compiles to
JavaScript with the same value. The user's workaround is to write the
polynomial or the recurrence out. Size M.

## Fix

`ChebyshevT`, `ChebyshevU`, `LegendreP`, `HermiteH` (physicists') and
`LaguerreL` are library operators (Epsil `chebyshevT`, …; LaTeX
`\operatorname{ChebyshevT}(n, x)`). With a literal integer degree, a symbolic
x gives the polynomial (`ChebyshevT(3, x)` → `4x^3 - 3x`), an exact rational x
an exact value (`ChebyshevT(3, 1/2)` → `-1`), a float x or `N()` the
recurrence value (`ChebyshevT(3, 0.5)` → `-1`). A negative degree of a
Chebyshev or Legendre polynomial maps to a nonnegative one; of `HermiteH` or
`LaguerreL` the call stays unevaluated. All five compile to JavaScript and
GLSL for an integer degree and a real x (NaN where the interpreter stays
unevaluated). To verify: the five names have a definition, and
`ChebyshevT(3, 0.5)` evaluates to -1 in the interpreter and in compiled code.
