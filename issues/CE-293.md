A product with a reciprocal, written as LaTeX and read back, has the same value but a different form.

## Witness

`Multiply(3, x, Power(y, -1))` is written `\frac{3x}{y}`, which parses back as
`Divide(Multiply(3, x), y)` (checked 2026-11-06).

## Cause and options

Same cause as CE-113: the canonical forms of `Divide` and `Multiply` differ for
this shape. Other cases with the same cause:

- CE-293.2: the `reciprocal` and `factor` fraction styles write `a/b` as
  `a\times b^{-1}` and `\frac{1}{b}a`; the round trip gives
  `Multiply(a, Divide(1, b))`, not `Divide(a, b)`.
- CE-293.3: every fraction style writes `c\frac{a}{b}` (canonical
  `Multiply(c, Divide(a, b))`) as `\frac{ac}{b}`, which reads back as
  `Divide(Multiply(a, c), b)`.
