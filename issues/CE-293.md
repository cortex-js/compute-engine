A product with a reciprocal, written as LaTeX and read back, has the same value but a different form.

## Witness

`Multiply(3, x, Power(y, -1))` is written `\frac{3x}{y}`, which reads back as
`Divide(Multiply(3, x), y)`; `isSame` is `false` (checked 2026-11-07). The
`reciprocal` and `factor` fraction styles have the same loss for `Divide(a, b)`.

## Options

Cause: the engine has two canonical forms for one quotient (CE-113). The
decision of 2026-08-04 accepts this loss (`docs/mathnet/README.md`). Details:
`docs/plans/2026-11-07-ce-293-reciprocal-round-trip.md`.

- (a) Close under that decision. No change; compare after `simplify()`.
  Recommended.
- (b) Do CE-113, one canonical form. Size L; four tasks first.
- (c) Write `3x\frac{1}{y}`. Worse LaTeX for every such product.

If nothing is decided, the behavior does not change, as with (a).
