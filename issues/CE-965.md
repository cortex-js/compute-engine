Under `.N()`, a user function that returns early with `Return(Floor(x))` uses the rounded argument and gives the wrong integer.

## Witness

```
f := x ↦ Block(If(x > 1, Return(Floor(x))), 0);  f((25! − 1)/24!).N()
  gives 25, should be 24
```

## Cause and options

Only the last statement of a body gets the numeric request (user decision
2026-10-18), and the `Return` is in an earlier statement. The design: an
evaluation option that only `Return` honors, carried by `If`, `Which`, `Block`
and `Loop` and removed by every inner function application, so that values in
the middle stay exact. Same family as CE-179.

## Decision

User decision 2026-11-08: The `.N()` should be applied to the value of the result of the function, not to its last statement
