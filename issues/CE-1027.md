The list of unknowns of a set-builder such as {2k | k ∈ ℤ, k > 1} includes the set of integers, which is a library constant.

## Witness

```
ce.parse('\\{2k \\mid k \\in \\Z, k > 1\\}').unknowns   ->  ["Integers", "k"]   (expected []: the fix of CE-537 binds k, and gives ["Integers"])
ce.box(['Add', 'Integers', 1], { form: 'raw' }).unknowns  ->  ["Integers"]   (expected [])
ce.box(['Add', 'Pi', 'k'], { form: 'raw' }).unknowns      ->  ["k"]          (correct)
```

## Cause and options

In the `'unknowns'` mode of `collectReferences()`
(`boxed-expression/abstract-boxed-expression.ts`), a symbol that is not bound
(a raw node, or an operand of `Condition`, which holds its operands) is looked
up by name. The lookup finds the constant definition of `Integers`, which has
no value, so the walk reports the name as free. A bound occurrence is left out
by the `isConstant` test before the lookup, and the `'references'` mode already
tests `looked.value.isConstant`. Fix: leave out a looked-up definition that is
a constant, as in the `'references'` mode. Size S.
