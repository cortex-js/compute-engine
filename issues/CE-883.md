Computing each point of a list from a formula costs 30 to 190 µs, because a new expression is built for each point.

## Witness

Per element, on the body of Tycho document `s8ishknvhe` (2026-09-18):

```
Abs(PointX(L))                                    30–40 µs
PointX(L) + PointY(L)                             60–80 µs
Conjugate(PointZ(L) / (PointX(L) + i PointY(L)))  140–190 µs
```

## Cause and options

Each element of each broadcast operator is computed by boxing a new canonical
function (`mapAtCell` and the drain iterator in `library/collections.ts`,
through `computeBroadcastCell`): operator lookup, type handler, operand
descriptor, allocation. The entry proposes no fix.
