The LaTeX of a derivative of negative order reads back as a reciprocal.

## Witness

On main:

```
ce.box(['Derivative', 'f', -1]).latex          // f^{(-1)}
ce.parse('f^{(-1)}').json                      // ["Divide", 1, "f"]
```

## Cause and options

A negative order has no meaning for `Derivative`; it could be refused at boxing, or written `\operatorname{Derivative}(f, -1)`. Size S.
