The square of a list of points, such as the squared coordinates of every point of a plot, does not compile.

## Witness

`q: list<tuple<real, real>>`; `compile(Power(q, 2), { to: 'javascript' })`
declines ("Power of a matrix"). The interpreter squares each coordinate of
each point (element by element), as it does for `Power(L, 2)` with
`L: list<real>`, which compiles.

## Cause and options

The IR reads a rank-2 operand of `Power` as a matrix (`MatrixPower`); a
list of tuples is a list of points, which `Power` threads over. The lowering
of `Power` should settle the two from the static type: a list whose elements
are tuples threads.
