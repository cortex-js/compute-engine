Transposing a matrix along an axis whose value is still unknown produces empty rows.

## Witness

```ts
const ce = new ComputeEngine();
ce.declare('axis', 'integer');
const expr = ce.expr(['Transpose', ['List', ['List', 1, 2, 3], ['List', 4, 5, 6]], 'axis', 2]);
expr.evaluate().json; // ['List', ['List'], ['List']] and a console assertion
```

The expression should stay unevaluated until the axis has a value. After
assigning `axis = 1`, the same expression gives `[[1, 4], [2, 5], [3, 6]]`.

## Cause and options

The runtime axis check only compares bounds, which allows `NaN` from the
unbound symbol to pass. Validate both evaluated axes as integers before
swapping. Check `ConjugateTranspose` as well. CE-1848 records the console
assertion for an axis of `0`, where evaluation already stays symbolic.
