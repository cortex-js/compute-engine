Compiled JavaScript of `Map` of the shorthand `Norm(_)` over the rows of a matrix applies `Norm` to each number, and returns the matrix, where the interpreter gives the norm of each row.

## Witness

At `edf0c42631a479230ffbb04bcd33d745725ceeed`, default options of `compile()`:

```js
const ce = new ComputeEngine();
ce.declare('M', 'matrix<2x2>');
const f = compile(ce.box(['Map', ['Norm', '_'], 'M']));
f.run({ M: [[1, 2], [3, 4]] }); // ➔ [[1, 2], [3, 4]]
```

The interpreter gives `[√5, 5]` for `Map(Norm(_), [[1, 2], [3, 4]])`.

| Program | Canonical form | Engine type of the function operand | Compiled code | Compiled value |
| --- | --- | --- | --- | --- |
| `Map(Norm(_), M)` | `Map(Function(Block(Norm(_1)), _1), M)` | `(unknown) -> nan \| real \| signed_infinity` | `((_f) => (_.M).map((_x) => _f(_x)))(((_tv2) => (_tv1) => _SYS.mapFn(_tv2, [1], _tv1))(((_1) => _SYS.norm(_1))))` | `[[1, 2], [3, 4]]` (wrong) |
| `Map(Function(Block(Norm(r0)), r0), M)`, the same canonical JSON boxed directly | the same | `(r0: vector<2>) -> nan \| real \| signed_infinity` | `((_f) => (_.M).map((_x) => _f(_x)))(((r0) => _SYS.norm(r0)))` | `[2.23606797749979, 5]` (right) |
| `Map(Abs(_), M)` | `Map(Function(Block(Abs(_1)), _1), M)` | `(unknown) -> real<0..> \| signed_infinity` | the `_SYS.mapFn(_tv2, [1], _tv1)` variant | `[[1, 2], [3, 4]]`, which is the interpreter's value: `Abs` applies to each element |
| `Map(Norm(_), L)` with `L: list<real>` | | `(unknown) -> …` | `((_1) => _SYS.norm(_1))` per element | `[3, 4]` for `L = [3, -4]`, right |

The `numeric-kernel` profile gives `[√5, 5]` for the first program (it reads the rows from the type of `M`).

## Cause

The shorthand function operand canonicalizes to a function literal whose parameter has the type `unknown`; boxing the same canonical JSON directly infers the parameter type `vector<2>` from the matrix. In `compile-function-literals.ts`, the choice of `ranks` (the condition `paramsAreScalar(literal.type.type) && signatureParamsLowerToScalars(literal.type.type)`, near `callbackArgumentRanks()`) reads the `unknown` parameter as a scalar, so the consumer's list argument of rank 1 maps the literal over each number of a row (`_SYS.mapFn(_tv2, [1], _tv1)`). For a function that reads a whole list (`Norm`, and any other head that takes a list), this gives a value of another shape.

## Options

- Give the parameter of the shorthand literal the element type of the list at canonicalization, as the direct boxing does (`vector<2>` for the rows of `M`); the compiler then binds the row whole, as in the second row of the table. Not checked: what this does to `Abs(_)`, whose arrow `Math.abs(row)` would need the element-wise form of the body.
- Or decline, in the compiler, a literal of a parameter typed `unknown` whose consumer passes it list values of rank 1 or more and whose body applies a head that reads a whole list.
