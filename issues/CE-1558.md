Applying a function to each group of a list split by a condition gives no answer, while the same works for a list cut into chunks.

## Witness

On main c9b5d60ae, with `F = Function(Length(r), r)`,
`P = Partition([1, 2, 3, 4], t ↦ t < 3)`, `C = Chunk([1, 2, 3, 4, 5], 2)`:

| expression | value |
| --- | --- |
| `At(P, 1)` | `[1, 2]` |
| `At(Map(F, C), 1)` | `3` |
| `Count(Map(F, C))` | `2` |
| `At(Map(F, P), 1)` | unevaluated |
| `Count(Map(F, P))` | unevaluated |

Expected: `At(Map(F, P), 1)` is `2` and `Count(Map(F, P))` is `2`.

## Cause and options

Not investigated. `Partition` with a predicate gives its groups (`At(P, 1)`
works), but `Map` over it stays unevaluated, so `Map` probably does not read
the predicate form as a collection (its iterator, or its type
`list<list<integer>>` against `Map`'s collection parameter). The compiled
code of CE-1549 declines `Map` over the groups of `Partition(L, p)` because
of this, so fixing it lets that case compile too.
