A notebook code cell whose result is a pair of lists shows Tuple(…) instead of the parenthesized pair.

## Witness

On 0.194.3 the LaTeX of `Tuple(List(1, 2), List(3, 4))` is
`\operatorname{Tuple}(\bigl\lbrack1, 2\bigr\rbrack,\bigl\lbrack3, 4\bigr\rbrack)`
and that of `Tuple(1, List(2, 3))` is `\operatorname{Tuple}(1,…)`. The Epsil
program `(continuedFraction(pi, 8), continuedFraction(sqrt(2), 8))` gives a
`value.latex` that starts with `\operatorname{Tuple}(`. Control: `Tuple(1, 2, 3)`
serializes as `(1,2,3)` and parses back to the same tuple. Both forms parse
back to the same MathJSON, so only the display is wrong.

## Cause and options

From the readings, the tuple serializer uses the parenthesized form only
when every element is a scalar. Option: use `(…)` for any element. The parser already reads
`([1, 2], [3, 4])` back as the tuple. Size S.
