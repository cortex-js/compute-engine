The examples of the library functions are written with the MathJSON names (`Join([1, 2], [3, 4])`), not as an Epsil user types them (`join([1, 2], [3, 4])`), and an editor cannot get them to show.

## Witness

On CE 0.201.5, 401 library definitions have 516 examples. A round trip
through `parseEpsil` and `serializeEpsil(…, { libraryNames: "epsil" })`
changes 515 of them and fails on none:

```
{ definitions: 401, examples: 516, changed: 515, failed: 0 }
About(Pi)  =>  about(pi)
[Abs(-3), Abs(3 - 4i)]  =>  [abs(-3), abs(3 - 4i)]
Join([1, 2], [3, 4])  =>  join([1, 2], [3, 4])
N(AiryAi(1))  =>  N(airyAi(1))
```

The examples parse as Epsil (the MathJSON names resolve), so this is a
matter of spelling. Neither the completion items, the signature help nor
`epsilHover` return them.

## Request

1. Rewrite the `examples` of the definitions in the Epsil spelling, with the
   round trip above as the script, and a test that each example is already
   what the round trip gives and evaluates without an error.
2. Return them: `examples?: string[]` on a library completion item, on
   `EpsilHover`, and on `EpsilSignatureHelp` (the callee's). Tycho shows them
   under the description, after "More".

## Cause and options

If the MathJSON spelling must stay in the definitions (for the MathJSON
documentation), option 2 can serialize them with `libraryNames: "epsil"`
when it returns them, and option 1 is then only the test that each one
parses.

## CE answer

CE (2026-11-25): done by option 2, at the user's request. The definitions
keep the MathJSON names; the editor functions return each example in the
Epsil spelling with the rewrite of the reference pages (`epsilSpelling`, now
`src/epsil/example-spelling.ts`), which changes only the free library names
and keeps the layout. A test checks that every converted example parses. The
inline "Example:" sentences of about twenty descriptions are CE-1835.
A name stays in the MathJSON spelling when its Epsil spelling would read
another binding: of the engine (`let pi = 3` run earlier), or of the source
of the editor at the offset (`let pi = 3` above `sin(`, a parameter `pi`):
`sin` then shows `sin(Pi / 6)`. The MathJSON names in the code spans of the
descriptions are CE-1836.
