After a sum is evaluated once, `simplify()` of the same sum can give a different result.

## Witness

```
nest = Sum(Sum(sin(k+j+1) − sin(k+j), Limits(k, 1, n)), Limits(j, 1, 3))
nest.simplify()   before nest.evaluate(): sum_(j=1)^(3)(-sin(j + 1) + sin(j + n + 1))
nest.simplify()   after  nest.evaluate(): the inner sum stays
nest.localScope.bindings.get('j').value   after evaluate(): 3
```

A single `Sum(j, Limits(j, 1, 3))` also keeps `j = 3` after `evaluate()`.

## Cause and options

The numeric iteration of a `Sum` or `Product` assigns each value of the index
in the scope of the operator and does not remove the last value when it
stops. Then a reader of that scope sees the index as an assigned variable:
`bigOpClosedForm()` (`library/utils.ts`) declines the inner sum. Fix: remove or
restore the value of the index binding at the end of the iteration.
