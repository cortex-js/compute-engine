The curve of the derivative `f'(x)` of a deeply nested function is missing from the document, and the document waits about 0.8 s before it gives up on it.

## Witness

`neyret/7kn7eakzkd` defines `f(x) = √(x + √(x + … √x))`, 37 square roots
deep, and plots `f'(x)` (records #7160 javascript, #7161 interval-js). Its
rows `\sum_{i=0}^3 \frac{(x-ε)^i}{i!} F(ε)[i+1]` with
`F(x) = [f(x), f'(x), f''(x), f'''(x)]` decline with the same message
(#7162, #7163). Probability `medium`: a shipped document, but a nest this deep
is unusual.

```ts
let e = ['Sqrt', 'x'];
for (let i = 1; i < 37; i++) e = ['Sqrt', ['Add', 'x', e]];
ce.declare('f', { type: '(x: unknown) -> number', inferred: false });
ce.assign('f', ce.box(['Function', ['Block', e], 'x']));
compile(ce.box(['Apply', ['Derivative', 'f', 1], 'x']),
  { to: 'javascript', mode: 'strict', inputs: { x: 'real' } });
```

Today: `Could not compile: Derivative(f, 1): a derivative with no closed form
of at most 10000 nodes in radians at compile time`, on both targets.
Expected on javascript: compiled code, as `D(f(x), x)` gives (a numeric
stencil, `_SYS.nd`).

Median of 5 fresh processes per arm, interleaved, npm CE 0.204.3, Node
26.13.0, Apple M5 Max 18 cores, load 4.6 → 4.9:

| arm | compile ms | result |
| --- | ---: | --- |
| `f'(x)` javascript | 770 | decline |
| `f'(x)` interval-js | 754 | decline |
| `D(f(x), x)` javascript | 900 | compiles to `_SYS.nd` |
| `f(x)` javascript | 21 | compiles |

`ce.box(['Derivative', 'f', 1]).evaluate()` alone: about 760 ms, and it
returns `Derivative(f, 1)` unchanged. At depth 10 it takes 73 ms
(1,144 nodes), at depth 20 282 ms (8,484 nodes), one process each, load 9 to
13.

## Where the 879 ms of the audit go

The Tycho resolve of the row (`7160-resolve-split.mts` in the Tycho audit
directory `_TASK/desmos/desmos-corpus/codegen-audit/repros-0.204.3/`), CE
calls timed at their outermost level, 5 fresh processes, load 4.3 to 4.6:
the first `evaluate()` of `Derivative(f, 1)`, made by Tycho before it
compiles, takes 750 to 880 ms (99 % of the resolve); a second `evaluate()`
0.2 ms; parse and box below 1 ms; `compile` 2.5 ms (javascript) and 0.7 ms
(interval-js), which find the memoized result. At load 32 the evaluation
passes Tycho's 1 s span and is cut, and the javascript compile then repeats
the whole search (2.3 s).

## Cause

A CPU profile on the CE source tree (main at
`9823c383a3ee90346a2595bbe6be16b16a80f0eb`): 2.57 s in `differentiate`, of
which 1.83 s in `expandProducts`, called from the `mul` of the product and
chain rules. This is the mechanism of CE-1287 (a nested quotient). The
result is then over the size limit, so the search gives nothing.

`lower.ts`, case `Apply` of a `Derivative`: with no closed form it declines
(`if (f === g || f === undefined) decline(g, NO_CLOSED_FORM)`), while the
case `D` falls back to `_SYS.nd` on javascript when the body is pure.

## Options

- (a) On javascript, compile `Apply(Derivative(f, k), x)` with no closed form
  as `D(f(x), x)` is compiled: the numeric stencil, order 1 (and the jet
  derivative where `prefersJetDerivative()` already applies). The row is
  drawn. The interval target keeps the decline. Size S to M.
- (b) Make the failing search cheap: estimate the size before
  `expandProducts`, or do not expand products while differentiating
  (CE-1287 options a and b). Size S to M.

Both are needed for the document: (a) draws the row, (b) removes the 0.8 s.

Ready (the instrument): `f'(x)` compiles on javascript, in at most 5 times
the compile time of `f(x)`.

## CE answer

CE (2026-11-28): P3 confirmed. Option (a) is fixed in the working tree of
compute-engine-94, not yet committed: on JavaScript, `Apply(Derivative(f, 1), x)`
with no closed form is the numeric derivative of the call `f(t)` at `x`
(`_SYS.nd`), as `D(f(x), x)` is, and gives the interpreter's numeric value
(0.577350266059878 at 0.5 for the witness); other orders, GLSL and interval-js
still decline. Option (b), the cost of the failing search, is CE-1287 and stays
open, so the instrument's compile-time criterion is not met yet: the issue stays
open for it.
