A document that plots a formula reading a long list of numbers opens slowly: each plotted row with a list of 10,000 numbers takes about 50 ms to prepare, per target.

## Witness

`neyret/1a9de333a1` holds a list `T` of 9,801 numbers (a 99 × 99 grid) and
plots `T[⌊99x⌋ + 99⌊99y⌋] < 3..9`. The compiled input is
`Add(At(List(<9,801 numbers>), Floor(99x) + 99·Floor(99y)), -3)` (records
#3356 javascript, #3357 interval-js, #3358 glsl). The audit measured 41 to
62 ms per compile on each target.

Control: the same formula with a list of 981 numbers. Median of 5 fresh
processes per arm, interleaved, npm CE 0.204.3, Node 26.13.0, Apple M5 Max
18 cores, load 4.6 → 4.9:

| target | 9,801 elements | 981 elements | per element |
| --- | ---: | ---: | ---: |
| javascript | 74 ms | 25 ms | 5.5 µs |
| glsl | 68 ms | 21 ms | 5.3 µs |

The emitted javascript `code` is 74 characters for both sizes: the list is
not in the code, and the time grows with the list before the emission.

## Cause

A CPU profile of the javascript compile on the CE source tree (main at
`9823c383a3ee90346a2595bbe6be16b16a80f0eb`, load about 25: read the shares)
spreads the 230 ms of the compile over the IR pipeline: a canonical box
inside the compile (`boxFunction` → `makeNumericFunction`, about 100 ms),
`lower` (about 95 ms) and `runPasses` (about 80 ms); the parts overlap. No
single hot function.

## Options

- (a) Read a `List` whose elements are all number literals as one packed
  constant (a `Float64Array`) at the start of the compile: no box, no
  lowering and no pass per element. Size M.
- (b) Remove the canonical re-box of a literal list inside `compile()` when
  the input is already canonical. Size S to M.

Ready (the instrument): at most 1 µs per list element on javascript and on
glsl (slope between 981 and 9,801 elements).

## CE answer

CE (2026-11-28): P3 confirmed; pool. CE will measure option (b) first (the
canonical re-box of an input that is already canonical), since it helps every
compile and needs no new path; (a) only if (b) leaves more than the criterion.
No workaround.
