In an imported Desmos document, curves defined piecewise over a list of values still do not draw when the piecewise definition is a function.

## Witness

```ts
const ce = new ComputeEngine();
ce.declare('x', 'real');
ce.declare('C', 'function');
ce.assign('C', ce.box(['Function',
  ['If', ['LessEqual', 0, 'w', 6], ['Add', 'w', ['List', 0, 4, 2]]], 'w']));
compile(ce.box(['At', ['C', 'x'], 1]),
  { to: 'javascript', mode: 'strict', inputs: { x: 'real' } });
```

0.196.0: declines on `javascript` and on `interval-js`
(`{to: 'interval-js', symbolic: ['x']}`), "If(LessEqual(0, w, 6), Add(w,
List(0, 4, 2))): an If with no else of a list arm whose value is read by other
than At, First, Last, an arithmetic operator or a reduction". Control: the
same `C` with the explicit else `List(NaN, NaN, NaN)` compiles on both targets
and gives 1.5 at x = 1.5. The CE-1606 witness, `At` of the `If` written inline,
compiles on 0.196.0 (1.5). 0.192.0 compiled the document form (CE-1606).

So the CE-1606 fix admits the `If` when `At` reads it directly, but not when the
`If` is the body of a user function and `At` reads the call `C(x)`: the reader
that the rule sees is the function call.

Document form (as in CE-1606): `C(x) = If(0 ≤ x ≤ 6, s(ElementMin(1,
ElementMax(0, |Mod(x + [0, 4, 2], 6) − 3| − 1))))`, and the line readers
`M(x) = Max(C(x)[1], C(x)[2], C(x)[3])`, `m(x) = Min(…)`, `V = M` and
`S = (M − m)/V`. 0.196.0 declines all four on `javascript` and `interval-js`
with the message above. Capture: Tycho `.cache/mg-ce196/codegen-full.json`.

Tycho impact: `neyret/ni3ih739at` still draws without its two dotted horizontal
lines and their points (Tycho `roadmap/MACRO_CARRIERS_PHASE_A.md`, rerun on CE
0.196.0). No workaround in Tycho: the function and the `If` with no else are the
imported Desmos definitions.

## Cause and options

The reader test of the CE-1606 decision looks at the parent of the `If`. When
the `If` is a function body, the parent is the function, and the readers are
the call sites. Option (a, recommended): apply the CE-1606 rule to the call
sites after inlining (or after the call is lowered), so `At(C(x), 1)` is judged
as `At(If(…), 1)`. The decline for `Length`, `Rest` and the discharges stays.
Option (b): when the call result is read only by `At`, `First`, `Last`,
arithmetic or a reduction, treat the call like a direct read.
