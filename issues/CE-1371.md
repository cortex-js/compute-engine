In a Desmos document, a list filtered by a condition over a shorter list (`L[K=1]`) needs a Tycho handler on `At`, because CE gives an error.

## Witness

With `L = [1,2,3,4,5]` and `K = [1,0,1]`, `At(L, Equal(K, 1))` is an error in
the interpreter ("The mask (length 3) must have the same length as the
collection (length 5)"), `null` with the existing compiler, and a decline
with the profile `ir`. Desmos gives `[1,3]` (official API; Tycho
`src/graph-paper/graph/at-index-semantics.ts` header). A position where the
condition is undefined keeps nothing. No ground truth exists for a mask
longer than its list.

## Request

Read a boolean mask by position up to the shorter of the mask and the
collection, keeping the positions where the mask is `True`; a `Missing` or
`NaN` member keeps nothing. The same in the interpreter and in compiled code
(JavaScript and interval; GLSL has no lists of run-time length). A base that
is a list of points keeps its points.

## Workaround

Tycho's `At` handler today; with CE-1370, a filter form that a Tycho handler
returns as an Expression.

## Tycho half on adoption

Run the instrument; remove the mask branch of the `At` handlers (row MK).

- **The rule as it landed**, in the interpreter, the existing JavaScript
  compiler and the profile `ir`: `At(L, M)` with `M` a boolean mask keeps
  `L[k]` for the positions `k` up to the shorter of the two lengths where
  `M[k]` is `True`. A member that is `Missing` or `NaN` keeps nothing. An
  index with a member that is neither a boolean nor one of those is not a
  mask: it is a list of indexes, as before. A mask longer than its list is
  read as far as the list goes (no Desmos ground truth for that case: the
  user's decision).
- **In the profile** a mask (of any length) is a filter over the shorter
  length on JavaScript and the interval target; GLSL declines (no list of a
  run-time length). `Equal` and `NotEqual` of a list and a scalar thread, and
  `And`, `Or`, `Not` of lists of booleans thread, so `L[K=1]` compiles as
  written. A mask or a base of a mask with an effect (a draw) declines. An
  index whose static type proves neither a list of booleans nor a list of
  numbers declines: no run-time test of a shape.
