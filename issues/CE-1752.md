In Epsil, an error in the body of a function that an element of a list calls still underlines another element when the list is an operand of a call other than arithmetic with numbers, when it is assigned to an element of a nested collection, or when two calls in the list can give a sequence.

## Witness

```
function g(x) { Ln(x) + 1 }
function k() { Sequence(1, 2) }
let y = 5
let u = [1, 2]
let m = [[1, 2], [3, 4]]

let v = [y + 1, g("a")] + u        underline -> y
let v = [y + 1, g("a")] + [1, 2]   underline -> y
let v = [y + 1, g("a")]^2          underline -> y
let v = Sqrt([y + 1, g("a")])      underline -> y
m[1][2] = [y + 1, g("a")]          underline -> y
let v = [k(), y + 1, g("a")]       underline -> y
expected: g("a") or the statement
```

## Cause and options

The fix of CE-1719 (`heldElement()`, `src/epsil/execute-epsil.ts`) finds the
written element of a list whose value holds the error in four forms: a list,
`m[k] = x` with one index, and `Add`, `Subtract`, `Negate`, `Multiply` or
`Divide` of one list literal and numbers. In each of these forms, the
position of the element in the value is proved: by the count of values of
each element (a variable by its value, a call by its static type), or by the
element-wise rule. In the forms of the witness, nothing proves the position,
so the old location runs: the frames of the body of `g` are matched to the
calls of the whole statement, and `Add argument 1` selects `y`.

- (a) Read more forms: two list operands of the same length, `Power` and the
  elementary functions over a list that is not a square matrix, and the path
  of `ReplaceAt` with more than one position. Each form needs a proof that the
  element `i` of the value is made from the element `i` of the literal.
- (b) When the value of the statement is a collection that holds the error,
  the written value holds a list literal, and the element is not found,
  underline the statement in place of the old location. This also drops a
  correct location inside an element (`[1, y + Ln(w)] + u` underlines `w`
  now), so it trades a correct location for one that is never wrong.
- (c) Option (a) of CE-1137: the call of a user function adds a frame to an
  error that its body returns. This fixes every form, and changes the
  `ErrorTrace` and the message of every such error.
