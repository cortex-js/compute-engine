A binomial coefficient with a fraction on top is not computed exactly, while the rising factorial that defines it is.

## Witness

```
Binomial(1/2, 2)      // stays unevaluated
N(Binomial(1/2, 2))   // -0.125
Pochhammer(1/2, 3)    // 15/8
```

Measured at 074e6347f39717e4f6d5b44521c5c459b6d9d2b7.

## Cause and options

The exact path of `Binomial` and `Choose` (`library/combinatorics.ts`) takes an integer `n` only. For a rational `n` and a non-negative integer `k`, give `Pochhammer(n - k + 1, k) / k!` (here `-1/8`).
