A declaration that refuses absent values refuses `Undefined` only when the program runs, never in the static check.

## Witness

`let n: integer = Undefined` gets no static report; the run time refuses the
value.

## Cause and options

`Undefined` has no type of its own: it is typed `unknown`. So a strict
declaration refuses it only by its value (`matchesDeclaredTypeAxes`,
`effects-inference.ts`, §9 slice S4 of
`docs/plans/2026-10-21-presence-contracts-and-assertion.md`). Fix: give
`Undefined` a type that a declaration can refuse statically.
