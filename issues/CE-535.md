Opening a large Tycho document spends about 720 ms preparing its formulas, most of it finding the result type of the same function again and again.

## Witness

```
npx tsx benchmarks/tycho-document-open/rebind.ts     # COLD=1 RUNS=1 for the first run only
```

Document `art/2ki2hjsouf`: 1 994 `ce.rebind` calls, about 720 ms. A 425-byte
tree `R_3(At(PointList(… D(PointY(S_orry(u)), u) …)))` takes 14 to 20 ms, 85 %
of it typing `S_orry(u)`.

## Cause and options

`callResultTypeOfBinding` and `literalBodyResultType`
(`boxed-expression/call-result-type.ts`) walk the 8.7 KB body. Their memo is
keyed on `_cacheGeneration()`, and each `D` declares its variable in a new
scope (`canonicalizeBinder`, `box.ts`), which advances the `any` axis (same
cause as CE-531). Exempting a fresh binder scope (848 → 664 ms) is unsound: a
cached sign is wrong after the pop (`ce-535-531-binder-declaration-cache.test.ts`).
The design needs caches keyed on the bindings they read, or a binder variable
that lookups see as bound before the `canonical` handler runs.
