`simplify()` of a system of linear equations returns the simplified equations, not the solution of the system.

## Witness

```
simplify(\begin{cases}x+y=70\\2x-4y=80\end{cases})
  gives [x + y = 70, x − 2y = 40]
solve([x, y]) of the same system gives {x: 60, y: 10}
```

## Cause and options

`simplifySystemOfEquations()` (`symbolic/simplify-rules.ts`) simplifies each
equation and has a `@todo` that names GitHub #189 (a closed feature request).
Option: return the solution when `solve()` finds a unique one. Workaround:
call `solve()`.

`needs-review`: the old entry called this a defect, but it is a request for a
capability with a workaround. The board can close it, or move it back to
`ROADMAP.md` as a capability.
