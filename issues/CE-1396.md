`Repeat(Random(), 3)` is three copies of one random number, but its sum, or the list plus 1, uses three different random numbers.

## Witness

```ts
const ce = new ComputeEngine();
ce.declare('L', 'list<real>');
ce.assign('L', ce.box(['List', 1, 2, 3]));
const v = (json) => ce.box(['WithRandomSeed', 3, json]).evaluate().N().json;
v(['Repeat', ['Random'], 3]); // [0.4706…, 0.4706…, 0.4706…]: one draw
v(['Max', ['Repeat', ['Random'], 3]]); // 0.4706…: one draw
v(['Add', ['Repeat', ['Random'], 3], ['List', 1, 2, 3]]); // [1.4706…, 2.4706…, 3.4706…]: one draw
v(['Add', ['Repeat', ['Random'], 3], 'L']); // [1.4706…, 2.3638…, 3.7936…]: three draws
v(['Add', ['Repeat', ['Random'], 3], 1]); // [1.4706…, 1.3638…, 1.7936…]: three draws
v(['Sum', ['Repeat', ['Random'], 3]]); // 1.6280…: three draws
```

Run with `npx tsx` on `c17ba79f97bfb25d9c40f8673301dced3522739c`. The same
holds for a value that writes a local: with `c` starting at 1,
`Sum(Repeat(Block(Assign(c, c + 1), c), 3))` is 9 and leaves `c` at 4, where
the list evaluated first would give 6 and leave `c` at 2. `Product` and an
element-wise function (`Sin`) read the list as `Sum` does. The same list is
read in two ways depending on the operator around it and, for `Add`, on
whether the other operand is a literal list or a name that holds one.

## Cause and options

Not read in detail. `Repeat` evaluated by itself evaluates its value and
copies it. A consumer that iterates its operand lazily (`Sum`, `Product`, the
broadcast of `Add` and `Multiply` with a scalar or a named list, an
element-wise function) asks the unevaluated `Repeat` for each element, and
each element evaluates the value again.

- (a) The value is evaluated once in every case: the lazy read of a `Repeat`
  evaluates the value at the first element and keeps it. It matches what
  `Repeat(Random(), 3).evaluate()` shows the user and the description ("a
  single value"). Recommended. Size S.
- (b) The value is evaluated once per element in every case: `Repeat` by
  itself would then give three draws. It changes the standalone result.

Compiled code: the profile `ir` declines a `Repeat` whose value has an effect
(batch G31), so it gives no value either way; the existing JavaScript
compiler gives one draw for some of these forms and three for others.
