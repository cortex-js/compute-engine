A document with a definite integral of a user function opens up to half a second slower per plotted row and per target, because each compile of the row searches for an antiderivative that it does not find.

## Witness

Three Tycho corpus documents. Each row compiles once per target (javascript
and interval-js). In the codegen audit both targets of jejjp1xikd paid the
cost in one process (414 ms and 393 ms). The instrument declares the row's
functions as Tycho does and compiles the captured input with Tycho's
options.

- `neyret/jejjp1xikd`: `\frac{s(x)}{\int_{-1}^{1} s(x)\,dx}` with
  `s(x) = (½cos(3.14(x−t)) + ½)·K(x)` and
  `K(x) = If(|x| ≤ 1, ½cos(3.14x) + ½)`.
- `neyret/pmciiapek6`: `\int_0^{10} I_2(−l + t − √(l²+x²)) I_1(t)\,dt`, where
  `I_k(t) = S(t, …)` is a `Sum` to `N` of `sin(t/h(i+s) + 2π h(i+s+½))` and
  `h(x) = 10000 sin(10000x) mod 1`.
- `neyret/trqrlcgu3h`: `m_2(x)` with `m_2(a) = \int_0^1 x² f(x, a)\,dx` and
  `f` a product of `ElementMax` and `ElementMin` (the `s(x)` row of the same
  document reads `m_1` and `m_2`; in the audit it compiled in 91 ms, `m_2(x)`
  in 85 ms).

Control: the same integrand written as `NIntegrate`. It compiles to the
same code, character for character (checked on the three witnesses), so the
whole difference is the search.

Median of 5 fresh processes per arm, arms interleaved, npm CE 0.204.3,
Node 26.13.0, Apple M5 Max 18 cores, load 4.6 → 4.9:

| witness | target | `Integrate` ms | `NIntegrate` ms | ratio |
| --- | --- | ---: | ---: | ---: |
| jejjp1xikd | javascript | 527 | 18 | 29 |
| jejjp1xikd | interval-js | 523 | 16 | 32 |
| pmciiapek6 | javascript | 280 | 22 | 13 |
| pmciiapek6 | interval-js | 279 | 19 | 15 |
| trqrlcgu3h `m_2(x)` | javascript | 194 | 18 | 11 |

The row without the integral (`s(x)` of jejjp1xikd) compiles in 17 ms. The
integral of each factor of `s` alone (`½cos(3.14(x−t)) + ½`, or `K(x)`)
compiles in about 55 ms (one process each, load 9): the cost comes from the
product of a trigonometric factor and a user function with an `If`.

## Cause

A CPU profile of each witness on the CE source tree (main at
`9823c383a3ee90346a2595bbe6be16b16a80f0eb`, through tsx, load about 25: read
the shares, not the times):

| witness | compile | in `antiderivative()` | largest part |
| --- | ---: | ---: | --- |
| jejjp1xikd | 1,959 ms | 1,866 ms | `tryIntegrationByParts` 1,740 ms |
| pmciiapek6 | 1,088 ms | 932 ms | `tryReversePowerChain` 796 ms |
| trqrlcgu3h `m_2` | 595 ms | 511 ms | `tryIntegrationByParts` 415 ms |

The path is `closedFormIntegral` → `integralClosedForm`
(`interval-quadrature.ts`) → `antiderivative`, the antiderivative-first
attempt of `closed-form-integral.ts` (300,000 steps per attempt, 600,000 per
compilation). None of the three searches finds a closed form. The record
`antiderivativeTimeouts` keeps only searches that used their whole budget,
so a search that ends without a result runs again at the next compilation.

CE-1286 has the same `tryIntegrationByParts` mechanism for an undeclared
`g`; its proposed fix (give up when the part is a call of an undeclared
function) does not cover these declared functions.

## Options

- (a) Record a search that ended without a closed form as a timeout is
  recorded, keyed on the integral and the engine state: the second target
  and every later compilation of the row skip it. Halves the cost per row.
  Size S.
- (b) Give the attempt a smaller budget when the integrand calls a user
  function or holds a piecewise head (`If`, `Which`, `ElementMax`, a `Sum`
  with a symbolic bound), and the full budget to the other integrands.
  Size S to M.
- (c) Skip the attempt when the integrand holds a head that no integration
  rule matches. Size M.

Ready (the instrument): `Integrate` / `NIntegrate` compile time ≤ 3 on every
witness and target.

## CE answer

CE (2026-11-28): P3 confirmed; pool. Option (a) is the one CE recommends: it
gives the same code and removes the search from every compile after the first;
(b) and (c) change which integrals get a closed form. Workaround: none needed on
Tycho's side (the cost is at load, not per frame).
