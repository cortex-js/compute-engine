A document with many computed lists computes every list each time one formula is substituted, also the lists that the formula does not read.

## Witness

Installed CE 0.187.0, binding units on (the default). `expr.subs(map)` lists every own key of `map` and reads each value. With `CE_BINDING_UNITS=0`, and on CE 0.186.0, it read only the keys of the symbols of `expr`.

```js
const map = new Proxy({ C: ce.box(['List', 2, 4, 6]), B: ce.box(['List', 1]) }, traps);
ce.parse('C[2]+1').subs(map).evaluate();   // 5 in both modes
// units on:  get _kind, ownKeys, descriptor C, get C, descriptor B, get B, descriptor C, get C, get C
// units off: descriptor C, get C, get C
```

Tycho gives `subs()` a lazy map: reading a key resolves that computed collection (`lazyResolvedCollections` in Tycho's `src/graph-paper/graph/computed-collections.ts`). About 60 Tycho call sites call `subs()`, many with this map, so each call now resolves every collection of the document. The values are the same; the cost is not measured on a document yet. The instrument prints the reads of the map and `CE-1213: READY` when the key `B` is never read.

## What it must give

`subs(map)` reads `map[name]` only for the names that the expression reads (its symbols and operator heads), as before.

## Cause and options

Not investigated. The read of `_kind` before the keys suggests that the new code tests whether the argument is an expression and then copies the map. Option: walk the symbols of the expression and read `map[name]` for each. Size S.

## Tycho half on adoption

Tycho half on adoption: run the instrument; when it reads READY, restore the assertion `failures().size === 0` of the test named in `source-ref` and remove its `Waits for compute-engine issue CE-1213` marker.

## CE answer

CE (2026-11-11): P2 confirmed, a regression of 0.187.0. Fixed in `da38904e70310895ed51442f93600426244aa57a`, for the next release: the input of the `subs()` operation was every boxed value of the substitution; it is now the values for the symbols and the operators of the expression (`substitutionInput()`, `binding-unit.ts`). The instrument prints `CE-1213: READY` against a production build of that commit (`CE_ALT_PKG`). No workaround is needed for values; until the release each `subs()` reads every key.
