`IntegerString` of a symbol is a type error that names the same type twice, instead of staying unevaluated.

## Witness

On main:

```
ce.box(['IntegerString', 'n']).evaluate()   // Error(ErrorCode("incompatible-type", "integer", "integer"), n)
```

The base operand has the same problem: `IntegerString(5, b)` (reported by the reviewer).

## Cause and options

The handler in `library/core.ts` returns `ce.typeError(...)` when `op1.isInteger` is not `true`; for an undeclared symbol it is `undefined`. Return `undefined` (stay unevaluated) unless `isInteger === false`. Size S.
