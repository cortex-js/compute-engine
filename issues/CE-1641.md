Expanding a sum or a function whose body names a stored formula uses the index of the sum, or the parameter of the function, in place of a variable of the same name in the formula.

## Witness

MathJSON, evaluated in order at `edccc20202dd5567a15031af3094240a7c52c04f`
(the fix of CE-1455 does not change these values):

```
["Assign", "a", ["Add", "n", 1]]
["Sum", ["Multiply", "a", "n"], ["Limits", "n", 1, 3]]
    → ["Add", ["Multiply", 6, "n"], 6]
["Expand", ["Sum", ["Multiply", "a", "n"], ["Limits", "n", 1, 3]]]
    → ["Sum", ["Multiply", "n", ["Add", "n", 1]], ["Limits", "n", 1, 3]]
```

The `n` of the value of `a` is the global `n`
(`docs/SCOPING-MODEL.md`, "Free names"), so the sum is `6n + 6`. The result of
`Expand` is a sum of `n(n + 1)` over the index, which is `20`. `Factor` gives
the same result.

```
["Assign", "y", ["Sin", "x"]]
["Assign", "x", 1]
["Apply", ["Function", "y", "x"], 2]               → ["Sin", 1]
["Apply", ["Expand", ["Function", "y", "x"]], 2]   → ["Sin", 2]
```

## Cause and options

`resolveBoundSymbols()` (`src/compute-engine/boxed-expression/utils.ts`)
replaces a symbol of the operand by its stored value, also under a binder of
the operand (`Sum`, `Function`, `Block`). It then makes the binder again with
`rebuildCall()`, which makes the value canonical in the scope of the binder: a
free symbol of the value that has the name of the binder's variable becomes
that variable. The names of the binder are in `protect`, so the symbol is not
replaced by a value of its own, but it is captured.

CE-1455 fixed the other shape of this defect: the transformer is evaluated
inside the function, the block or the sum, and the binder is not in its
operand.

Options:

- (a) Do not replace a symbol under a binder of the operand when its resolved
  value has a free symbol (`freeSymbolNames()`) with the name of a variable of
  an enclosing binder of the operand. The symbol stays, and the transformer
  does not see into it: `Expand(Sum(a·n, …))` is the sum as written, which
  evaluates to `6n + 6`. The names that binders add must be kept apart from
  the caller's `protect` (the unknowns of `Solve`), which must still stop a
  replacement and not a capture test. This is the test that
  `betaReduceLambda()` makes before it inlines a body. Size S.
- (b) Rename the variable of the binder before the value is placed under it.
  Size M, and it changes the names in results.

Recommended: (a).
