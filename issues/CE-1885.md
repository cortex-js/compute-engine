Starting the million-cell Game of Life can time out while the notebook binds
its board and picture.

## Witness

On CE 0.202.0, Tycho's instrument injects a host function that adopts a
4 MiB `Uint8Array` as 1,048,576 `Pixel` cells. Each program returns 1 with
no diagnostics. On the M5 Max on 2026-11-26, the run with the large array
in a nested block took 2.3 ms. Binding the same size array at top level
took 1,440 ms. A top-level 16-pixel control took 7.4 ms. The Life notebook
with top-level board and picture bindings took about 8 s in one run and
hit a 10 s limit under machine load. Moving those bindings inside `do`
brought initialization below 0.4 s with a 2 s limit.

## Cause and options

The notebook CPU profile shows `BoxedArray.json` and `_peek` under the
Epsil statement-result hook. In `src/epsil/execute-epsil.ts`,
`reportStatement` passes `value.json` to `scanUnknownFunctions`, so the
scan expands all array cells even when the program discards the statement
value. The cost also applies to an array inside a nominal tuple, such as
a raster or picture. Please skip array contents in the diagnostic scan of
evaluated values, using the boxed tree or opaque object serialization.
Keep diagnostics for calls written in the source.

## CE answer

Confirmed P2 and fixed in `f930ee0f9`. Top-level pixel arrays, including
arrays held by nominal tuples, are opaque to the statement diagnostic scan.
Calls written in source are still checked. Until adoption, moving the large
bindings inside `do` remains the workaround.

Ran Tycho's instrument with its imports pointed at source on Node 26.13.0.
There were three fresh process runs each at `04dd1d457` and at that revision
with the fix applied. The 1,048,576-pixel top-level binding took a median
4,516.8 ms before and 1.9 ms after. The nested control took 3.4 ms and 2.8 ms,
respectively. All runs returned 1 with no diagnostics. Every baseline
reported `BLOCKED` and every patched run reported `READY`. The shared box
lock was held, with load of 9.1 / 11.2 / 10.2 on 18 cores at acquisition.

example with top-level board and picture bindings at the default run limit.
