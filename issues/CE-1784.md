In a scope where the user defines a function named `Divide`, `solve()` finds no solution of a linear equation.

## Witness

At commit `7b5ebf46fc30852681ff9167781295c9a28fc999`, with the CE-1760 fix applied:

```ts
ce.pushScope();
ce.declare('Divide', 'function');
ce.assign('Divide', ce.expr(['Function', 1000, 'u', 'v']));
ce.expr(['Equal', ['Multiply', 2, 'x'], 3]).solve('x')   // []; must be [3/2]
ce.popScope();
```

Outside the scope the same call gives `[3/2]`.

`crafted`: the program defines a user function with the capitalized name of
a library function and solves an equation in its scope.

## Cause and options

The solver (`solve-domain.ts`, also `factor.ts`, `polynomials.ts`,
`diophantine.ts`, `kind-dispatch.ts`) builds its quotients with
`ce.function('Divide', …)`, which binds the call by its name in the current
scope, so in a scope with a user `Divide` the quotient is a call of the user
function. CE-1760 fixed the builds of the arithmetic code with `libraryFn()`
(`library-shadowing.ts`) and `libraryReciprocal()` (`arithmetic-power.ts`).
Option: build these quotients the same way, or run the solver with the
library definitions of the arithmetic operators. Related: CE-1759, CE-1114.
