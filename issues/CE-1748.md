A recursive function declared `-> nothing` whose body reads the value of its own recursive call is accepted alone, and refused with a misleading message when the program has any other statement.

## Witness

Main at `6bfc0b53d0778762499b4611e7cbe042101e0617`, with a host function
`figureDraw` declared `(any) -> nothing`:

```
function rec3(t: real) -> nothing { if t > 0 { let y = rec3(t - 1)
  figureDraw(y + 1) } else { figureDraw(0) } }
```

Alone, `executeEpsil` reports no diagnostic. With one more statement before or
after it (`const a = 1`), the program reports:

```
runtime-error: expected `(t: real) -> nothing`, got `unknown` — rec3: The
declared type is a function signature, but the initializer is not a function …
```

The same function without the read of its own value (`if t > 0 { rec3(t - 1) }
else { figureDraw(0) }`), or with a result `real`, is accepted in both cases.

## Cause and options

Not investigated. The body reads `Nothing + 1` (`y` is the `Nothing` of the
recursive call), so a static error at `y + 1` is a reasonable outcome; the
defects are that the outcome depends on whether another statement is present,
and that the message names the initializer instead of `y + 1`. Expected: the
same diagnostic in both cases, at `y + 1`.
