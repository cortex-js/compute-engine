A function that fills a list in a loop gives a broken list when the loop writes more than 100 elements: about one write in a hundred is not done.

## Witness

CE 0.201.5 (the installed bundle of Tycho), a fresh engine per shape. The
program is the MathJSON of the Epsil function
`let L = [0 for j in 1..n]; for k in 1..n { L[k] = k*k }; L`:

```json
["Block",
  ["Declare", "L", ["Dictionary", ["KeyValuePair", "value",
    ["Comprehension", 0, ["Element", "j", ["Range", 1, n, 1]]]]]],
  ["Loop", ["Block", ["Assign", "L", ["ReplaceAt", "L", "k", ["Multiply", "k", "k"]]]],
    ["Element", "k", ["Range", 1, n, 1]]],
  "L"]
```

`ce.box(program).evaluate()` gives:

| n    | `ReplaceAt` left in the value | value head  |
| ---- | ----------------------------- | ----------- |
| 100  | 0 (positive control)          | `List`      |
| 200  | 2                             | `ReplaceAt` |
| 1000 | 10                            | `ReplaceAt` |

Expected: a `List` of `n` numbers in every case. The inner `List` holds the
other writes; the unevaluated ones wrap it, for example
`["ReplaceAt", ["ReplaceAt", ["List", 1, 4, …], 199, …], 200, …]`. The count
is the same on every run, so it is not a time limit; `iterationLimit` is
`Infinity` on the engine. In Tycho, `koch-snowflake`'s prelude function
`snowflakeVertices(3)` leaves 23 writes, `(4)` 10 and `(5)` 18. A nested
loop, an `if` or trigonometry is not needed.

Tycho meets it when a plot row calls a prelude function
(`K = \operatorname{snowflakeVertices}(5)`): the document engine evaluates the
call with the interpreter, the row's value is a `ReplaceAt` expression, and
the plot that reads `K` draws nothing. A prelude constant
(`const Q = snowflakeVertices(5)`) is right, because the prelude runs compiled.

## Cause and options

Not traced. The value is right up to 100 writes, so a cap of 100 on some
evaluation step (a cache, a depth, a batch) is likely. Possibly related:
CE-1796 (the same loop over 20,000 elements exceeds the call stack).

Tycho's way around it (user ruling 2026-11-25, ROADMAP row LY): a row's call
of a prelude function will run the compiled function. The interpreter still
gives the wrong value to any other host that evaluates such a function.
