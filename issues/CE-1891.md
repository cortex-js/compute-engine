Animated notebook drawings can lose the fast path when a group contains a figure with default style options.

## Witness

Relay Vault draws a textured 320 × 200 raster alongside vector controls. On
CE 0.202.0 the timer's draw declines with `List(): an empty list`. Tycho runs
the draw interpreted while compiling the pixel loop separately. The instrument
verifies a 256,000-byte frame and the fallback note.

The compiler also declines without a host call or a raster. Evaluate these
declarations, then compile the value of `frame` to JavaScript.

```epsil
type Leaf = tuple<geom: list, options: list<real>>
type Group = tuple<parts: list>
let leaf = Leaf([1], [])
let figure = Group([leaf])
let frame = (t: real) => figure
```

The interpreter returns `["Group", ["List", ["Leaf", ["List", 1], ["List"]]]]`
with no diagnostics. JavaScript compilation succeeds for both controls:
`let figure = leaf` with the empty list, and the original group with
`Leaf([1], [1])`. The installed package's MCP evaluator also returns the
nested empty-list value without diagnostics. Its compile tool declines the
type declarations when they are part of the program being compiled, so the
instrument evaluates the declarations before compiling the callback.

## Cause and options

The controls isolate an empty typed field inside a record inside a list.
CE-1808 covers empty lists at a known field type. Preserve or recover the
leaf field's type when lowering the nested record in the list. The compiled
result should have the same shape as the interpreted value, with
`options: []`. Verify both the reduced case and Relay Vault.

Tycho half on adoption: rerun the instrument. Combine the render and draw
statements in Relay Vault once the combined callback compiles and the browser
instrument still passes. The split is the current workaround.

## CE answer

Confirmed P3. The compiler fix is in `067f2803c`. It looks through the
captured list to the `Leaf` constructor, where `options: list<real>` supplies
the type of the empty list. The regression test checks both the interpreted
MathJSON and the compiled object with `options: []`.

Ran the Tycho instrument against the Compute Engine source. Both controls
and the nested case compiled, the timer returned a 256,000-byte raster
frame, and the instrument reported `READY`. The drawing helper still
reports a separate decline for `figureDraw(ListFrom("args"))`. Keep the
split until the combined callback and browser instrument pass on adoption.
