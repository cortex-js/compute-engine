A compiled integral whose integrand draws a random number is a constant.

## Witness

At `114403d0b44156730f1f943b12362d0c74f90fc8`, JavaScript target,
`cse: false, constantFold: false`:

```ts
const e = ce.box(['Integrate', ['Add', 't', ['Random']], ['Limits', 't', 0, 1]]);
compile(e, { cse: false, constantFold: false }).code; // (1.0442009924764881)
```

Each compilation gives another constant, and each call of the compiled
function the same one; the interpreter draws at each evaluation.

## Cause and options

`closedFormIntegral()` (`compile-integrals.ts`) evaluates the integral at
compile time with no purity test, so the draw is made once.
`derivativeClosedForm()` and `compileDerivative()` decline an impure node
for this reason. Option: return `undefined` from `closedFormIntegral()`
when the node is not transitively pure, so that the quadrature samples at
run time. The numeric-kernel profile declines such an integral.
