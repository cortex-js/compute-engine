A numerical integral of a lone variable that holds a number gives no number.

## Witness

At 1ceacbf03641f2e11fa728bc2f6990accd8d9919, with `c := 5`:

```
NIntegrate(c, 0, 2)      NaN        (must be 10, the integral of the constant 5)
NLimit(c, 0)             5
ND(c, 1)                 1.6e-15    (0 within the precision)
Limit(c, 0).N()          5
```

The workaround is to write the variable: `NIntegrate(x => c, 0, 2)` is 10.

## Cause and options

The canonical form of `NIntegrate` keeps a bare symbol as the name of a
function (`canonicalImplicitLimitFunction()`, `library/calculus.ts`). The
evaluate handler wraps only the name of an operator in a literal
(`functionLiteralOfName()`); a symbol that holds a number is passed on as it
is, and the quadrature reads no number from it. `ND` and `NLimit` read the
same symbol as the body of a constant function.

- (a) Recommended. In the evaluate handler of `NIntegrate`, read a bare
  symbol that holds a value that is not a function as the body of a constant
  function, as `ND` does: `NIntegrate(c, 0, 2)` is 10.
