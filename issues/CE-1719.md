In Epsil, an error in the body of a function that an element of a list calls can still underline another element when a variable or a call comes before it in the list, when the list has a spread, is assigned to an element, or is an operand of a calculation.

## Witness

```
function g(x) { Ln(x) + 1 }
let y = 5
let w = [1]
let v = [y + 1, ...w, g("a")]
underline  ->  y          expected: g("a") or the statement

let m = [[1, 2], [3, 4]]
m[1] = [y + 1, g("a")]
underline  ->  y          expected: g("a") or the statement

let v = [y + 1, g("a")] + 1
underline  ->  y          expected: g("a") or the statement

let z = 2
let v = [y, z + 1, g("a")]
underline  ->  z          expected: g("a") or the statement
```

## Cause and options

The fix of CE-1137 (`heldElement()`, `src/epsil/execute-epsil.ts`) finds the
written element of the list whose value holds the error, and locates the error
inside that element, so that the frames of the body of `g` match no call. It
reads only a list or a tuple that is the value of the statement, of a `let` of
a name or of an assignment to a name, whose value has as many elements as are
written.

- A variable or a call before the element: either can give a `Sequence`,
  which the list splices, so the position of the element in the value is not
  known (`[s, g("a"), t]` with `s = Sequence(1, 2)`, `t = Sequence()` is
  `[1, 2, Error]`). Only a literal, a list, a tuple or an arithmetic call
  (`isSingleValued()`) is accepted before the element; otherwise the old
  location runs. A fix reads the value of each such variable, or the type
  of each such call, to prove that it is not a `Sequence`.
- A spread: the value has another number of elements. A fix maps the
  elements before the first spread from the start, with the rule above.
- An assignment to an element: the value of the statement is `Nothing`, so
  the list is not in it. The path that reports this error is not traced. A
  fix reads the assigned value on that path.
- A list that is an operand of a call (`[…] + 1`): the value of the
  statement is not the list, so its elements are not read.

Option (a) of CE-1137 (the call of a user function adds a frame to an error
that its body returns) would fix all four, and changes the `ErrorTrace` and the
message of every such error.
