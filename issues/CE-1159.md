The compiled code of `Reduce(S, f, 0)` over a list of strings, with `f := (a, s) ↦ a + Length(s)` given by its name, throws a `RangeError` instead of giving the total number of characters.

## Witness

With `S: list<string>`, on the JavaScript target, at `S = ["xy", "z"]`:

- `f := (a, s) ↦ a + Length(s)` defined on the engine: `Reduce(S, f, 0)`
  compiles to `(_.S).reduce(((_f) => (_a, _b) => _f(_a, _b))(_fn_f), 0)` and
  throws `RangeError: Length: the operand is not a list or a set at run
  time`. `Fold(f, 0, S)` compiles to the same code and throws too. The
  interpreter gives `3`.
- The same function local to a block,
  `Block(Assign(g, (a, s) ↦ a + Length(s)), Reduce(S, g, 0))`, throws the
  same error. The interpreter gives `3`.
- Workaround: the function literal written in place of its name,
  `Reduce(S, (a, s) ↦ a + Length(s), 0)`, compiles `Length` with
  `_SYS.chars` and gives `3`.

Checked at commit `01761c21599a0ea80e443afa1b3a6d39d752fc89` with the fix of
CE-1120 applied, which does not change this case.

## Cause and options

`s` has the inferred type `collection`, and the function is compiled once
against that type: `Length` of a `collection` reads the operand with
`_SYS.elts`, which refuses a string. A call with a string argument and a
callback that receives one element use the function compiled with the
parameter typed `string` (`ensureSpecializedUserCallEmitted()` in
`compilation/compiler-core.ts`; `stringElementCallbackEta()` and
`stringElementLocalCallback()` in `compilation/compile-user-functions.ts`,
called from `callbackArg()` in `compilation/javascript-target.ts` only when
`extraArgTypes` is empty). A callback that also receives an accumulator
(`Reduce`, `Fold`, `Scan`) has a non-empty `extraArgTypes` and keeps the
function compiled for a list.

Options: (a) extend the two callback functions to a callback with an
accumulator, typing only the element parameter `string` (the expansion
`(_a, _x: string) ↦ f(_a, _x)` for a function defined on the engine, the
typed literal for a block-local function); (b) decline such a callback when
the element parameter is a collection type that admits a string and the
elements are strings.
