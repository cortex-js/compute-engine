Substituting a name in a sum changes the value of the sum when the new value uses the name of the index.

## Witness

```
Sum(j + k, Limits(k, 1, 3)).subs({j: k})  ->  Sum(k + k, …) = 12
expected                                   ->  Sum(k + k_1, Limits(k_1, 1, 3)) = 3k + 6
```

## Cause and options

`subs()` is not capture-avoiding: the index captures the replacement `k`. User
decisions 2026-10-30: `subs()` renames the index first. For the two binders
that cannot be renamed before evaluation (a held block's `Assign`, a `Declare`
inside an `If` branch), option (a): the replacement is inserted as today,
documented with examples, and an internal variant returns `undefined` there.
Nine internal callers check for this capture and decline today; each check is
removed in its own step, with a test. Starts after the fix of GitHub issue #489
is committed. Plan: `docs/plans/2026-10-30-capture-avoiding-subs.md`.
