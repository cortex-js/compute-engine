Keeping one symbol from a boxed tuple can keep a discarded sibling function's expressions and local definition alive.

## Witness

Run with Node 26.13.0 and `--expose-gc`. Start with an empty engine and box
two functions together. Keep only the second function's `kept` occurrence.

```js
import { ComputeEngine } from '@cortex-js/compute-engine';

function sample() {
  const ce = new ComputeEngine();
  const pair = ce.box([
    'Tuple',
    ['Function', ['Add', 'a', 'other'], 'a'],
    ['Function', ['Add', 'b', 'kept'], 'b'],
  ]);
  const body = pair.ops[0].op1.ops[0];
  const parameter = body.ops.find((op) => op.symbol === 'a');
  const kept = pair.ops[1].op1.ops[0].ops.find((op) => op.symbol === 'kept');
  if (body.type.toString() !== 'number') throw new Error('expected number');
  return {
    kept,
    sibling: new WeakRef(parameter),
    definition: new WeakRef(parameter.valueDefinition),
  };
}
const { kept, sibling, definition } = sample();
for (let i = 0; i < 12; i++) {
  await new Promise((resolve) => setImmediate(resolve));
  globalThis.gc();
}
console.log(kept.json, Boolean(sibling.deref()), Boolean(definition.deref()));
```

Source snapshots gave `kept false false` at `aa49b8ab0` and
`kept true true` at `672b22cfa`. A private per-environment `WeakMap` trial
gave `kept false false` and passed the 11 binding-unit cache tests. The probe
uses a deliberately selected survivor. It establishes a retention edge
without estimating the frequency or total retained bytes in host workloads.

## Cause and options

`7f6c62956` moved the token table onto the shared unit environment and
made scope and definition keys strong. A retained occurrence keeps the
environment alive after sibling occurrences have been discarded. A
per-environment `WeakMap` keeps the table ownership and removes the new
strong edge. Six screened production pairs measured median paired changes
of +0.8% on polynomial boxing and +1.7% on function boxing against
`672b22cfa`, with both signs across rotations. The private patch passed all
18 core suites. It is ready to stage separately from the solver fix.
