A sum over a set with a condition that reads an unknown value gives 0 instead of staying unevaluated.

## Witness

```
ce.box(['Sum', 'k', ['Element', 'k', ['Set', 1, 2, 3], ['Greater', 'x', 0]]]).evaluate()
  ->  0        (x has no value; probe 2026-11-07, HEAD 5ab79553c01efb59ebfbc53e0298267fb7bea620)
ce.box(['Sum', 'k', ['Element', 'k', ['Set', 1, 2, 3], ['Greater', 'k', 'x']]]).evaluate()
  ->  0
expected  ->  the sum stays unevaluated (6 when x > 0, 0 otherwise)
```

## Cause and options

`filterValuesWithCondition()` (`library/logic-analysis.ts`) keeps a value
only when the condition evaluates to `True`, so an undecided condition drops
the value as if it were `False`. Option: when the condition of a value is
neither `True` nor `False`, give no filtered domain, so that the sum stays
unevaluated. Size S.
