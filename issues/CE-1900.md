Go to Definition and Rename treat an early read of a shadowing local as a read of the outer variable.

## Witness

```epsil
let x = 10
do { let before = x; let x = 2; before }
```

At the first `x` inside the block, `epsilProgramSites()` resolves the local
`x`, and `checkEpsil()` reports `read-before-declaration`. Go to Definition
points to the outer `x`. The editor's occurrence group for the outer variable
includes the inner read. Applying its rename edits to rename the outer `x`
to `outer` changes that read, removes the diagnostic, and makes the block
return 10.

## Cause and options

The editor and the engine select different binding rules in
`documentBindings()`. Use the engine's lexical target for navigation and
rename, and track initialization separately so the editor can still report
a premature read. CE-1889 covers a separate case involving a recursive
initializer.
