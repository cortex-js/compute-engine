A function whose parameter accepts a point of integers or a string accepts a point with a fractional coordinate and returns it unchanged.

## Witness

At `50a7ed54e784bdea02b0da186964c714e24897a9` with the fix of CE-1088:

```ts
const ce = new ComputeEngine();
ce.declare('F', '(tuple<integer, integer> | string) -> unknown');
ce.parse('F(p) := p').evaluate();
ce.box(['F', ['Tuple', 1.5, 2]]); // valid; evaluates to (1.5, 2)
```

Expected: an `incompatible-type` error, as `F` declared
`(tuple<integer, integer>) -> unknown` gives since CE-1088.

## Cause and options

The CE-1088 fix (`pointComponentRefuted()` in
`src/compute-engine/boxed-expression/validate.ts`) checks the components of a
`Tuple` argument only at a parameter that is one tuple type. At a union
parameter, the overlap admission at boxing admits the tuple, and the runtime
conformance check (`runtimeConformanceError()`) leaves a collection-shaped
value at a parameter with a collection arm to the handler; a user function
has no handler that checks it. Option: in `pointComponentRefuted()`, read the
arms of the parameter (`paramArms()`) and refute when every tuple arm of the
arity of the point refutes a component and no other arm overlaps the type of
the argument. Size S.
