An Othello move cannot run within the action budget unless its author adds explicit types to intermediate counts.

## Witness

Installed CE 0.184.0. Epsil `f(B: list<integer>, k: integer) -> integer` accumulates a local count in a loop and returns it. The function binding has the declared integer result, but `f(L,3)` with `L: list<integer>` has type `integer | list<any>`. A caller's `if f(B,k)>0 { out=1 }` declines compilation because its condition might be a collection and its branch assigns a name. The interpreter returns 1. Assigning the call to `let c: integer` first makes compilation succeed and returns 1.

The instrument uses fresh engines for both forms. Othello exposed this with `flips` and `ray`; its Prelude now annotates those intermediate counts. The 50 ms budget is unchanged. Expected: a call with arguments of the declared parameter types retains its declared scalar result and its scalar condition compiles. Cause not established.

## Tycho half on adoption

Tycho half on adoption: rerun the scalar return instrument, then remove the extra scalar count annotations and the CE-1179 marker in `src/graph-paper/onboarding/showcase-othello.js` only when its exact click handler still compiles and runs within the unchanged action budget.
