A function compiled to JavaScript that calls a host function given in the `functions` option reports success, then fails when it is called.

## Witness

On commit `1e5d675b7c8364c96dc5957a37a4c7c8495700be`, with no other change:

```ts
const r = compile(ce.box(['Function', ['helper', 'x'], 'x']), {
  functions: { helper: (x) => 2 * x },
});
r.success; // true
r.code;    // "(x) => helper(x)"
r.run(3);  // throws ReferenceError: helper is not defined
```

It must give `6`, or the compilation must decline.

## Cause and options

The code of a function literal names `helper`, and the result does not define
it. For an expression that is not a function literal, a function object of
the `functions` option is copied into the preamble as source
(`javascript-target.ts`, where the preamble is built from the option). The
cause for a function literal is not traced.

Options: (a) define the function for a literal as for an expression;
(b) decline. Size S.

Workaround: compile the body as an expression with `x` as an input, or define
the function in the engine.
