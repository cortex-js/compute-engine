A function that returns a list is reported as returning a single number when it is called with a name that has no definition; no Tycho user sees an effect today.

## Witness

CE 0.193.0, `new ComputeEngine()`. The same readings on 0.186.0, so this is not
a regression.

```ts
ce.declare('j', { type: 'list<integer>', value: ce.box(['List', 3, 1, 4, 1, 5]) });
ce.assign('f', ce.box(['Function', ['At', 'a', ['Add', 'b', ['Range', 1, 3]]], 'a', 'b']));

ce.box(['f', 'j', 'N']).type.toString();             // "integer"        (N not declared)
ce.box(['f', 'j', 'N']).evaluate().type.toString();  // "list<integer>"  (At([3,1,4,1,5], [N+1,N+2,N+3]))
ce.box(['f', 'j', 2]).evaluate().toString();         // "[4,1,5]"
```

The index `Add(b, Range(1,3))` is a list for every `b`, so the call returns a
list for every `N`. The type `integer` does not hold that value.

Controls, each on a new engine:

| Call or expression | `N` | Type |
| --- | --- | --- |
| `f(j, N)` | not declared | `integer` (wrong) |
| `f(j, N)` | declared `unknown` | `unknown` |
| `f(j, N)` | declared `real` | `list<integer>` |
| `f(j, 2)` | | `list<integer>` |
| `At(j, Add(N, Range(1,3)))`, no function | not declared | `list<integer>` |
| `g(b) := At(j, Add(b, Range(1,3)))`, `g(N)` (the list is not a parameter) | not declared | `list<integer>` |
| `f(a,b) := At(a, Less(b, Range(1,5)))`, `f(j, N)` | not declared | `list<integer>` |
| `f(a,b) := At(a, Less(0, Add(b, Range(1,5))))`, `f(j, N)` | not declared | `integer` (wrong) |

It reproduces when the list is a parameter, the index is an `Add` of another
parameter and a list, and the argument of that parameter is a name that
nothing declares. These are the shapes we found; the cause is not known.

Corpus form: `r_{emove}(L,i)=L[|[1...count(L)]-i|>0]` and the action
`r_{emoveAll}(N)=j\to r_{emove}(j,N),…` of state `3y0t1f0mo7`. `N` is the
action's parameter, so nothing declares it when the written side is typed.

## What it must give

A type that holds the value: `list<integer>`, or `unknown` as for a declared
`unknown` argument.

## Effect on Tycho

None visible today. A check of an action write by the static type of the
written side would refuse these six valid list writes; the Document rule of
2026-11-18 admits a write by its evaluated value, which avoids it. Workaround:
declare the name, or read the type of the value. Tycho half on adoption: none.
