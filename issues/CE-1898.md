Transposing a row of booleans replaces every cell with a missing-value error.

## Witness

```ts
const ce = new ComputeEngine();
ce.expr(['Transpose', ['List', ['List', 'True', 'False']]]).evaluate().json;
// ['List', ['List', ['Error', "'missing'"]], ['List', ['Error', "'missing'"]]]
```

The result should be `['List', ['List', 'True'], ['List', 'False']]`.
The input is a literal with both dimensions known.

## Cause and options

Trace the packing and transpose of a tensor with nonnumeric cells. The
transpose type is already `matrix<boolean^(2x1)>`.
