A product of two names that have no type is ordered as a product of numbers, so two matrices given later are multiplied in the other order, with no error.

## Witness

Run on main at `3927b6c89ac284a5088a752718937455ac3c8a23` and on the fix of
CE-1270.

A function of two untyped parameters:

```js
const A = ['List', ['List', 1, 2], ['List', 3, 4]];
const B = ['List', ['List', 0, 1], ['List', 1, 0]];
ce.assign('f', ce.box(['Function',
  ['Subtract', ['Multiply', 'A', 'B'], ['Multiply', 'B', 'A']], 'A', 'B']));
ce.box(['f', A, B]).evaluate().json;
// [[0, 0], [0, 0]]        the commutator is [[-1, -3], [3, 1]]
// the type of f: (A: unknown, B: unknown) -> number
```

An expression boxed before its names are assigned:

```js
const e = ce.box(['Multiply', 'q', 'p']);     // boxed as ["Multiply", "p", "q"]
ce.assign('p', ce.box(A));
ce.assign('q', ce.box(B));
e.evaluate().json;                             // [[2, 1], [4, 3]], which is p·q
ce.box(['Multiply', 'q', 'p']).evaluate().json; // [[3, 4], [1, 2]], boxed after
```

The fix of CE-1270 covers a function whose body ALSO uses the parameter as a
matrix (`Determinant(A)`): the body is then boxed again with `A: matrix`. A
body with no such use, and a host name, are not covered.

## Cause and options

The canonical form of `Multiply` sorts its operands when it reads them as
numbers, and a name with no type is read as a number
(`docs/plans/2026-11-13-names-and-types-user-model.md`, rule 4). The form is
made once, when the expression is boxed.

Options:

- (b) A product whose operands include a name with no type (an untyped
  parameter, an undeclared name) keeps the order of its operands, and a
  difference of two such products does not cancel. Cost, not measured: the
  canonical forms of products of undeclared symbols change (`b·a` is no
  longer printed `a·b`), which many tests and snapshots hold, and
  `x·y − y·x` no longer simplifies to 0 at boxing for undeclared `x`, `y`.
- (c) Keep the reading and document it: an untyped name is a number, and a
  matrix function declares its parameters (`A: matrix`) or uses
  `MatrixMultiply`. The model document states this for a parameter (section
  5, "A matrix given to an untyped parameter is treated cell by cell"); it
  does not state it for a host name assigned after the expression is boxed.

Recommended: (c), with the host-name case added to the guide. (b) changes
the printed form of ordinary algebra for every user to cover a program that
a declaration fixes. The measurement of CE-1280 found 7 tests whose value
depends on the order of a product of two names that hold matrices when the
expression is boxed; they are right today because the held value is read at
boxing.
