The integral of `x^2 g(x)`, with `g` a function nobody defined, waits about 1.5 s before it comes back unevaluated; `x g(x)` comes back at once.

## Witness

Measured on commit `40ba059a8444959fbcfb94fe393d1a540d423088`, on a loaded
machine, one engine:

| Program | Time | Result |
| --- | --- | --- |
| `\int x^2 g(x) dx` `.evaluate()` | about 1.8 s | `int(g(x) * x^2 dx)` |
| the same, a second time | about 1.5 s | the same |
| `\int x g(x) dx` | about 7 ms | `int(x * g(x) dx)` |
| `\int g(x) dx` | about 6 ms | `int(g(x) dx)` |

No closed form exists without knowing `g`. Test:
`test/compute-engine/calculus.test.ts`, "INDEFINITE INTEGRATION product" (its
shared engine also has `f := x ↦ x³`).

## Cause and options

The review traced the time to `tryIntegrationByParts`
(`symbolic/antiderivative.ts`): it differentiates `x²` and integrates `g(x)`,
which has no antiderivative, and the search continues on the parts.

- Integration by parts gives up at once when the part it must integrate is a
  call of an undeclared function (or any part with no antiderivative found in
  a first, cheap pass). Size S.
