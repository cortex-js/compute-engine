The length of a point, written `|p|` or `Norm(p)`, is no longer known to be a real number, so a colour or a test that needs a real value can treat it as a complex one.

## Witness

`ce.box(json).type.toString()`, a new engine with no declarations:

| expression | 0.201.1 | 0.201.2 |
| --- | --- | --- |
| `["Norm", ["PointList", 3, 4]]` | `real` | `+oo \| nan \| real` |
| `["Abs", ["PointList", 3, 4]]` | `real` | `number` |
| `["Norm", ["Tuple", 3, 4]]` (control) | `real` | `real` |
| `["Distance", ["PointList", 0, 0], ["PointList", 3, 4]]` (control) | `real` | `real` |

Both versions measured on 2026-11-24 (0.201.1 from its npm package). The value
is 5 in every case. Expected: `real`, as for the `Tuple` control and as the
0.201.2 CHANGELOG entry for CE-1215 says ("the type of the norm of a point").

The instrument prints `CE-1767: READY` when the two cases are typed `real`.

## Cause and options

Not investigated on the CE side. The change came with 0.201.2; the CE-1215 fix
(the type of `Norm(At(LQ, -1))`) is the likely cause, since it changed the
type handler of `Norm`, `Abs` and `Hypot` of a point. `PointList` with two
numbers seems to take a different arm of that handler than `Tuple`.

Tycho effect: one engine pin fails. The CORE render audit and the
classification census show no change on 0.201.2. Tycho's GPU domain proof
(`gpuDomainProof` in `src/graph-paper/graph/style-expressions.ts`) reads
whether an operand's type matches `real`; a colour that takes the length of a
point could lose the GPU lane.

## CE answer

CE (2026-11-24): fixed on main, not released. The CE-1215 change read the
components of a point for its norm type only from a written-out `Tuple`
(`pointLiteralComponents()`, `library/utils.ts`), so a `PointList` call fell
to the wide `number`. A call of the library `PointList` is now read as a
point written out, with its arguments as the components: `Norm(PointList(3,
4))` and `Abs(PointList(3, 4))` are typed `real`. A function of the user named
`PointList` is not read as a point. `Hypot(PointList(3, 4), 12)` is still
typed `number` (CE-1780, an older defect of `Hypot`). Tycho half on adoption:
run the instrument; the engine pin in `style-coordinate-colors.test.ts` can
go back to `real`.
