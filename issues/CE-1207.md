With angles in degrees, compiled code computes the sine of a `let` variable's value in radians.

## Witness

At `775bc003b8ae9fcb40a0766fd62e2b5b40163759`, JavaScript target, default
options, `ce.angularUnit = 'deg'`, `x: real`:

```ts
const b = ce.box(['Block',
  ['Declare', 'a', ['Dictionary', ['KeyValuePair', { str: 'value' }, ['Sin', 'x']]]],
  ['Multiply', 'a', 'a']]);
compile(b).code;           // (() => { let a = Math.sin(_.x); return a * a })()
compile(b).run({ x: 30 }); // 0.9762064902075782
```

The interpreter gives `0.25`. The same block with the typed form
`Declare(a, 'real', Sin(x))` compiles to
`let a = Math.sin(0.017453292519943295 * _.x)` and gives
`0.24999999999999994`. The first form is the one of `let a = sin(x)`.

## Cause and options

`rewriteAngularUnit()` (`symbolic/angular-unit.ts`) scales the operand of a
trigonometric function before compilation. It does not descend into the value
of a `Declare` whose second operand is a `Dictionary` (the `let` form), so the
sine there stays in radians. Option: descend into the `value` entry of that
dictionary. The `numeric-kernel` profile declines such a program when the
angular unit is not radians.
