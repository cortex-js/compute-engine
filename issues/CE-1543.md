The harmonic number of a decimal number very close to 0 is computed with few correct digits.

## Witness

`ce.box(['HarmonicNumber', ce.number(1e-20)]).N()` gives `1.7e-20` (two
digits; the value is 1.6449340668482264e-20); with `ce.precision =
'machine'` it gives `2.220446049250313e-16`. At `-1e-300` it gives `0`.
The exact rational `10^-20` gives the right value, and so does compiled
code, which uses the series ζ(2)·n − ζ(3)·n² + … for |n| < 0.1.

## Cause and options

The numeric path computes ψ(n + 1) + γ, which cancels for |n| ≪ 1. The
series near 0 of the compiled kernel (CE-1533) can be used there.
