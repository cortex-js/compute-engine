A finite double integral whose integrand grows like 1/r near one interior point gives `NaN`.

## Witness

```
\int_0^1\int_0^1 ((x-1/64)^2+(y-1/64)^2)^{-1/2} dy\,dx
  .N() gives NaN, should be about 1.9451
```

Near the point the integrand is `1/r` and the area element is `r dr dθ`, so
the integral is finite.

## Cause and options

The scan for moving poles finds the point, the inner integral diverges on
the two lines through it (a set of zero measure), and `nIntegrateMultiple`
(`library/calculus.ts`) then gives `NaN`. Fix: when the singular set is a
point where the integrand grows like `1/r^p` with `p` less than the dimension,
split the domain at the point, or change variables around it. The test "AN
ISOLATED SINGULAR POINT IN A DOUBLE INTEGRAL"
(`test/compute-engine/integrate-symbolic-pole.test.ts`) accepts `NaN` or the
value today; make it require the value.
