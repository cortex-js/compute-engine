`simplify()` of a definite integral with an exact value returns the integral, not its value, while `evaluate()` gives the value.

## Witness

```
simplify(\int_{-\infty}^{\infty}\frac{x^2-1}{(x-1)(x^4+1)}dx)
  gives   ∫_{-∞}^{∞} (x+1)/(x⁴+1) dx
evaluate  gives   π·√2/2
```

## Cause and options

`docs/SIMPLIFY.md` folds a constant subexpression only when its evaluation is
a number literal; `π·√2/2` is not a literal, so the integral stays (with a
reduced integrand).

Question: does `simplify()` evaluate a definite integral that has an exact
value?

- (a) No. Keep the documented folding rule; a caller uses
  `expr.evaluate().simplify()`. Close this issue. Cost: none.
- (b) Yes. Fold `Integrate` (and only it) when `evaluate()` gives an exact
  closed form. Cost: a rule in `simplify-rules.ts`, a change to
  `docs/SIMPLIFY.md`, and snapshot changes (not measured); `simplify()` gets
  slower on integrals it cannot evaluate.

Recommended: (a). The folding rule is documented and applies to every head;
an exception for one head makes the rule harder to predict. If nothing is
decided, today's behavior stays.

## Decision

User decision 2026-11-06: (a)

User decision 2026-11-06: (a)
