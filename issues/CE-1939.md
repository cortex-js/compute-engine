The count of a list given to a function that the program names `Sort` is the count of the list, whatever the function returns.

## Witness

```ts
const ce = new ComputeEngine();
ce.pushScope();
ce.declare('Sort', {
  signature: '(list<real>) -> list<real>',
  evaluate: () => ce.expr(['List', 1]),
});
ce.expr(['Count', ['Sort', ['List', 1, 2]]]).evaluate(); // 2, expected 1
```

Read on d656f0889f874dfc5eb117f380a4d03157fc5f4e. `Length`, `IsEmpty` and
`Contains` take the same path.

## Cause and options

`peekWrappers` (`library/collections.ts`) removes `Sort`, `Reverse`,
`RandomShuffle` and `Unique` by their names, in the canonical handlers of
the count and membership operators. It does not check that the call is
bound to the library operator. Option: stop the removal at a wrapper for
which `isLibraryOperator` (`library-shadowing.ts`) is false. CE-1821 added
that check to `orderIndependentSource`, which the evaluate handlers use.
