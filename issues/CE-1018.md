A plot row that draws one curve per element of a long list inside a sum opens about 4 times slower unless Tycho keeps its own route for it.

## Witness

`\sum_{n=0}^{3} 2^{-n}|\sin(2^n x + [0...999]/1000)|`, `x` free:
`evaluate()` and a read of the 1 000 elements take 951 ms; Tycho's route, which
boxes the members, takes 248 ms (medians of 5, 0.182.0, box lock). Reading:
`CE-1018: NOT READY on 0.182.0 (… 3.8×, limit 1.25×)`.

Requested: the elements stay evaluated forms (owner decision 2026-10-28);
reading them costs at most 1.25 times boxing the members.

## Cause

The three costs of the CE profile of 2026-11-04 (the `Abs` node for a
coefficient of 1, the type check after each evaluation, the facts of an
unfrozen union) were removed before 0.182.0 (`e029bb575`); the witness above
was measured after them. A profile of 2026-11-08 on CE main `7650d9bbd`
(source, unminified) splits the route WITHOUT the workaround: element reads
about 640 ms, `latex` of the elements about 600 ms, `json` 5 ms. The `latex`
cost was the serializer: it split each `Multiply(1/8, |…|)` into a
numerator and a denominator, which gave the same product back, and it read
the type of every node to find a dictionary. The CE-1018 commit of
2026-11-08 removes both: `latex` of the 1 000 elements takes about 50 ms.
Both routes write LaTeX, so both are faster. The instrument, run with CE
from source (box lock, load 1.5): before, 377 ms with the route and
1 422 ms without (3.8×); after, 194 ms and 985 ms (5.1×).

What remains is the element read: each element is a four-term symbolic sum,
and its read evaluates about 21 operators with `x` free; each one builds a
node and derives its type. Boxing a member is one canonicalization. The
2026-11-05 measurement found no evaluated form under 2×.

## Options

(a) Close CE-1018 with the `latex` speed-up. Tycho keeps
`literalCarrierFamily()`, which it keeps in any case for two literal lists
of different lengths. Example: the witness stays at about 5× on the source
tree; the values do not change.

(b) Change the contract of `each()` on an evaluated broadcast: an element is
the canonical member until the caller evaluates it. Example: element 1 is
read as the boxed member `\sum_{n=0}^{3} 2^{-n}|\sin(2^n x + 1/1000)|`, not
as the evaluated four-term `Add`. This reverses the owner decision of
2026-10-28 and changes a documented contract.

(c) Keep CE-1018 open as a general speed-up of the typing of new nodes in
symbolic arithmetic (size L). No measured design reaches 1.25×.

If nothing is decided, the item stays `needs-decision`, Tycho keeps its
route, and no value changes.

Recommendation: (a). The owner kept the evaluated elements twice (2026-10-28,
2026-11-05), and (c) has no design that reaches the limit.

## CE answer

CE (2026-11-08): the `latex` part of the cost is fixed on CE main (not
released); the element read needs a decision of the board, options above.
Workaround: keep `literalCarrierFamily()`.
