A function that assigns one of its own variables is refused with a `scope` effect error when the variable comes from a nested pattern or is assigned by a local function.

## Witness

```
function f() { let (a, (b, c)) = (1, (2, 3)); b = 5; b }
f()
```

Gives `f()` with an `incompatible-type` diagnostic ("writes outside a
function require a declared `scope` effect"); the value is 5. Same for

```
function w() { let a = 1; function bump() scope { a = a + 1 }; bump(); a }
w()
```

(the value is 2). At main `43db9f4e6` and with the bound-once change.

## Cause and options

Not investigated. The effect analysis counts a write to a local of the
function's own body as a write outside the function: for a leaf of a nested
destructuring pattern, and for a write made by a local function with the
`scope` effect that the outer function calls.
