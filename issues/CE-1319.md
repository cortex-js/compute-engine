The type of a point plus a name is printed as "a number or a point", but a point plus a number is an error.

## Witness

Run on the build of rule 7 (main at
`3927b6c89ac284a5088a752718937455ac3c8a23` plus the change):

```js
ce.box(['Add', ['Tuple', 1, 2], 'y']).type;        // number | tuple<number, number>
ce.box(['Add', ['Tuple', 1, 2], 1]).evaluate();    // Error("incompatible-type", "tuple", "number")
```

A program that reaches it: `d(a) := a[1] + a[2]`, `P` a list of two points,
`Q(x) := d(P) + x`. Since rule 7, point 2, `d(P)` is the point `(4, 6)`, so
`Q(1)` is that error, and the type of the call is
`number | tuple<number, number>`.

A second case of a type that does not hold the value, as the implementer
reported it (through the internal `deriveApplicationType`, not run again):
with `h := p ↦ p[1] + p[2]`, an argument typed `matrix<2x2> | missing`
gives the result type `vector<2>`, and `h(Missing)` evaluates to `NaN`. The
`missing` arm of the argument is dropped where the parameter binds the
argument whole.

## Cause and options

The type of `Add` with a tuple operand and an operand of unknown type joins
the type for a number operand (`number`) with the type for a tuple operand,
although a tuple plus a number has no value. Options: give the `error` type
when one operand is a tuple and the other is known to be a number, and leave
the join for an unknown operand; or document the type as an upper bound.

## New evidence (2026-11-21)

A `plausible` witness from the Tycho Document port (session tycho-35, test
recursion-point-base-case, Desmos state neyret/dnz1jlbvnn): with an untyped
point `u`, `u + (1, 2)` is typed `number | tuple<number, number>` (checked on
`a98bb597a`). In that document, a helper `d(P)` is called as `d(P ± (e, 0))`,
so its advisory `callSiteTypes` is `number | tuple<number, number>` instead of
the point type, and feeding it back as `d`'s formal type leaves the recursive
`P` at `-> unknown`. The impossible `number` arm makes call-site evidence
useless for point helpers. Tycho works around it by stating the point type
(`formalTypes` or `resultType`). The board may want to raise the witness to
`plausible` and the probability.
