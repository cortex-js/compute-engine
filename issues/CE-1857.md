The editor shows the summary of nine library functions cut in the middle of a sentence, such as "WithRandomSeed(seed, body): evaluate `body` with a random seed frame".

## Witness

The signature help of `withRandomSeed(▮` (`epsilSignatureHelp()`) has as its
`documentation` the first element of the description array only, which
ends mid-sentence. The same holds for `arbitraryConstant`,
`arbitraryInteger`, `solve`, `findRoot`, `replaceAll` and three others:
9 of the 65 library descriptions written over several array elements have
a first element that does not end a sentence (measured at
e20d18bbd4c5e402dc4e6dfc1a446dfa18c3fb04). The library wraps descriptions
at about 72 columns by convention (`library/core.ts`, the comment at
`FindRoot`).

## Cause and options

`src/epsil/signature-help.ts` (about line 324), `src/epsil/completion.ts`
(about lines 5346 and 5502) and `summary()` in
`scripts/library-docs-shared.ts` read `description[0]`. The reference
generator joins lines up to one that ends in `.`, `:`, `!`, `?` or `)`
(`paragraphs()` in `scripts/build-library-reference.ts`). Use the same
rule for the summary: the first paragraph, not the first element. Size S.
