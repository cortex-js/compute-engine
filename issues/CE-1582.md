The nightly compiler comparison flags missing draw-order warnings for draws that the program cannot reach.

## Witness

Run `CE_NIGHTLY=1 CE_FULL_SUITE=1 npx jest -w 2 --runTestsByPath test/compute-engine/ir-slice-random.test.ts`.
The seeded 5,000-case run reports two entries in `missingWarnings`.
The first has two raw `Random` nodes, including one behind
`Which(Equal(2, -1), …)`. The second puts all three `Random` nodes inside
`WithRandomSeed` behind `Which(Not(LessEqual(ExponentialE, Pi)), …)`.
The exact parent and candidate report the same witnesses, zero differences
with compiler passes on versus off, and no unclassified disagreements.

## Cause and options

The test counts operator spellings in raw MathJSON. The compiler reports the
draw sites that survive boxing and IR lowering. Check the warning contract
with focused reachable and unreachable examples, and keep the seeded run for
compiler/interpreter comparisons and aggregate warning coverage. No runtime
defect has been observed in these two programs.
