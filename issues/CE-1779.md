A product with a power to a negative symbolic exponent, written as LaTeX and read back, is a quotient, not the same expression.

## Witness

```ts
const ce = new ComputeEngine();
const e = ce.parse('|x|\\cdot2^{-n}');
e.json;                       // ["Multiply", ["Abs", "x"], ["Power", 2, ["Negate", "n"]]]
e.latex;                      // \frac{\vert x\vert}{2^{n}}
ce.parse(e.latex).json;       // ["Divide", ["Abs", "x"], ["Power", 2, "n"]]
ce.parse(e.latex).isSame(e);  // false
```

Main at `bd0a49f4b881a541240baca05b4efb1104f048e3`. The value is the same. The
MathJSON round trip holds (`ce.box(e.toMathJson()).isSame(e)` is `true`).
With a numeric exponent the two forms agree: `\frac{1}{2}e^{w}` reads back as
itself. The review checklist asks that a serializer change pass both round
trips (`docs/REVIEW-CHECKLIST.md`, "Verify a serializer change by a round trip
on canonical forms"), so a test of such a product cannot check the LaTeX
round trip today.

## Cause and options

Not traced. The LaTeX serializer of `Multiply` writes the power with the
exponent `Negate(n)` as a denominator, and the canonical form of
`Divide(a, 2^n)` keeps the quotient, while the canonical form of the parsed
`|x|\cdot2^{-n}` keeps the product. Options: (a) canonicalize
`Divide(a, b^n)` with a symbolic `n` to `Multiply(a, b^{-n})`; (b) write `Power(b, Negate(n))` in a product as `b^{-n}`, not as a
denominator. (a) changes the canonical form of every such quotient and many
snapshots; (b) changes the LaTeX of such products. Measure the snapshot count
of each before choosing.
