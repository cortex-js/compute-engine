A LaTeX declaration written with the characters `:=` after `let` gets an extra `invalid-type` error statement.

## Witness

```
ce.parse('\\mathrm{let} c := 5; c').json
// ["Block", ["Declare", "c", "'unknown'", 5], ["Error", "'invalid-type'", "''"], "c"]
ce.parse('\\mathrm{let} c \\coloneq 5; c').json
// ["Block", ["Declare", "c", "'unknown'", 5], "c"]
```

At `022fde7f4e06adeba3e7c99d0d278626dcfd641a`. The same with `\operatorname{let}`
and with a space command after the keyword.

## What it must give

The block of the second line: `:=` and `\coloneq` are the same assignment
everywhere else.

## Cause and options

Not investigated. The `:` of `:=` is probably read as the colon of a type
annotation with an empty type, and the declaration is then parsed again.
Workaround: write `\coloneq`.
