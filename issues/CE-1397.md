The JavaScript compiler writes the square of a square root of a sum without parentheses, so `1 - \sqrt{x^2+y^2}^2` compiles to `1 - x² + y²`.

## Witness

At `202902d99`, default options, default precision (the same at
`ce.precision = 'machine'`):

```ts
const e = ce.parse('1-\\sqrt{x^2+y^2}^2');
// ["Add", ["Negate", ["Power", ["Sqrt", ["Add", ["Power", "x", 2], ["Power", "y", 2]]], 2]], 1]
e.subs({ x: 0.5, y: 0.25 }).N();                     // 0.6875
compile(e).code;                                      // -(_.x * _.x) + (_.y * _.y) + 1
compile(e).run({ x: 0.5, y: 0.25 });                  // 0.8125
compile(e, { profile: 'ir' }).run({ x: 0.5, y: 0.25 }); // 0.6875
compile(e, { to: 'glsl' }).code;                      // -_gpu_pow2(sqrt((x * x) + (y * y))) + 1.0
compile(e, { to: 'interval-js' }).run({ x: { lo: 0.5, hi: 0.5 }, y: { lo: 0.25, hi: 0.25 } });
                                                      // [0.68749…98, 0.68750…03], also with profile: 'ir'

const m = ce.parse('2\\sqrt{x^2+1}^2');
compile(m).code;                                      // 2 * (_.x * _.x) + 1
compile(m).run({ x: 0.5 });                           // 1.5; the interpreter gives 2.5
```

Corpus: `neyret/h3k6mi4qfo` program 8, a region
`Floor(11 · Which(r ≤ 1, 0.58·(a + b + Sqrt(1 - Sqrt(a² + b²)²)), True, 0.8)) ≤ 8`
with `a = Floor(31x)/31`, `b = Floor(31y)/31`. At `x = -0.443, y = 0.810` the
interpreter gives `True`, both interval targets `'true'`, and the JavaScript
code `false`: it computes `Math.sqrt(-a² + b² + 1)`. The sweep of the
interval targets reported this program as a miss of the interval targets;
the interval value is right.

## Impact

A wrong finite value with no error, for inputs of their declared types, on
the JavaScript target with the existing compiler. It needs `Sqrt(X)^n` with
an even `n`, a radicand `X` that the compiler proves non-negative and
whose code is an infix expression (a sum of squares, `x² + 1`), and a
parent that writes its operand with an infix operator (`Negate`, `Multiply`).
`Sqrt(x² + y²)²` is how a squared distance is written by hand. The profile
`ir`, GLSL and both interval targets give the right value.

## Cause and options

`realRadicalPower()` in `src/compute-engine/compilation/javascript-target.ts`
reduces `Sqrt(X)^2` to `X` when `BaseCompiler.assumedRealNonNegative(X)`,
and returns `compile(radicand)` (the line `if (e === 1) return
compile(radicand);`) with no parentheses. The parent chose its parentheses
from the operator `Power`, so `Negate` (the operator table entry
`['-', 14]`) and `Multiply` (`nonOne.map(compile).join(' * ')`) splice the
bare sum. Same family as CE-1196 and CE-1224 (a handler that returns an
infix expression where its parent expects a primary).

Option: return `(${compile(radicand)})` there. The other returns of the
function are calls or are already parenthesized. Check with the witness
above and `Multiply(a, Sqrt(a² + 1)²)`.
