A series of `GammaLn(x)` at −1 or at −3 is off by πi for values of the variable above the point.

## Witness

At commit `4d9da3765bd5982bd8f48316d2d76171ca2c3554` with the fix of CE-1442, the value is `f − Normal(Series(f))`:

```
Series(GammaLn(x), x, -1, 2)   // −ln(x + 1) + ln(−1) + (1 − γ)(x + 1) + …
                               // x = −1.01: 7e-8;  x = −0.99: −6e-8 − πi
Series(GammaLn(x), x, -3, 2)   // −ln(x + 3) + ln(−1/6) + …
                               // x = −3.01: 2e-8;  x = −2.99: −8e-9 − πi
```

`Series(Ln(Gamma(x)), x, -1, 2)` gives the same series, and it is right on both sides for `Ln(Gamma(x))`.

## Cause and options

`symbolic/series.ts`, `expandLaurent()`, case `GammaLn`: at a pole of Γ at a finite point it expands `ln(Γ(u))` with `lnLaurent()`. `GammaLn(x)` evaluates to `ln|Γ(x)|` for a negative real `x` (`GammaLn(-0.5)` is `1.2655…`, `Ln(Gamma(-0.5))` is `1.2655… + πi`), so the two differ by `πi` where `Γ(x) < 0`. At 0 and at −2 the fix of CE-1442 makes `lnLaurent()` decline, so the `Series` stays unevaluated there. Option (simple, sound): the `GammaLn` case returns `null` at a finite pole when `bothSides` is set, because `ln|Γ(x)|` has no series in `ln(x − x0)` that holds on both sides. The expansion at +∞ (Stirling) is not changed.
