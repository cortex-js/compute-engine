A string conversion with a format name it does not know gives the plain text of the number instead of an error.

## Witness

```
StringFrom(65, "bogus")   // "65", where an unknown format must be an error
```

Measured at 074e6347f39717e4f6d5b44521c5c459b6d9d2b7.

## Cause and options

The end of the `evaluate` handler of `StringFrom` (`src/compute-engine/library/core.ts`) falls through to the printed form when no format matches. Give an `expected-value` error naming the formats it accepts, as `ColorToString` does for an unknown format.
