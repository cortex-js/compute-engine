Go to Definition and Rename miss recursive calls in a function selected by an initializer.

## Witness

```epsil
let f = if true {
  (n) => if n == 0 { 1 } else { n * f(n - 1) }
} else { (n) => 0 }
f(3)
```

On a fresh engine this gives `6` with no diagnostics. Go to Definition on
`f(n - 1)` gives no result, and renaming the declaration leaves that call
unchanged.

## Cause and options

`visibleBinding()` in `src/epsil/occurrences.ts` walks a non-function
initializer in the enclosing scope. In engine mode it falls back to the
initializer's own declaration if no outer binding exists. Editor lookup
needs the same fallback for a deferred nested function, with knowledge of
host and library bindings so that they keep precedence.
