A function that uses a variable declared below it gets the library function of the same name instead of the variable.

## Witness

On main `39ffe2d9a71016554c924475f29f82ed35a66538`, with `executeEpsil()` on
a new engine:

```
let h = () => mean([1, 3])
let mean = (x) => 7
h()
```

gives `2`. It must give `7`: the `let` of a program binds its name in the
whole program, and a function body above the statement reads that binding
(`docs/plans/2026-11-12-program-operator-spec.md`, P4). With a name that the
library does not have (`let h = () => m([1, 3])`, `let m = (x) => 7`) the
value is `7`. In the same way, `function g() { mean }`, `let mean = 7`, `g()`
gives `Mean` and must give `7`.

In the editor, a rename of the `let` does not rewrite the name in the function
body above it, for any name.

## Cause and options

`resolveLibraryNames()` (`src/epsil/resolve-library-names.ts`) rewrites each
free occurrence of a library spelling to the library name before the program
is boxed. It takes "free" from `documentBindings()`
(`src/epsil/occurrences.ts`), whose default model makes a `let` visible only
after its statement, so the occurrence in the body above is free and becomes
`Mean`.

`documentBindings()` has the rules of the interpreter under its `engineRules`
option (CE-1628): a `let` binds its name in its whole block, except in its
own initializer. Option (a), recommended: `resolveLibraryNames()` passes the
option, with `defined` as in `epsilProgramSites()`
(`src/epsil/program-sites.ts`). To check: under the option an assignment
never declares, which changes what `isBound` answers to `binderSitesOf()`.
`epsilProgramSites()` reports such an occurrence as `library`, as the
interpreter runs it: it walks the program a second time without the option
and gives the result as `engineRules.library`. The fix removes that second
walk and changes the test "a library spelling that the interpreter rewrites
is `library`" of `test/epsil/program-sites.test.ts`.
Option (b): the editor callers (`hover.ts`, `completion.ts`,
`static-diagnostics.ts`) take the option too, which also corrects the rename;
it changes the pinned occurrences of `test/epsil/occurrences.test.ts`.
