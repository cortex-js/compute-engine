In Epsil, an error in a subtraction whose other side holds a sum underlines a variable of that sum.

## Witness

```
let s: any = "a"
let y = 5
let v = Sqrt(y + 2) - s
frames     ->  Add argument 1
underline  ->  y          expected: s
```

## Cause and options

The canonical form of `a - b` is an `Add`, so the frame names `Add`.
`findWrittenCalls()` (`src/epsil/error-location.ts`) looks for a written
subtraction only when the statement has no written `+`. Here it finds the
`y + 2` inside `Sqrt`, and the frame selects its operand `y`. Option: for an
`Add` frame, collect the written `+` and `-` calls together, and treat the
frame as ambiguous when there is more than one cluster of them.
