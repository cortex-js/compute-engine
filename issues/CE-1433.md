A limit written with its variable and its point is wrong when the formula is held in a variable: `let G = sin(x); limit(G + 0, x, 0)` gives `x`.

## Witness

At d476bcce3fe25ae621a30965bd60d0cf8ed3a322, Epsil:

```
let G = sin(x); limit(G, x, 0)       lim_(x -> x) G(x)    (must be 0)
let G = sin(x); limit(G + 0, x, 0)   x                    (must be 0)
limit(sin(x), x, 0)                  0
```

The same with `ce.assign('G', ce.box(['Sin', 'x']))` and
`ce.box(['Limit', 'G', 'x', 0])`. The LaTeX form `\lim_{x\to 0} G` gives `0`
after CE-1375.

## Cause and options

The `canonical` handler of `Limit` (`library/calculus.ts`) reads
`Limit(f, x, a)` as the form with a variable only when `f` contains `x` by
syntax (`f.canonical.has(x.symbol)`). `G` does not, so the handler reads the
form as `Limit(f, point, direction)`: the variable is chosen from the symbols
of `f` (`G`), the point is `x` and the direction is `0`.

Options:

- (a) Read `Limit(f, x, a)` with a symbol `x` as the form with a variable
  whenever `f` is not a function literal. A two-operand `Limit(f, point)` and
  a function literal keep their reading. Check first which callers write a
  three-operand `Limit(f, point, direction)` with a symbol point.
- (b) Also count a symbol of `f` that holds a formula in `x` (the rule of
  CE-1375). This makes the canonical form depend on the values assigned at
  boxing.
