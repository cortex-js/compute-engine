The Riemann zeta function at −0.5 is about 4 units in the last place off at machine precision.

## Witness

```
Zeta(-0.5).N() at machine precision   gives -0.20788622497735468
the 50-digit value                    -0.207886224977354566017306725397...
```

## Cause and options

The nightly test `test/compute-engine/nightly/mpmath-kernels.test.ts` relaxes
the tolerance of the case `zeta_m_-0.5` to 6 ulp. Impact `minor`: only the
last digits differ. Find the machine-precision method of `Zeta` for negative
non-integer arguments and the step that loses the digits; then restore the
default tolerance. The other parts
of the old entry: CE-968 (two tests that pin an inaccuracy the engine no
longer has).
