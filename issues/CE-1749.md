In Epsil, the message of an error in a product or a sum that is the second operand of a subtraction names a sum or a negation that the program does not contain.

## Witness

```
let w: any = "s"
let v = 3 - 2*ln(w)      ->  "in Ln argument 1, in Multiply argument 2, in Add argument 1"
expected                 ->  "in Ln argument 1, in Multiply argument 2, in Subtract argument 2"
let v = 1 - (2 + ln(w))  ->  "in Ln argument 1, in Negate argument 1, in Add argument 1"
expected                 ->  "in Ln argument 1, in Subtract argument 2" (or with "in Add argument 2" before it)
```

The underline is `w`, which is correct.

## Cause and options

The canonical form of `3 - 2*ln(w)` is `Add(Multiply(-2, Ln(w)), 3)`: the
negation is folded into the coefficient, so no `Negate` frame is recorded, and
the frame `Add argument 1` names the canonical sum. The canonical form of
`1 - (2 + ln(w))` distributes the negation over the inner sum, so the
`Negate` frame is made from `ln(w)`, not from the written subtrahend.
`subtractionFrames()` (`src/epsil/error-location.ts`) changes only the pair
`Negate argument 1, Add argument k` whose canonical operand `k` was made from
the written subtrahend (CE-1717). Option: change an `Add argument k` frame
into `Subtract argument 2` when the canonical operand `k` has the source range
of the subtrahend of one written subtraction, also without a `Negate` frame
before it, and drop a `Negate` frame whose operand is inside that subtrahend.
