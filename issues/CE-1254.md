Compiled code runs a function declared pure with `let` whose body draws a random number, where the interpreter refuses it.

## Witness

In a block that is compiled: `let g: (integer) pure -> real = (k) => Random()`
then a call of `g`. The compiled code returns a number; the interpreter
refuses the declaration because the body has an effect that the declared
type excludes. Reported at worktree commit `3f4152e06` (the bound-once
work on main `dc51affd4`) as existing before that work; not reproduced on
main by the filer.

## Cause and options

`refuseEffectContractViolations()` in the compiler checks a
`DefineFunction` and an `Assign`, not a `Declare` with an initial value.
Fix: check the `Declare` too, or decline.
