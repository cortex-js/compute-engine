An Epsil function called before a variable it reads is declared gives a string on the runner and an error in a block.

## Witness

```epsil
let a = String(g())
let c = 2
function g() { c^2 }
```

The Epsil runner gives `a = "c^2"`; the block route gives
`read-before-declaration` (measured 2026-10-21).

## Cause and options

The top level of the runner has no "declared, not yet initialized" state for a
variable, so the read of `c` stays symbolic. Fix: give the runner that state,
so that both routes give `read-before-declaration`. Plan:
`docs/plans/2026-10-21-function-declaration-hoisting.md`.
