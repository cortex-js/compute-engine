A predicate written with `===` (structural identity) is always false inside `any`, `filter` and `find`, so `any([1, 2, 3], e => e === 2)` is False.

## Witness

Epsil CLI, main a28dd290f:

| program | prints | must print |
| --- | --- | --- |
| `any([1, 2, 3], e => e === 2)` | `False` | `True` |
| `any([1, 2, 3], e => isSame(e, 2))` | `False` | `True` |
| `filter([1, 2, 3], e => e === 2)` | `[]` | `[2]` |
| `find([1, 2, 3], e => e === 2)` | `NaN` | `2` |
| `map(e => e === 2, [1, 2, 3])` | `[False, True, False]` | (right) |
| `any([1, 2, 3], e => e == 2)` | `True` | (right) |

In MathJSON, `Any([1, 2, 3], Function(IsSame(e, 2), e))` is False and
`Filter([1, 2, 3], Function(IsSame(e, 2), e))` stays unevaluated. The
descriptions of `Contains` and `Any` (`library/collections.ts`, lines 13893
and 14315) give `Any(xs, (e) => e === v)` as the equivalent of
`Contains(xs, v)`, so the reference shows the wrong identity.

## Cause

Investigated at main `d6c0e759ef9b0c9021c3fc5f079f30e8dac0dd3a` by
`cebatch-1381`. The selection route is not the cause. `Same` (`===`) and
`IsSame` are `lazy` and never read the value of a symbol
(`library/relational-operator.ts`, the comments of `IsSame` and `Same`). An
application of a function literal binds the parameter in an activation and
evaluates the body there (`makeLambda()`, `function-utils.ts`), so `Same`
compares the symbol `e` with `2`. Every route that applies a literal gives
the same answer:

| program | gives |
| --- | --- |
| `let f = (e) => e === 2; f(2)` | `False` |
| `Apply(Function(Same(e, 2), e), 2)` | `False` |
| `for x in [1, 2, 3] { if x === 2 { n = n + 1 } }` | `n` stays `0` |
| `Map(e => If(Same(e, 2), 1, 0), [1, 2, 3])` | `[0, 0, 0]` |
| `Map(e => Same(e, 2), [1, 2, 3])` | `[False, True, False]` |
| `Map((e, f) => Same(e, f), [1, 2], [1, 2])` | `[True, True]` |
| `Apply(Function(Same(e, f), e, f), 2, 2)` | `False` |
| `Apply(Function(Hold(e), e), 2)` | `Hold(2)` |

The only exception is a `Map` whose body is one broadcast-shaped call: the
broadcast-chain lowering (`lowerMapSpine()`, `map-lowering.ts`, used by
`mapIteratorImpl()`) applies the operator to the element itself, so `Same`
sees `2`. That path must give the values of the general path, and it does not.

So the False of the witness is the behavior that the documents state:
`src/epsil/docs/reference/core.md` ("`===` ... never reads the value of a
name", with `let x = 5; (x == 5, x === 5)` ➔ `(True, False)`) and
`docs/EPSIL-LANGUAGE-MODEL.md` ("`Same` / `===` is structural and never
follows a symbol value"). The descriptions of `Contains` and `Any`
(`library/collections.ts`) state the opposite for a parameter
(`Contains(xs, v)` is `Any(xs, (e) => e === v)`). A fix in either direction
changes one of these documented statements, so the board must choose.

## Options

(a) **A parameter denotes its argument for `===` (recommended).** A name that
a call or an iteration binds (a function parameter, a binder variable of
`Sum`/`Product`/a comprehension, a `for` variable) is compared by the value it
is bound to; a name that is declared or assigned (`let`, a global, an
assigned variable) is still not read. Then `any([1, 2, 3], e => e === 2)` is
`True`, `filter([1, 2, 3], e => e === 2)` is `[2]`, `f(2)` above is `True`,
the `for` loop counts `1`, and `let x = 5; x === 5` stays `False`. This is the
substitution reading of an application, which `Hold(e)` already follows
(`Hold(2)` above) and which the `Contains`/`Any` descriptions assume. Cost (an estimate):
`Same` and `IsSame` replace each activation-bound symbol of their operands by
its value before they compare (one walk of the operands, about 30 lines of
`src/`), and the two documents above get one sentence each about parameters.
The broadcast lowering of `Map` then agrees.

(b) **Keep the rule: `===` never reads any name, parameters included.** Then
the witness is right as it is: `filter(xs, e => e === 2)` is `[]` for every
`xs`, and `===` cannot be used in a predicate. The fix is: the broadcast
lowering of `Map` declines a body with `Same` or `IsSame` (so
`Map(e => Same(e, 2), [1, 2, 3])` becomes `[False, False, False]`), and the
`Contains`/`Any` descriptions stop naming `Any(xs, (e) => e === v)`. Cost (an estimate):
about 5 lines of `src/`; a program that uses `===` in a predicate must use
`==`, which compares within the tolerance and can stay unevaluated.

Recommendation: (a). A predicate is the main use of `===` over data, and (b)
makes it always false with no diagnostic.

## Decision

User decision 2026-11-17: (a)
