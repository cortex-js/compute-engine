A function that takes a list and returns a list (one step of the Game of Life) cannot be compiled, so an animation that steps it runs about a hundred times slower than it could.

## Witness

On 0.195.1, with the program of the instrument (a 32 × 32 grid of 0 and 1;
`count`, `nextCell` and `step` declared with `g: list<list<integer>>`,
`i: integer`, `j: integer`):

```
A  compile((g: list<list<integer>>) => step(g))
   → declined: "Could not compile: g: the input g of type list<list<integer>>"
B  compile(step(animState)), animState declared list<list<integer>>
   → declined: "Could not compile: Function(Block(Map(…))): the result of
     step is not a scalar (list<list<integer>>)"
interpreted: one generation of 32 × 32, 611 ms
```

Control: the same program, given to the MCP `compile` tool on 0.193.0 as one
Epsil program ending in `step(grid)` with `grid` declared
`list<list<integer>>`, compiles: the user functions become JavaScript
functions, `map` becomes `Array.map`, and the result is an array of arrays.
So the compiler can emit the body; what declines is the route a host has:
a lambda with a list parameter (A), and a call of a user function whose
result is a list (B).

Expected: A or B compiles to a runner that takes a nested JavaScript array
(`run(a)` for A, `run({ animState: a })` for B) and returns a nested array,
with the same values as the interpreter for integer inputs.

## Cause and options

Unverified. A: the lambda route seems to accept only scalar (or flat real
list) parameters. B: the call route requires a scalar result of the callee.
Options: (a) accept a parameter and a result of a declared list type on the
lambda route (A), which is the form a host gets from a function value;
(b) accept a list result on the call route (B). (a) is the one Tycho needs:
`animate(init, step, render)` receives `step` as a function value.

Tycho half on adoption: `animate` compiles `step` on route A and falls back to
the interpreter when CE declines (the same rule as `bitmap(f, …)` today); the
instrument then prints `compiled` and the time of 100 generations, and the
fallback warning disappears for this example.

## Code

The declines are in `src/compute-engine/compilation/ir/lower.ts` and `src/compute-engine/compilation/ir/lower-functions.ts`.
