The inverse of a singular matrix that has both exact entries (a fraction, `i`) and decimal entries gives huge numbers instead of saying that the matrix has no inverse.

## Witness

At commit `0bebdaee7b63afd440151e05c12684ab9151765c`. In each matrix, row 3 = row 1 + row 2.

```
Inverse([[1/3, 2.5, 1], [1, 1, 1], [4/3, 3.5, 2]])
  evaluate()   // entries of about 3.5e20
  N()          // entries of about 3.6e20
Inverse([[i, 2.5, 1], [1, 1, 1], [1 + i, 3.5, 2]]).evaluate()
               // entries of about 1.5e20 + 3.6e20i; N() stays unevaluated, which is right
```

Each must stay unevaluated, as `Inverse([[3, 2, 1], [1, 1, 1], [4, 3, 2]])`
does. `PseudoInverse` and `MatrixPower` with a negative exponent call the same
code.

## Cause and options

A matrix of machine numbers takes a kernel that tests each pivot relative to
the magnitude of the entries: `numberMatrixInverse()` for the `float64` dtype
(CE-1542) and `complexMatrixInverse()` for `complex128` (CE-1803). A matrix
of another dtype (`expression`) takes the generic elimination of
`AbstractTensor.inverse()`, which tests a pivot for an exact 0
(`field.isZero`): an inexact entry leaves a rounding residue in place of the
0. The witnesses show which matrices take it: one with an exact entry that is
not real next to a decimal entry, and one with a fraction next to a decimal
entry (its `N()` has entries of 21 digits, so the cells are not machine
numbers). Not checked: which rule of `tensor-fields.ts` gives each dtype.

Options:

1. In the generic elimination, when every entry is a number and one is
   inexact, use partial pivoting and the relative test of the two kernels,
   with the magnitude of each entry (the `magnitude()` helper of
   `determinant()` in the same file gives it). The threshold must follow the
   working precision. Size M.
2. For such a matrix, call a machine kernel first, only as the test of a
   singular matrix, and keep the generic elimination for the value. A matrix
   that is regular at the working precision and singular in doubles then stays
   unevaluated. Size S.
