A matrix to a symbolic power, `A ^ n`, is computed entry by entry, which is wrong once `n` is an integer.

## Witness

Epsil CLI, main 6be5b5f52: `[[1, 2], [3, 4]] ^ n` prints
`[[1, 2^n], [3^n, 4^n]]`. With `n = 2` that form is `[[1, 4], [9, 16]]`, while
`let n = 2; [[1, 2], [3, 4]] ^ n` prints the matrix power `[[7, 10], [15, 22]]`.

`docs/BROADCAST-MODEL.md` (around line 447): an integer power of a matrix is
the matrix power, and a power whose exponent is not an integer applies to
each entry (`[[4, 9], [16, 25]]^{1/2}` is `[[2, 3], [4, 5]]`); that
`^ (1/2)` and `^ 2.5` apply to each entry is therefore intended. A symbol
whose integer-ness is not known is neither case.

## Cause and options

Fix: a power of a matrix whose exponent is not known to be an integer or a
non-integer stays as it is (`Power(A, n)`), and evaluates when `n` gets a
value. Check `MatrixPower(A, n)` too, which stays as it is today.
