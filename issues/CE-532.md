Tycho must use private fields of the engine to give symbols temporary values while it reads point coordinates.

## Witness

Tycho's `withValuelessVariablesBound()`
(`~/dev/tycho/src/plot-core/list-materialize.ts`) assigns values to document
symbols and restores them by reading `storedValue`, `_placeholderSkeleton` and
`_signatureSkeleton`. It cannot restore a type that `assign` changed. The
public `ce.checkpoint()`/`ce.restore()` copy the whole engine and throw during
an evaluation.

## Cause and options

Question: approve or delete the proposed API (no approval is recorded).

Proposal: `ce.withValues(values, fn)` pushes a scope, declares each name in it
with the given value and the declared type of the visible binding (as the
internal `withValueShield()` does for valueless names), runs `fn`, and pops
the scope in a `finally`. The outer definition is never written, so nothing is
restored. An expression created inside `fn` must not be kept after `fn`
returns.

Recommended: approve. If not decided, Tycho keeps reading private fields,
which can change in any release.
