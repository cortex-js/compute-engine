Tycho needs a fragile workaround to give symbols temporary values while it reads point coordinates.

## Witness

Tycho's `withValuelessVariablesBound()`
(`~/dev/tycho/src/plot-core/list-materialize.ts`) assigns values inside
`ce.checkpoint()` and `ce.restore()`. The checkpoint copies the whole engine
and is refused during an evaluation, so the binding is then skipped; a failed
restore falls back to the `value` setter. Reading on 0.182.0: `CE-532: NOT
READY on 0.182.0 (ce.withValues does not exist)`.

Tycho half on adoption: replace the checkpoint code of
`withValuelessVariablesBound()` with `ce.withValues()`.

## Cause and options

Proposal: `ce.withValues(values, fn)` pushes a scope, declares each name in it
with the given value and the declared type of the visible binding (as the
internal `withValueShield()` does for valueless names), runs `fn`, and pops
the scope in a `finally`. The outer definition is never written, so nothing is
restored. An expression created inside `fn` must not be kept after `fn`
returns.

## Decision

User decision 2026-11-06: approved: add ce.withValues(values, fn) as proposed.
