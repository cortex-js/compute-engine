The difference of two arrays of three dimensions is not computed: the result is the unevaluated sum of the two arrays.

## Witness

At `bc382309d8b9f6052bf6e12757ec18637a917020`:

```ts
const ce = new ComputeEngine();
ce.declare('T', 'tensor<real^(2x2x2)>');
const T = ce.box(['List', ['List', ['List', 1, 2], ['List', 3, 4]],
                          ['List', ['List', 5, 6], ['List', 7, 8]]]);
ce.withValues({ T }, () => ce.box(['Subtract', 'T', 'T']).evaluate().json);
// ["Add", <the list T>, <the list of its negated elements>], unevaluated;
// expected the 2x2x2 array of zeros.
ce.withValues({ T }, () => ce.box(['Add', 'T', 'T']).evaluate().json);
// [[[2,4],[6,8]],[[10,12],[14,16]]]: the sum is computed.
```

The difference of two 2x2 matrices (`M - N`) is computed. The compiled code
of the profile `ir` gives the array of zeros.

## Cause and options

Not investigated. The operand `Negate(T)` evaluates to a list of rank 3 of
negative numbers, and the `Add` of that list with `T` stays unevaluated,
while `Add(T, T)` evaluates.
