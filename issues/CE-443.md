A pure function nested nine or more levels deep is reported as a function that can have any side effect.

## Witness

A pure function literal with 9 nested function literals is typed
`(unknown) any -> …`: its effects are `any`.

## Cause and options

The effects walker stops at a depth of 8 nested function literals
(`MAX_LITERAL_DEPTH`, `boxed-expression/effects-inference.ts`) and answers
`any`. This is the safe direction, but it loses precision. A fix needs a
design choice: the nested walk shares its confinement state with the enclosing
literal.
