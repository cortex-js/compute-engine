A thin space or another visual space at the start of an expression, before a plus or a minus sign that a symbol or a fraction follows, gives an error: `x = \, -b` is `x == -b + Error(…)`.

## Witness

Readings of 2026-11-08, on `246428a205e3b3ce594b6bfdd20734c5fcaee499` with the
CE-1170 fix applied (the fix does not change these readings), with
`ce.parse(latex, { canonical: false }).json` and `ce.parse(latex).toString()`:

```
\,-b             Subtract(HorizontalSpacing(3), b)               -b + Error(ErrorCode("incompatible-type", "number", "nothing"), "Nothing")
x=\,-b           Equal(x, Subtract(HorizontalSpacing(3), b))     x == -b + Error(…)
a+\,-b           Add(a, Subtract(HorizontalSpacing(3), b))       a - b + Error(…)
\sqrt{\,-b}      Sqrt(Subtract(HorizontalSpacing(3), b))         sqrt(-b + Error(…))
\,-\frac{1}{2}   Subtract(HorizontalSpacing(3), Divide(1, 2))    Error(…) - 1/2
\,\times b       Multiply(HorizontalSpacing(3), b)               Error(…) * b
x=\,-1           Equal(x, -1)                                    x == -1    (correct: a number follows the sign)
(\,-b)           Delimiter(Negate(b))                            -b         (correct: the fence skips the space)
\,b              InvisibleOperator(HorizontalSpacing(3), b)      b          (correct)
x=-b             Equal(x, Negate(b))                             x == -b    (control)
```

The workaround is to remove the spacing command.

## Cause and options

`parseExpression()` (`latex-syntax/parse.ts`) looks for a prefix operator at
the spacing command and finds none. `parsePrimary()` then reads the spacing
command as a `HorizontalSpacing` operand, and the infix loop reads the sign
with that operand on its left. The canonical forms of `Subtract`, `Add` and
`Multiply` have no rule for a spacing operand; only the canonical form of
`InvisibleOperator` drops it. When a number follows the sign, the number
reader skips the space and reads the sign, so `\,-1` is correct.

Options:

- (a) Before `parseExpression()` looks for a prefix operator, skip visual
  space when a prefix operator follows it. The raw form of `\,-b` loses the
  spacing command, as the raw form of `\,-1` does today. Size S. Recommended.
- (b) Keep the spacing operand in the raw form, and drop it in the canonical
  forms of the arithmetic operators. This adds a rule to each operator.
