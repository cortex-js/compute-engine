Destructuring an unevaluated `svd` result fails with the message "expected `tuple`, got `tuple`", which does not say what is wrong.

## Witness

Epsil CLI, main 6be5b5f52: `let (U, S, V) = svd([[1, 2], [3, 4]])` prints
`error: Runtime error: expected \`tuple\`, got \`tuple\` at \`SVD([[1,2],[3,4]])\``.
`svd` of an exact matrix stays unevaluated (it needs `N`), so the value is not
a tuple, but its type is the declared tuple type.

## Cause and options

The message prints the type of the value where it should print that the value
is an unevaluated `SVD(...)`. Fix: when the value has the right type but is
not a tuple, say so ("`SVD(...)` did not evaluate to a tuple; an exact
matrix needs `N`").
