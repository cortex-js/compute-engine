A notebook code cell cannot show what its program prints: the text goes to the browser's developer console.

## Witness

On 0.193.0, `executeEpsil(ce, 'print("square of", 3, "is", 9)\nprint([1, 2])\n7')`
returns 7 and writes both lines with `console.log`. The host has no option to
receive them. Tycho's code cell gets a console pane that shows the output of
`print` and the value of the program, in order.

## Cause and options

Proposed: an option `onPrint(text: string)` on `ExecuteEpsilOptions` (so also
`executeEpsilAsync`); when it is given, `print` calls it and does not write to
`console.log`. The text is what `print` writes today. Workaround: Tycho replaces
`console.log` in the notebook worker for the duration of a run, which also
captures unrelated logging. Tycho half on adoption: remove that replacement.
