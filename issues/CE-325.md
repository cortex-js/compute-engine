A filter or a map that calls a named function on each element takes about 100 µs per element, so full-size Project Euler programs take about 20 s.

## Witness

```
sum(filter(2..9999, isAmicable))   → about 20 s
filter(10..50000, isCurious)       → about 20 s per walk
filter(1..20000, isEven)           → about 100 µs per application, isEven(n) = n % 2 == 0
```

CPU profile of 2026-10-07 on a loaded machine (an upper bound).

## Cause and options

For a trivial body: about a quarter is typing the body again at each call (the
parameter declaration advances the `any` axis, and `BoxedFunction.type` keys on
it; `skipBroadcastForVectorOps` reads the type through `isTextAtom`); a quarter
is boxing the application again; an eighth is `declareSymbolValue`; and the
application memo serializes each argument to JSON. An inline arithmetic lambda
in `map` costs 7 µs (it becomes a broadcast). Option A (CE-325.1): key the
type cache of a body on the call frame (a redesign, see CE-321). A compiled
predicate for `Filter`/`Any` is CE-880.
