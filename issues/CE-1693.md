A list that is computed from local values is drawn as a curve over x and y, and the rows that read it lose their values.

## Witness

CE 0.198.0, Document API, the axes `x` and `y` declared as inputs and as
field axes. Rows (raw bodies): `d = x + y` (a field macro), `A =
Delimiter(Block(Declare(x, unknown, [1,2]), Declare(y, unknown, [3,4]), d))`,
`B = A + 1`.

`prepare` gives `d` the field parameters `["x","y"]` (correct), and also `A`
and `B`. But `A` evaluates to `["List",4,6]`: inside the Block, `d` reads the
locals `x` and `y`, so `A` reads no axis.

In Tycho the field parameters make `A`, `B` and `Length(A)` field rows: a row
that reads `A` classifies `implicit` instead of `line`, and `G = g(2)` with
`g(s) = A[1] s` gets no value in the variable pass. Stock (the host
registration before the port) gave `B = [5,7]`, `Length(A) = 2`, `G = 8`.

## Cause and options

Not investigated. Probable: the field-parameter walk follows `d` from `A`
without removing the names that the Block declares as locals before it
reads `d`.
