A plot that reads a list of random numbers with a fixed seed, whose length comes from a slider, draws nothing.

## Witness

`N: integer<1..30>`, `t: real`;
`H := WithRandomSeed(139128, RandomChoice([0, 1), 4N))` (assigned). Compile
`t + H[2]` to javascript.

0.194.3 and 0.195.1: declines, "H: the value of H, which has an effect". 0.186.0
compiled it. Control: the same draw written inline, `t + WithRandomSeed(139128,
RandomChoice([0, 1), 4N))[2]`, compiles on 0.195.1, and its value equals the
interpreter's at N = 3 and N = 5. A second shape, from `neyret/hztlhoa5ea`:
`R := Which(0.5 < WithRandomSeed(626421, RandomChoice([0, 1), N^2)), 1, True,
-1)`; `t + R[2]` declines in the same way, and its inline form compiles.

Render check (Tycho render audit, 2026-11-19, 0.186.0 against 0.194.3):
`neyret/hztlhoa5ea` (a Truchet tiling, `R` above) was drawn and is fully blank;
`neyret/cf56wfb4cm` (`H` above) lost two of its three curves and most of the
third. In the audit, 21 JavaScript rows in 6 documents decline for this cause.
7 of them draw nothing, and the others draw through a data or JavaScript band.
In each draw that the audit captured, the argument that is not a literal is a
slider that is an input of the compiled program (`N` in both documents above,
`d_iskdensity` in `art/tpalesypcc`).

## Cause and options

CE-1524 decision (a) compiles a held value of seeded draws over literals as the
interpreter's value, and declines a held draw that reads another name. Tycho
asks to extend (a) to a held draw whose arguments read only inputs of the
compiled program and literals. Then the value is a function of the inputs, and
the program reproduces it.

Options: (a) inline the held definition into the program when it is a seeded
draw whose free names are all compiled inputs, as the inline control already
compiles (recommended; the JavaScript runtime already has `WithRandomSeed`
frames, and the inline form gives the interpreter's value); (b) compile it as a
value memoized on the input values that it reads. A held draw that reads a name
that is not an input, or that calls a user function, still declines. A held
draw that is not seeded still declines.

## Decision

User decision 2026-11-20: (a)

## CE answer

CE (2026-11-20): fixed, P2 confirmed. `fixed-in` is the parent of the fix
commit, whose message starts with `CE-1614:`. A held value is lowered as
written in place, and its draws are accepted when each `WithRandomSeed` that it
holds has one draw site evaluated once (one `Random`, `RandomChoice`,
`RandomSample` or `RandomShuffle`, not in a `Map`, a `Sum` or a loop): `t +
H[2]` and `t + R[2]` compile to JavaScript with the interpreter's value at each
`N`, with no warning. The frame runs at each read of the name. Still declines
("the value of …, which has an effect"): a draw outside a `WithRandomSeed`, a
seed that is a draw, a read of a `vars` name, a call of a user function that
draws, and a `WithRandomSeed` of several draw sites or of a draw at each
element (`WithRandomSeed(5, Random() + Random())`), which written in place
compiles with the warning `seeded-draw-order` and can give other draws than the
interpreter. GLSL has no random frame and declines. A held draw that reads a
name with a literal value (`M := 5`) or calls a user function that does not
draw compiles too: the name is a dependency of the code, as for every held
value.
