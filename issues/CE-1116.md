A curve made by joining pieces cannot be offset along its own slope, because the slope of the joined curve is not computed.

## Witness

Plain engine, `a = (u, u^2)`, `b = (u, u^3)`, `c = (sin u, cos u)`:

| Input                                  | Expected        | Today (0.176.0, 0.178.0, 0.183.0) |
| -------------------------------------- | --------------- | --------------------------------- |
| `D(PointY(ListJoin(a, b)), u)`           | `[2u, 3u^2]`    | `D(…)` unevaluated                |
| `D(PointX(ListJoin(a, [b, c])), u)`      | `[1, 1, cos u]` | `D(…)` unevaluated                |
| `D(PointY(ListJoin([a], W)), u)`         | `[2u, 2, 3u^2]` | `D(…)` unevaluated                |

`W` is `Block(Declare(k, "unknown", 2), [(u, k u), (u, u^3)])`, the form of a
Desmos `with` (or `where`) binding whose value is a list of points.

Controls that work: `PointY(ListJoin(a, b))` evaluates to `[u^2, u^3]`, so
the join of single points is a list of points; the same join of one-element
lists, `D(PointY(ListJoin([a], [b])), u)`, gives `[2u, 3u^2]`;
`D(PointY(W), u)` alone gives `[2, 3u^2]`.

Corpus: the "Sorry" text of Desmos document `art/2ki2hjsouf` is a curve
`S(u) = join(piece_1, …, piece_25)`, where most pieces are single points and
four are lists. Two rows offset it along its normal with
`\frac{d}{du} S(u).y`. Desmos joins single points and lists the same way.
The derivative stays unevaluated, and Tycho draws nothing for these rows
(with CE-1115, which blocks the same derivative).

## What it must give

The derivative of a coordinate of `ListJoin(…)` is the list of the
derivatives of the coordinate of each element, in order, for arguments that
are single points, literal lists, or expressions whose value is a list (such
as a `Block`).

## Cause and options

Not traced. The derivative of `ListJoin` seems to require every argument to
be a literal list. Option: apply the same flattening that `evaluate()` uses (a
single point is one element, a list-valued argument gives its elements)
before differentiating, or differentiate the evaluated join when it is a
list.

Tycho half on the fix: run the instrument, and the document reading in
`scripts/repros/2026-11-07-ce1115-named-point-derivative-repro.mts`; the row
also needs a Tycho change recorded in ROADMAP row LJ.
