A sum over a list and over a range of very large integers runs out of memory and stops the process.

## Witness

At `2a5988f8b78cf11fbba9ec1ce5440c373b0725e9`, `ce.box(…).evaluate()`:

```json
["Sum", ["Multiply", "j", "k"],
  ["Element", "k", ["List", 1, 2]],
  ["Limits", "j", ["Power", 2, 60], ["Add", ["Power", 2, 60], 2]]]
```

The process stops after about 15 s with a JavaScript heap out-of-memory
error (exit code 134). Right: the `out-of-range` error that the same sum with
only the `Limits` clause gives ("a bound with magnitude at most
9007199254740991").

## Cause and options

`reduceElementIndexingSets` in `src/compute-engine/library/utils.ts` turns
each `Limits` clause of a sum that also has an `Element` clause into a list
with `for (let i = limits.lower; i <= limits.upper; i++)`. Above 2^53, `i++`
does not change `i`, so the loop never ends and the list grows until the heap
is full. The path with only `Limits` clauses calls
`nonEnumerableIndexingSet()` first and returns `NON_ENUMERABLE_BOUNDS`. Fix:
make the same check in the mixed path and return the same error (size S).
