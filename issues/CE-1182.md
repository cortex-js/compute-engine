A compiled numeric function unnecessarily checks whether a scalar local is an array when an outer variable with the same name holds a list.

## Witness

A notebook may have a list named `total` and a function with its own scalar
`total`. This two-line program needs no special input type or target mode:

```epsil
let total = [91, 92]
function f(w: real) { let total: real = w; total = total + 1; total }
```

Observed on source at `14e279a45`, through the traditional JavaScript target,
with `constantFold: false, cse: false, fallback: false`:

```typescript
const ce = new ComputeEngine();
ce.assign('total', ['List', 91, 92]); // Omit this line for the control.
const fn = ce.expr(['Function', ['Block',
  ['Declare', 'total', "'real'", 'w'],
  ['Assign', 'total', ['Add', 'total', 1]], 'total'],
  ['Typed', 'w', "'real'"]]);
const result = compile(fn, {constantFold: false, cse: false, fallback: false});
console.log(result.run!(2), result.code);
```

Both programs are valid and return **3**. The control emits
`total = total + 1`. With the outer list, it emits
`total = _SYS.bcast((_tv1, _tv2) => (_tv1 + _tv2), total, 1)`.
The local is explicitly real, so the documented compile-time shape contract
requires scalar emission without a run-time shape check.

No wrong value or timing regression was observed. Impact is minor for the
unnecessary generic broadcast; probability is medium because notebook globals
can share names with function locals. Renaming the local is a workaround.

## Cause and options

The old broadcast selection (`tryCompileBroadcast` in
`src/compute-engine/compilation/compile-broadcast.ts`) is reached for this
scalar expression. The exact ambient-value lookup causing that selection has
not been isolated. Ensure that the local declaration determines its shape,
then add this witness and its control to the legacy compiler tests.

The current fragment-binding change adds explicit scope handoffs; it does not
rewrite the broadcast selection. Its internal target rejects this unexpected
child scope instead of emitting unannotated code. This older issue is recorded
separately under the repository's defect policy.
