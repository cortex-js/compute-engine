An absent value divided by `NaN` gives `NaN` when the quotient is boxed, and `Missing` when it is computed with `div()`.

## Witness

On main `327732c36831e48ca5463d66eabe12b84f7ee207`:

```ts
const ce = new ComputeEngine();
ce.box(['Divide', 'Missing', 'NaN']).json; // 'NaN'
ce.Missing.div(ce.NaN).json; // 'Missing'
```

## Cause and options

`canonicalDivide` (`arithmetic-mul-div.ts`) folds a `NaN` literal operand to
`NaN` before its absence rule, and `div()` tests the absence before the
`NaN` divisor. One of the two orders must change. `docs/ERROR-MODEL.md`
states which of `Missing` and `NaN` wins; the route that disagrees with it
changes. CE-1583 made the two routes agree for a point with an absent
coordinate (`(1, Missing) / NaN` is `(NaN, NaN)` on both), by having
`div()` divide each component with `canonicalDivide`.
