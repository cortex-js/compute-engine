A program that names the parts of a pair, in a `let` or in a `for` loop, no longer compiles.

## Witness

1. `Block(Declare(Tuple(a, b), { value: Tuple(1, 2) }), a + b)` (Epsil
   `let (a, b) = (1, 2); a + b`).
2. `P1: list<tuple<real, real>>`;
   `Block(Declare(s, 'real', { value: 0 }), Loop(Assign(s, s + p·q), Element(Tuple(p, q), P1)), s)`
   with `inputs: { P1: 'list<tuple<real, real>>' }`.

0.193.0: both compile; they give 3, and 3.5 at
`P1 = [(1, 0.5), (2, 1.5)]`, the interpreter's values.
0.194.0: case 1 declines, "a declaration with no value, or with attributes";
case 2 declines, "a Loop index that is not a name".

CE-1462 (in progress) adds the parallel assignment `Assign(Tuple(…), Tuple(…))`
(design `docs/plans/2026-11-18-ir-parallel-for-and-list-locals.md` § 4.3) but
not these two patterns; they can join that work. Workaround, not tested: rewrite the
program with indices (`let r = …; r[1]`).

## Expected

Both compile on javascript and give the interpreter's value.
