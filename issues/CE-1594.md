Solving 1/(x²+1)² = 0 gives the unsolved equation back instead of "no solution".

## Witness

On 0.194.3 `Solve((x^2+1)^(-2) = 0, x)`, `Solve(1/(x^2+1) = 0, x)` and
`Solve((x-1)^(-2) = 0, x)` evaluate to the `Solve` expression. Each must give
`[]`. Controls: `Solve(1/x = 0, x)` gives `[]` and
`Solve((x-1)/(x^2+1) = 0, x)` gives `[1]`.

## Cause and options

A quotient whose numerator is a nonzero constant is handled for a
denominator `x`, but not for a polynomial denominator or a negative power of
a polynomial. Option: write `p^(-k)` as `1/p^k`, then apply the rule that a
nonzero constant over a non-constant denominator has no root (the roots of
the denominator are excluded anyway). Size S.
