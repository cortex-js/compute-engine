The value of a function whose body is a loop of 12 passes takes about 3 seconds to evaluate at one point.

## Witness

Tycho's document `showcase/black-hole` (the program and its definitions are
in `~/dev/compute-engine-recovery/interval-dump/t12-interval-js-document-definitions.json`,
program 0). The function `blackhole(x, y, a)` is a `Block` that declares five
locals and runs a `Loop` over `Range(1, 12)`; each pass declares locals and
assigns four of the outer ones (trigonometric and square-root arithmetic, 1,905
characters of MathJSON for the whole body).

At `ed9c1f9e8`, with the engine at machine precision and the document's
definitions:

```ts
const e = ce.box(['Power', ['blackhole', 'x', 'y', 'a'], 0.6]);
e.subs({ x: 0.75, y: 1.25, a: 3 }).N();   // 0, after 2.9 to 3.3 s
```

The compiled JavaScript and the compiled interval code of the same program
take about 20 microseconds per call, so the interpreter is about 150,000
times slower on it; 12 passes of a body of that size should take
milliseconds. The script
`_TASKS/2026-11-15-interval-mode/` does not hold a copy: the witness is
reproduced by loading the document as
`_TASKS/2026-11-15-interval-mode/sweep-t12.mts` does and timing the
expression above.

## What the user sees

A host that evaluates this function with the interpreter (the fallback when a
compilation declines, or a single value shown beside a plot) waits seconds
for each point. The workaround is to compile, which every target does for
this program.

## Cause and options

Not investigated. Candidates to measure first: the cost of each `Assign` to
a local declared outside the loop (a new binding and its type inference at
each pass), the canonical form or the simplification of the values that the
locals hold from pass to pass (a value that grows as an expression instead of
being a number), and the time per `Declare` inside the pass. `CE-1210`
measures the general slowdown of bound names against 0.186.0 at 1.25 times;
this is another order of magnitude and has its own witness. It was not
checked whether an earlier release is faster on it.

A profile of the witness (2026-11-21, a session that did not finish) puts the
time in `max(...)`, which compares exact symbolic operands with `simplify`.
At a point whose coordinates are integers, the body also runs exactly under
`.N()`: the block does not pass the numeric approximation to its statements.

## Code

The interpreted `Loop` and `Block` are in `src/compute-engine/library/control-structures.ts`; the application of a function is in `src/compute-engine/boxed-expression/boxed-function.ts`.
