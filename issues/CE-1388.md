The pseudo-inverse of a matrix that is not of full rank stays unevaluated, also under `N`.

## Witness

Epsil CLI, main 6be5b5f52: `pseudoInverse([[1, 2], [2, 4]])` and
`N(pseudoInverse([[1, 2], [2, 4.0]]))` stay `PseudoInverse(...)`. The
Moore–Penrose inverse exists for every matrix; for this one it is
`[[1, 2], [2, 4]] / 25`. `pseudoInverse([[1, 2], [3, 4]])` (full rank) gives
`[[-2, 1], [3/2, -1/2]]`.

## Cause and options

The handler seems to use `(AᵀA)⁻¹Aᵀ` or `Aᵀ(AAᵀ)⁻¹`, which need full rank.
Fix: for a matrix of lower rank, use the SVD (numeric) or a rank
factorization `A = C F`, `A⁺ = Fᵀ(F Fᵀ)⁻¹(CᵀC)⁻¹Cᵀ` (exact).
