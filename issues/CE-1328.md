A range whose step holds a random draw draws when the expression is made,
not when it is evaluated: every evaluation of the expression gives the same
list.

## Witness

At `d4e8d87819f53fa014559a0891d8b96c27b109ec`, `new ComputeEngine()`:

| Program | Result |
| --- | --- |
| `ce.box(['Range', 0, 3, ['Add', 0.5, ['Random']]]).json` | `["Range", 0, 3, {num: "0.55705315400581479"}]` (another number at each boxing) |
| `ce.box(['Add', 0.5, ['Random']]).json` (control) | `["Add", 0.5, ["Random"]]` |
| `ce.box(['Multiply', 2, ['Add', 0.5, ['Random']]]).json` (control) | `["Multiply", 2, ["Add", 0.5, ["Random"]]]` |

The canonical form of the `Range` holds a number in place of the step, so
the draw is made once, at boxing. CE-657 is about a random value that repeats
at each evaluation; this may be one of its causes.

## Cause and options

Not investigated. The canonical form of `Range` evaluates its step.
