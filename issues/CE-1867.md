The limit of a function defined by cases, at the point where its value jumps, is the value at the point, also for the limit from the other side.

## Witness

```
Limit(Which(x < 0, 1, True, 2), 0)       // 2, where it must stay unevaluated: the one-sided limits are 1 and 2
Limit(Which(x < 0, 1, True, 2), 0, -1)   // 2, where the limit from below is 1
Limit(If(x < 0, 1, 2), 0, -1)            // 2, where the limit from below is 1
```

`evaluate()` and `N()` give the same values. Measured at
fbdb345bc01a931039ea899c65fbf129144b4eff, with
`ce.box(['Limit', ['Which', ['Less', 'x', 0], 1, 'True', 2], 0, -1]).evaluate()`.

`Limit(Floor(x), 2)` and `Limit(Abs(x)/x, 0)` are right: they stay unevaluated.

## Cause and options

`evaluate()` has only the symbolic limit (`symbolicLimit()`,
`src/compute-engine/symbolic/limit.ts`), so the value comes from there. The
cause in that file is not investigated; the result is the value of the
function at the point, which is the limit only for a function that is
continuous there.

Options: the symbolic limit gives no value for a body with `Which` or `If`
whose condition reads the variable, and the numeric samples then give the
one-sided and two-sided values under `N()`; or it takes the limit of the
branch that holds on the side of the direction, and compares the two sides
when no direction is given.
