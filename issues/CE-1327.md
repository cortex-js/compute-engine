Inside `ce.withValues()`, a sum whose index has the name of a variable that
`withValues()` gives a value changes that variable: after the sum, the
variable holds the last value of the index.

## Witness

At `d4e8d87819f53fa014559a0891d8b96c27b109ec`, `new ComputeEngine()`,
`ce.declare('x', 'real')`:

```
e = ce.box(['List',
  ['Sum', ['Map', ['Function', ['Sum', 2, ['Limits', 'x', -0.5, 1.7]], 'z'],
                  ['Range', 1, 3]]],
  'x'])
```

| Route | Result |
| --- | --- |
| `ce.withValues({ x: 0.7 }, () => e.evaluate())` | `[18, 1]` |
| `e.subs({ x: ce.number(0.7) }).evaluate()` | `[18, 0.7]` |
| `ce.assign('x', 0.7)` then `e.evaluate()` | `[18, 0.7]` |
| `ce.withValues({ x: 0.7 }, …)` of `List(Sum(2, Limits(x, -0.5, 1.7)), x)` (control: the sum is not in a `Map`) | `[6, 0.7]` |
| `ce.withValues({ x: 0.7 }, …)` of `List(Sum(x, Limits(x, 1, 3)), x)` (control) | `[6, 0.7]` |

The right value of the first row is `[18, 0.7]`: the index of a sum is bound
by the sum. `1` is the last value of the index (the floor of `1.7`).

## Cause and options

Not investigated. The difference between the first row and the controls is
that the sum is the body of a function mapped over a list, so it is evaluated
when the outer `Sum` reads the lazy list, inside the scope that `withValues()`
made for `x`.
