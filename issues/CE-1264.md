A function with an annotated parameter, called with fewer arguments than it has parameters, gives a "missing" error instead of a function of the remaining arguments.

## Witness

```js
ce.assign('G', ce.box(['Function', ['Add', 'x', 'p'], 'x', 'p']));
ce.box(['G', 1]).evaluate();                 // (_) => Apply((x, p) => p + x, 1, _)
ce.box(['Apply', ['G', 1], 2]).evaluate();   // 3

ce.assign('F', ce.box(['Function', ['Add', 'x', 'p'], 'x', ['Typed', 'p', "'real'"]]));
ce.box(['F', 1]).evaluate();                 // Error("missing")
ce.box(['Apply', ['F', 1], 2]).evaluate();   // Error("missing"); expected 3
```

Checked at main `d2f392f08`, before and after the removal of the binding
leftovers (the same values on both trees).

## Cause and options

Not investigated. The partial application is made by `makeLambda`
(`function-utils.ts`) for the unannotated function. Option: make it for an
annotated function too, with the annotation on the remaining parameter.
Workaround: write `y ↦ F(1, y)`.
