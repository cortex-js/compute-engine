A call of a function that returns a pair, over a value of unknown type, is typed with a type that does not hold its value when that value is a list of uneven depth.

## Witness

```
P := a ↦ (a, a)
ce.declare('L', 'list<unknown>')
P(L[1])                          typed broadcastable<tuple<unknown, unknown>>
L := [[1, (1, 2), [2, 3]]]
P(L[1])                          value [(1, 1), ((1, 2), (1, 2)), [(2, 2), (3, 3)]]
```

`isSubtype` of the value type against the static type is false: the value is
a ragged list, and `broadcastable<R>` (`R | tensor<R>`) holds only lists of
one rank. The same call over `y` declared
`number | tuple | list<number | tuple | list<any>>` is typed `any` (CE-545
kept that answer for this case).

## Cause and options

`openTriggerBroadcastType` (`broadcast-lift-type.ts`) answers
`broadcastableOf(R)` when the cells of `R` can hold a list
(`tuple<unknown, unknown>`), on the ground that `broadcastable<R>` then holds
a list of any depth. That holds for `R = unknown` or `list<unknown>`, not for
a tuple `R`. Option: answer `R | list<R | list<any>>` for such an `R` unless
`R` itself can hold a list. Size S.
