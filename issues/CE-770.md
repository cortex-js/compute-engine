The compiled Python code of `Apply((x, y) ↦ x + y, L, 3)` with a list `L` raises a `TypeError` instead of giving a list.

## Witness

`Apply((x, y) ↦ x + y, L, 3)` with `L = [1, 2]`: the interpreter gives
`[4, 5]`. The ROADMAP entry reported a `TypeError` from the compiled Python
code.

At commit `5784d4aec`, with `L: list<real>`, the Python target emits
`(lambda _tv1, _tv2, _tv3: [_tv1(_tv4, _tv3) for _tv4 in _tv2])(((lambda x, y: x + y)), L, 3)`,
which maps over `L`. The original reproduction (2026-10-30, "Item 6") is not
recorded, so the declaration that failed is not known.

## Cause and options

The board decides: close it as fixed, or keep it until someone finds the
failing declaration of `L`. Recommended: close.
