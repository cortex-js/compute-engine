A sum whose body is nested about 2,000 levels deep cannot be created: the engine throws a stack overflow.

## Witness

At `8c2d6f97fac86fe5e8b6093ed7cdd57df9d4ef39`:

```ts
const ce = new ComputeEngine();
let body: any = 'k';
for (let i = 0; i < 2000; i++) body = ['Add', ['Negate', body], 1];
ce.box(['Sum', body, ['Limits', 'k', 1, 3]]);
// RangeError: Maximum call stack size exceeded, in assignsSymbol (binding-sites.ts)
```

With 1,000 levels it boxes. The same body as the operand of `Solve`
(`Solve(body = 0, k)`) boxes at 5,000 levels, so the limit is in the binder
path, not in boxing in general.

## Cause and options

`assignsSymbol()` in `boxed-expression/binding-sites.ts` walks the body by
recursion. The rest of boxing uses an explicit work stack for a deep tree
(`preboxDeepOperands()`). Option: make this walk iterative.
