A drawing of a formula that uses the Möbius function or the prime counting function takes seconds where a formula without them takes milliseconds, and a plot of the prime counting function is empty.

## Witness

On 0.198.1, `compile(expr, { to: "javascript" })` declines each of these
operators alone, with `x` declared as the operator's argument type: "Could not
compile: MoebiusMu(x): the operator MoebiusMu is not supported by the
compiler".

| Operator     | `javascript` |
| ------------ | ------------ |
| `MoebiusMu`  | declines     |
| `PrimePi`    | declines     |
| `PrimeOmega` | declines     |
| `PrimeNu`    | declines     |
| `Totient`    | declines     |
| `NthPrime`   | declines     |
| `IsPrime`    | compiles (control) |
| `Floor`      | compiles (control) |

The program of the Tycho document (the first Blog post, on the Riemann
hypothesis) is the Möbius inversion of a sum over the zeros of zeta:

```
P(x) = sum(moebiusMu(m) / m * A(x^(1/m)), (m, 1, floor(ln(x) / ln(2))))
```

`A` compiles: Tycho's curve sampler draws `A` with 100 zeros over `[2, 60]` in
about 28 ms. With the `MoebiusMu` sum around it, the sampler falls back to the
interpreter and the same curve takes about 19 s (readings of `timing(graph(…))`
in a notebook code cell). The sum with a variable upper limit compiles when
`MoebiusMu` is not in it.

A notebook formula cell `Plot(PrimePi(x), li(x), x/ln x)` drew only `x/ln x`.
Tycho did not diagnose that route; the decline of `PrimePi` is the likely cause
of its missing curve.

## What Tycho needs

The six operators compile on `javascript` for an argument of their declared
type, with the interpreter's values. `MoebiusMu` and `PrimePi` are the two the
post uses; the others are in the same family and decline in the same way.

Tycho's workaround: a list of the values μ(1) … μ(9) indexed by the summation
variable, which compiles. It limits the formula to x < 1024 and replaces the
name of the function by a table in a document that teaches the function.

## Cause and options

Not investigated on the Tycho side. `IsPrime` has an emitter and these six
have none. `PrimePi` on a real argument is a step function, as `Floor` is.

## CE answer

compute-engine-fb, 2026-11-22. P3, the table value (`minor`, `high`), as
filed. Fixed in `756d266e1`: the six operators compile on `javascript` with
the interpreter's values (`docs/COMPILATION-MODEL.md`, "Integer operations
beyond the safe integer range", for the operands that throw). The Möbius sum
of the witness, with a variable upper limit, compiles. Not checked: the
`Plot(PrimePi(x), li(x), x/ln x)` route of the notebook cell.
