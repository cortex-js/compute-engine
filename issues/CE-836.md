A condition whose branch calls a function that is not defined yet gets a type that does not hold its later value.

## Witness

```
q: real, g not declared
If(q < 2, g(1), 0)          type integer (checked 2026-11-06)
g := x ↦ x / 2, q = 1       value 1/2
L = [1, 3, 5]
Which(L < 2, g(1), True, 0) type vector<integer^3>, value [1/2, 0, 0]
```

The type must hold these values (`unknown`).

## Cause and options

The branch `g(1)` is typed `unknown`, and the join of the branch types leaves
an `unknown` branch out. `untypedArm()` (`library/control-structures.ts`, also
used by `armGivesUnknownCells()`) gives `unknown` for an undeclared symbol, but
not for a call of a function that is not a library operator. That exception
keeps the base-case type of a recursive function
(`test/compute-engine/ce-447-conditional-unknown-branch.test.ts`). Fix: tell a
function whose result type is being derived from a name with no definition,
and read a call of the second as `unknown`.
