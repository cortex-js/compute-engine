Compiling a list input to GLSL reports success, but the shader code cannot run, because no shader can declare that input.

## Witness

With `L: list<real>`, compiling `L` to GLSL gives `success: true` and the code
`L` (checked at commit `5784d4aec`). A shader has no declaration for a list of
unknown length. It must decline, as `L + 1` does ("an operand lowers to a
shader ARRAY").

## Cause and options

The GLSL target emits a symbol of a list type as its name without a shape
check. Fix: decline an input whose type is a list with no static length, at the
point where the target emits the input.
