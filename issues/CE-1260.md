A hold function whose body has a second summation index gives a wrong number when the held argument uses a caller's variable of that name.

## Witness

```
let j = 10
hold ss(body, bind i, n) = Sum(Sum(body, (j, 1, i)), (i, 1, n))
ss(k * j, k, 2)
```

Gives 7; main before the bound-once change gave 50 (the `j` of `k * j` is
the caller's). With `j` free it gives 7 for `5j`. A sibling binder captures
too. When `j` is a caller LOCAL it is replaced first and the value is
right. Measured at worktree commit `c22d678d9` (bound-once step 1, not on
main when this was filed): a regression that the change is landed with, by
user decision; see ROADMAP CE-1258.

## Cause and options

The call rewrites the body with the held argument substituted and boxes it
again (`invokeWithBoundVariables`, `function-utils.ts`), so every binder of
the body binds its variable in the substituted argument, not only the
`bind` variable. Fixed by CE-1258.
