Reading the type of a call of a recursive function that returns a pair takes more than a second each time.

## Witness

On CE main 367c1236e, with `P` declared `(unknown, unknown) -> unknown` and
`P(n, x) := Which(n = 0, 1, True, (Length(n), P(n - 1, x)))`, each read of
the type of `P([1], 2)` takes about 1.4 s (the first about 0.4 s), the same
with and without the CE-1501 change. Declared `function`, the same body
takes about 0 ms per read.

## Cause and options

Each read derives the signature about 17 times with the same hypothesis H;
the memo hits 12 times and misses 5, each miss on `memo.valueType !==
valueTypeKey`: the type of the stored literal comes back with another text
under the same H (possibly the facts-hidden and facts-visible reads, or the
list-hypothesis pass). Find why that type's text changes and key the memo
on a form that does not.
