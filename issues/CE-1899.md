A conjugate transpose with the same axis twice leaves complex entries unchanged.

## Witness

```ts
const ce = new ComputeEngine();
const matrix = ['List', ['List', ['Complex', 1, 2], 3]];
ce.expr(['ConjugateTranspose', matrix, 1, 1]).evaluate().json;
// ['List', ['List', ['Complex', 1, 2], 3]]
```

The axes have no effect on the shape. The complex entry should still become
`['Complex', 1, -2]`, as it does when the axes are 1 and 2. Checked at
`93b9c7bc0`.

## Cause and options

The equal-axis branch returns the operand before applying conjugation.
Update the interpreter to conjugate the cells without permuting them.
