The limit of a function that passes another function to a helper gives the helper's parameter name instead of the value.

## Witness

```
ce.assign('g', ce.box(['Function', ['Power', 't', 2], 't']))
ce.assign('h', ce.box(['Function', ['p', 'a'], 'p', 'a']))
['Limit', ['Function', ['h', 'g', 'x'], 'x'], 2]   → ["p", 2]; expected 4
['h', 'g', 3]                                      → 9 (correct)
```

Probed 2026-11-06. In LaTeX, `h := (p, a) \mapsto p(a)` reads `p(a)` as a
product (CE-638), so the LaTeX form gives an `incompatible-type` error instead.

## Cause and options

When the limit inlines the call of `h`, it does not put the argument `g` in
place of the parameter `p` at a call position. It also happens with no
shadowing scope.
