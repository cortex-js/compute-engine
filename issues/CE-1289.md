Creating a new engine takes about 5 to 6 ms, so a program that creates many engines (one per document, one per worker) pays that each time.

## Witness

```ts
for (let i = 0; i < 200; i++) new ComputeEngine();
```

On commit `40ba059a8444959fbcfb94fe393d1a540d423088`, on a loaded machine:
about 5.2 to 6.1 ms per engine after the first (the first takes about 47 ms).
A CPU profile of 200 engines: about 1.07 s of the 1.18 s in the constructor
is in `setSymbolDefinitions` (`library/library.ts`), 0.77 s of it in
`_BoxedOperatorDefinition` and 0.61 s in its `_update`
(`boxed-expression/boxed-operator-definition.ts`). The review found test
files that create an engine per test spending 60 to 87% of their time there
(`compile-javascript-structured-nested2`, `redeclare-arithmetic-copy`, the
execute test of `test/epsil/documentation.test.ts`).

## Cause and options

Each engine builds every library operator definition again from the library
tables, and `_update` normalizes each one.

- (a) Normalize the library tables once per process (the parts of a
  definition that do not depend on the engine), and have each engine copy or
  wrap them. Size M; needs care that a definition holds no engine state.
- (b) Build an operator definition lazily, at the first lookup of its name.
  Size M; an engine uses a small part of the library.

## Progress

Option (b) is done for the operators of the standard library
(`deferredOperatorBinding()`, `library/library.ts`): an engine builds about 4
to 20 of the 669 operator definitions, and one engine costs about 1.4 ms in a
bundle where it cost 3.4 ms. Entries with an `arithmetic` field, `Add`,
`Multiply` and custom libraries stay eager.

What remains: the value definitions of the library (`_BoxedValueDefinition`,
about a quarter of what is left), whose construction computes the type of
each stored value (`noteSymbolValue()` → `noteAssignedKindValue()`). Building
them later moves the moment that type is computed, which is the subject of
D16 and D17 (`docs/plans/2026-11-11-bound-once-spec.md` §11): wait for those.
