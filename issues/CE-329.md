A compiled loop that replaces one element of a list at each step still copies the whole list on the Python target, or when the list has a second name.

## Witness

```
xs = ReplaceAt(xs, i, v)     inside a compiled loop
```

On JavaScript, a block local updated this way is copied once and then written
in place (`ownedLocalUpdateChains`, `compilation/in-place-update.ts`). The
Python target keeps the copying form. With `ys = xs` before the loop, the
check refuses and copies, although that program is safe at run time.

## Cause and options

Add the in-place form to the Python target, and let the check accept an alias
made before the loop. Probability `medium`, not the `high` default of a
`corpus` witness: the JavaScript part of issue #386 is fixed, and the rest
needs the Python target or an aliased local.
