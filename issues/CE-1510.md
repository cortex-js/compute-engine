Evaluating a sum, a quotient or a sine of a list whose length is computed from another list computes that other list about fifty times, whatever the length of the list.

## Witness

The form of Tycho row MK (CE-1364), evaluated: `Divide(1, Map(j ↦ At(C, j),
Range(1, Length(C), 1)))`. The smallest program, with an operator that counts
its evaluations (the program of CE-1364):

```ts
const ce = new ComputeEngine();
let calls = 0;
ce.declare('Spy', { signature: '(list<number>) -> list<number>',
  evaluate: (ops) => { calls++; return ops[0].evaluate(); } });
ce.declare('C', { type: 'list<number>', value: ce.box(['Spy', ['List', 7, 8, 9]]) });
ce.box(['Add', 1, ['Range', 1, ['Length', 'C']]]).evaluate();   // calls === 54
```

Measured with the fix of CE-1364 (boxing evaluates `C` no times):
`evaluate()` evaluates `C` 54 times for `Add`, 58 for `Multiply`, 33 for
`Negate`, 44 for `Divide` and for `Less`, 39 for `Sin` of a `Map` over the
`Range`, 50 for `Divide` of that `Map`. The counts are the same for a list of
3 and of 6 elements, except the two `Map` forms (42 and 53 with 6).
`Add(1, C)` evaluates `C` once. With the `C_c` of row MK at `D = 10,000`
(5.6 s for one evaluation, CE-1364), 50 evaluations would take about 280 s
(an estimate from these two numbers, not measured).

## Cause and options

The broadcast of the operator reads the facets of the `Range` that is not
evaluated (`isFiniteBroadcastParticipant()`, `zipParticipates()`, `zip()`,
`zipLengthMismatch()`, `lazyBroadcastMapIfNeeded()` in `collection-utils.ts`).
Each `count`, `isFinite` and `isEnumerable` read of `Range` reads the bounds
with `operandNumericValue()` (`library/collections.ts`), which calls `.N()` on
`Length(C)`, so each read evaluates `C` (1 to 3 times per read). Nothing keeps
the bound between reads.

Options (from CE-1364, which fixed only the reads made while boxing):

- (b) The `Range` handlers read each bound once and keep the value for the
  other facets of the same state of the engine. Size M.
- (c) A `Range` bound that is not a number literal or an exact constant is not
  evaluated by a facet read; the count is unknown until the `Range` is
  evaluated. Changes what `staticShape` and the display preview answer for
  `Range(1, Length(L))` (`docs/COLLECTIONS-MODEL.md`). Size M.
- (d) The broadcast evaluates a lazy operand whose bounds are not literals
  once, and reads the facets of the result. Size M.

Workaround: write the list as an eager list (`ListFrom(Map(…))`), as for
CE-1364.
