A compiled `Chop` of a complex value returns the value unchanged.

## Witness

With `z` declared `complex`, on main:

```
compile(ce.box(['Chop', 'z'])).run({ z: { re: 3, im: 1e-12 } })   // {re: 3, im: 1e-12}
ce.box(['Chop', ['Complex', 3, 1e-12]]).evaluate()                 // 3
```

The same with `Chop(z, 0.01)` at `3 + 0.002i`, and `Chop(x + 0.002i, 0.01)` for `x: real` (reported by the reviewer, not run again).

## Cause and options

The JavaScript lowering of `Chop` in `compilation/javascript-target.ts` emits `_SYS.chop(<operand>, tol)`, and the runtime `chop` handles a real only. Options: decline `Chop` when the operand's type can be complex (smallest), or emit a component-wise chop for a complex operand. Size S.
