The error for an unclosed extended string names the opening delimiter as the one that is missing.

## Witness

`parseEpsil('let t = ##"abc')` gives
`["string-literal-closing-delimiter-expected", "##\""]`, so the message reads
"A closing delimiter (##") was expected". The closing delimiter is `"##`.

## Cause and options

`scanExtendedString` in `src/epsil/lexer.ts` builds the argument as
`'#'.repeat(prefixLen) + '"'`. Change it to `'"' + '#'.repeat(prefixLen)`,
update the two expectations in `test/epsil/lexer.test.ts` and the inline
snapshots of `test/epsil/epsil-parse.test.ts`, and remove the reversal in
`closingStringDelimiterFixit` of `src/epsil/parser.ts` (CE-1520), which
reverses the argument to get the closing delimiter. Size S.
