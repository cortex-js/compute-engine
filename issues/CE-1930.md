A sum with no index whose lower bound is a single name changes meaning when its LaTeX is read again: the name becomes the index.

## Witness

At `63089f044dd5a0a31d699439879ba8da47ac7888`, with
`ce.box(mj, { canonical: false }).latex` and
`ce.parse(latex, { canonical: false }).json`:

```
["Sum","x",["Limits","Nothing","a",5]]
  latex: \sum_{a}^5x     back: ["Sum","x",["Tuple","a","Nothing",5]]
```

The witness is crafted: a range with no index and a lower bound that is one
symbol. The workaround is to name the index (`\sum_{i=a}^5 x`).

## Cause and options

`serializeIndexingSet()` (`latex-syntax/dictionary/definitions-arithmetic.ts`)
writes the lower bound of a clause with no index alone in the subscript, and
`getIndexAssignment()` reads a symbol there as the index. A number or an
arithmetic expression reads back as a lower bound with no index (CE-1763);
a symbol has no such spelling. Option: write the clause with a placeholder
index, or in parentheses (`\sum_{(a)}^5`) and read a parenthesized symbol as
a lower bound with no index.
