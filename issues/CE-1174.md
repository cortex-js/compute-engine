A list made by repeating a function that uses random numbers is reported as not pure, although the function is never called.

## Witness

```ts
const f = ['Function', ['Random'], 'k'];
ce.box(['Repeat', f, 2]).isPure; // false
ce.box(['List', f, f]).isPure;   // true
ce.box(['Fill', f, 2]).isPure;   // true
```

`Repeat(f, 2)` holds `f` twice and never calls it, as `List(f, f)` does, so
it must be pure. Measured on the working tree of 2026-11-08 (session
compute-engine-43), after the new `Fill` was added.

## Cause and options

The definition of `Repeat` in `src/compute-engine/library/collections.ts`
does not set `invokes: false`. The default, `invokes: true`
(`boxed-operator-definition.ts`), counts the effects of the body of a
function operand as effects of the call. `Fill(value, d1, …)` holds its value
the same way and sets `invokes: false`; its test is "does not take the
effects of a function value" in `test/compute-engine/linear-algebra.test.ts`.

Fix: add `invokes: false` to `Repeat` and the same test. Check `Cycle`, which
also holds its operand without calling it. Size S.
