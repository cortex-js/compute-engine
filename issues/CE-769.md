A function with its first argument filled in, used as the function of `Map`, gives a type error instead of the mapped list.

## Witness

`Apply((x, y) ↦ x + y, 1)` is typed `number`.
`Map(Apply((x, y) ↦ x + y, 10), [1, 2, 3])` gives
`Error(incompatible-type, function, number)`; with `f` assigned that function,
`Map(Apply(f, 10), [1, 2, 3])` stays unevaluated (checked 2026-11-06). Both
should give `[11, 12, 13]`.

## Cause and options

An `Apply` with fewer arguments than parameters is a partial application, but
its type is the result type of the function, not a function type. The type
handler of `Apply` is in `library/core.ts` (`anonymousApplicationType`). Fix:
type a partial application as a function of the remaining parameters.
Workaround: write `y ↦ f(10, y)`.
