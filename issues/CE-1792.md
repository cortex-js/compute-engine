In a scope where the user defines a function named `Sqrt` or `Root`, the square of a call of that function, or its product with itself, gives the argument of the call instead of the value of the user's function.

## Witness

At commit `58629ce35b7bc2c501fed918294e0fe9fad23b09`:

```ts
ce.pushScope();
ce.declare('Sqrt', 'function');
ce.assign('Sqrt', ce.box(['Function', ['Add', 'a', 100], 'a']));
const s = ce.box(['Sqrt', 'x']);   // a call of the user function: x + 100
s.pow(2).json                      // "x"; must be the square of Sqrt(x)
s.mul(s).subs({ x: 1 }).N()        // 1; must be 10201
ce.declare('Root', 'function');
ce.assign('Root', ce.box(['Function', ['Add', 'a', 'b', 100], 'a', 'b']));
ce.box(['Root', 'x', 3]).pow(3).json   // "x"; must be the cube of Root(x, 3)
ce.popScope();
```

`crafted`: the program defines a user function with the capitalized name of
a library function and takes a power of a call of it in its scope.

## Cause and options

`pow()` (`boxed-expression/arithmetic-power.ts`) selects the rules
`(√a)^b → a^(b/2)` and `(Root(a, n))^b → a^(b/n)` by the operator name
(`isFunction(x, 'Sqrt')`, `isFunction(x, 'Root')`), so it applies them to a
call bound to a user function. A `Product` keeps such a call as an opaque
factor (`shadowsLibraryOperator()`), but writes the factor with its exponent
again with `pow()`. Option: add `isLibraryOperator(x, 'Sqrt')` and
`isLibraryOperator(x, 'Root')` to the two tests, as CE-1759 did for
`(a^b)^c`. Related: CE-1114.
