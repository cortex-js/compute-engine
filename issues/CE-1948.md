When a user asks Graph Paper's assistant, Spark, for code, it writes Epsil with loops in the habits of Python: it does not use a library function, broadcasting or a pipeline that does the job.

## Witness

Spark, the chat assistant of Graph Paper, writes Epsil code cells into
notebooks. Tycho wants to teach it Epsil from the agent card
(`src/epsil/docs/for-agents.md`), so that the teaching follows the language at
each adoption. Two things stop this.

**1. The package does not export the card.** It ships at
`dist/esm-min/cli/for-agents.md` (19,138 characters in 0.204.3), but the
`exports` map has no entry for it. Tycho can read it only through that internal
path, which a build change can move.

**2. The card does not teach the idioms that the style guide states.** The
style guide (`src/epsil/docs/style.md`) says "Produce values with `map`,
`filter`, `fold`; loop for effect" and "Prefer a pipeline when the list has a
formula". In the card:

- 2 of the 10 examples of "Verified Idioms" are loops (the GCD with `while`, a
  list built in a `for` loop). A model copies the examples.
- Broadcasting is mentioned once, for string interpolation. The rule that
  arithmetic and most numeric functions broadcast over a list
  (`from-python.md`: "Arithmetic broadcasts over a list elementwise") is not in
  the card.
- The card does not say to look in the library before writing a loop.
  `nthPrime`, `mandelbrot` and `julia` exist; Spark wrote all three by hand.

Tycho request "Compute the sum of the first 100 primes". Spark wrote:

```epsil
let sum = 0
let count = 0
let n = 2
while count < 100 {
  if isPrime(n) {
    sum = sum + n
    count = count + 1
  }
  n = n + 1
}
print(sum)
```

The idiomatic program is `nthPrime(1..100) |> sum`. Both give 24133 on
0.204.3 (the instrument's controls).

Measured with Tycho's trial script (`workers/api/scripts/spark-try.ts`,
Claude Haiku 5.5, 2 runs each): for "Count the twin prime pairs below 1000 in a
code cell", Spark's current prompt gave Python syntax in 2 of 2 runs (`and`,
`len`, `if` inside a list literal). With a short section added to the prompt
(an order of preference, the broadcasting rule, the argument order of `map`
and `filter`, "the value is the last statement", and one before/after pair
that is not the test case), it gave
`1..997 |> filter(_, p => isPrime(p) && isPrime(p + 2)) |> length` in 2 of 2
runs. The same section made Spark draw the Julia set with
`bitmap((x, y) => julia(x + y*i, -0.8 + 0.156*i, 200), …)` instead of its own
loop.

The instrument prints, on the installed bundle: the `exports` entries that
name the card (none today), the control that the card is at its internal path,
the number of loop examples in "Verified Idioms", the lines that mention
broadcasting, and whether the card states an order of preference and a library
search before a loop.

## Cause and options

Ask, in two parts:

1. **Export the card**, for example as `@cortex-js/compute-engine/for-agents.md`
   (a file export), or as a function in `@cortex-js/compute-engine/epsil` that
   returns its text. Tycho would read it at build time and take sections of it
   by their headings, so stable `##` headings help. The Compute Engine API card
   (`compute-engine-for-agents.md`) could be exported the same way.
2. **Put the idioms in the card**, as the style guide states them:
   - an order of preference: a library function, then broadcasting, then a
     pipeline, then a loop; and "look up the library (`epsil doc <keywords>`)
     before writing a loop";
   - the broadcasting rule: which operators and functions apply elementwise to
     a list or a range (`sqrt([1, 4, 9])`, `isPrime(1..10)`, `nthPrime(1..100)`);
   - two or three before/after pairs, such as the program above and
     `nthPrime(1..100) |> sum`;
   - examples in "Verified Idioms" that are not loops, or a note on each loop
     example that says why a loop is the right form there.

Workaround: Tycho keeps its own short Epsil card in Spark's prompt until the
export ships. That card can drift from the language, which is the reason for
the request. Size S.

## Answer

P3, done as asked, both parts. The package exports the two cards as files:
`@cortex-js/compute-engine/for-agents.md` (Epsil) and
`@cortex-js/compute-engine/compute-engine-for-agents.md` (Compute Engine);
read them with `require.resolve` or `import.meta.resolve`. The Epsil card has
a new section, `## Order of Preference`, before `## Verified Idioms`: the order
(library function, broadcasting, pipeline, loop) with `epsil doc <keywords>`
before a loop, the broadcasting rule (arithmetic, `< <= > >=`, functions of
numbers; aggregates take the whole list), the before/after pair of this issue
and a table of four more. "Verified Idioms" keeps one loop example, the Collatz
path, with the reason a loop is the right form there. The `##` headings are the
ones Tycho can take sections by. Workaround until the release: Tycho's own card.
