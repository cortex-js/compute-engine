The WGSL shader for a plot condition such as `3 < y < x or x < 5` does not compile, because the code has no parentheses around the `and`.

## Witness

With `x: real` and `y: real`, `Or(Less(3, y, x), Less(x, 5))` compiles to WGSL
as `(3.0 < y) && (y < x) || x < 5.0`. WGSL needs
`((3.0 < y) && (y < x)) || x < 5.0`. An `Or` under an `And` has the same
defect.

## Cause and options

The WGSL grammar gives `&&` and `||` no precedence over each other, so
`a && b || c` is invalid. The precedence table of `compilation/gpu-emit.ts`
(And 4, Or 3) is correct for GLSL only. Fix: on
WGSL, put parentheses around an `And` operand of an `Or` and an `Or` operand of
an `And`, including the conjunction that a comparison chain lowers to
(`compileExprOperator()` in `compile-operators.ts`).
