A series of a square root, a cube root, an inverse sine or a log-gamma function of an expression with complex coefficients that is on the cut of the function at the point has the wrong value on one side or on both.

## Witness

At commit `76e1ad8618838b1594491f938dd483b4ee40c03e`, the value is `f − Normal(Series(f))`:

```
Series(Sqrt(-1 - i*x), x, 0, 3)          // i − x/2 + …
                                         // x = −0.01: 4e-10;  x = 0.01: 0.01 − 2i
Series(Root(-1 - i*x, 3), x, 0, 3)       // −1 − i·x/3 − x²/9 + …
                                         // x = −0.01: 1.50 + 0.86i;  x = 0.01: 1.50 − 0.86i
Series(Arcsin(2 + i*x), x, 0, 3)         // arcsin(2) + √3/3·x + …
                                         // x = −0.01: 6e-10i;  x = 0.01: −0.01 + 2.63i
Series(GammaLn(-1/2 + i*x), x, 0, 3)     // ln(2√π) + …
                                         // x = −0.01: 3.14i;  x = 0.01: −3.14i
```

The witness is `crafted`: the argument has a coefficient that is not real and a value on the cut at the point.

## Cause and options

`symbolic/series.ts`, the Taylor engines (`taylorCoeffs()`) at a regular point. The argument crosses the cut of the function at the point (the negative real axis for `√` and the cube root, `(1, ∞)` for `arcsin`, the negative real axis for `ln Γ`), so the function has a jump there; the Taylor coefficients are the derivatives of the value on one side. The cube root is wrong on both sides: its coefficient at the point is the real cube root `−1` of `−1`, but the value for an argument that is not real is the principal cube root, near `1/2 + i·√3/2`. `GammaLn` is wrong on both sides: its constant term is `ln|Γ(−1/2)|`, the value on the real axis, which is the mean of the values on the two sides.

Option (simple, sound): `computeSeries()` and `seriesAtInfinity()` decline when one of these functions, or a `Power` whose exponent is not an integer (`(−1 − i·x)^(1/3)`, `(−1 − i·x)^x`), has, at the point, an argument whose value is on its cut and that is not real for every real `x` (`isRealOnRealAxis()`). This is the test of `lnCrossesCutAt()`, which CE-1617 added for `Ln` and `Log`; extend that function with the cut of each operator.
