A function that subtracts two matrix products returns a zero matrix if the determinants appear later in the same tuple.

## Witness

```js
const ce = new ComputeEngine();
const A = ['List',['List',1,2],['List',3,4]];
const B = ['List',['List',0,1],['List',1,0]];
const a = ['Transpose','a'], b = ['Transpose','b'];
const comm = ['Subtract',['Multiply',a,b],['Multiply',b,a]];
const ds = [['Determinant','a'],['Determinant','b']];
const f = ce.box(['Function',['Tuple',comm,...ds],'a','b']);
ce.box(['Apply',f,A,B]).evaluate().json;
```

Main 489125b returns a zero matrix in the first component. Moving the two determinants first gives the correct commutator, [[1,-3],[3,-1]]. Using Block(a) and Block(b) in place of the transposes gives zero in the first order and [[-1,-3],[3,1]] in the second. First([a]) and First([b]) also reproduce it. The determinants settle matrix contracts in the same function. CE-1317 records the separate case with no matrix evidence. CE-1490 and CE-1491 have explicit external contracts. A computation reporting matrix diagnostics alongside its commutator is a plausible use.
