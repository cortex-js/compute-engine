Sorting a list of strings, removing its duplicates, or comparing two strings does not compile.

## Witness

On javascript, with `L: list<string>` and `s, t: string`: `Sort(L)`,
`Unique(L)` and `Less(s, t)` decline; the interpreter gives a value.
Workaround: none in compiled code; the interpreter answers.

## Cause and options

The interpreter has two orders for strings (`compare.ts`): code points when
a character is compared, and JavaScript `<` on UTF-16 code units between two
strings; a character against a longer string stays unevaluated. Compiled code
holds characters and strings the same way, so it must pick the order from
the static type (character vs string) and decline the mixed case. This is
per-operator code (about 30 lines, no core change), on top of CE-1556's
element reads.
