`N()` of a convergent iterated integral is `NaN` when the inner integral has a
closed form that cancels near a bound: the interpreter, the existing compiler
and the `numeric-kernel` profile all give `NaN` for
∫₀¹ ∫₀ᵗ sin(s·t³) ds dt, whose value is 0.0804194546574510.

## Witness

At `7576ecde0f22d8464122c34e4b78da066c528da9`, `new ComputeEngine()`,
`ce.box(…)`:

| Program | Result | Right |
| --- | --- | --- |
| `Integrate(Integrate(Sin(s·t^3), Limits(s, 0, t)), Limits(t, 0, 1)).N()` | `NaN` | 0.0804194546574510 (series Σ (−1)^(k+1)/((8k−2)·(2k)!) integrated term by term: 1/12 − 1/336 + 1/15840 − …) |
| `Integrate(Sin(s·t^3), Limits(s, 0, t)).evaluate()` | `t^(-3) - cos(t^4)/t^3` | (1 − cos t⁴)/t³ |
| the same at t = 1e-3, `.evaluate().N()` | `0` | 5.0e-16 |

The closed form of the inner integral is written as a difference of two terms
that each grow as t⁻³: at t = 0 it is ∞ − ∞, and near 0 it loses every digit.
The outer quadrature then gives `NaN`. Computed numerically (the IR pipeline's
`Integrate` region under `CE_JS_PROFILE=ir`, which the interpreter then calls
for the outer integrand), the value is right.

The test `compile-javascript-structured-calculus2.test.ts` passes on a plain
run only because the three values are all `NaN` (`close()` accepts two NaN).

## Cause and options

The antiderivative-first route (interpreter `Integrate`, and the existing
compiler's `closedFormIntegral`) takes a closed form with no check of its
conditioning on the interval. Options: keep the closed form only when it is
finite at the sample points of the outer quadrature (fall back to the
numeric inner integral otherwise); or simplify `t^(-3) - cos(t^4)/t^3` to
`(1 - cos(t^4))/t^3` and evaluate `1 - cos u` as `2 sin²(u/2)`. Size M.
