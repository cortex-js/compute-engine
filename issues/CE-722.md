The compilation guide does not show that a conditional which selects element by element and assigns a name in its branch does not compile.

## Witness

With `L: list<real>`, `Block(p ≔ 0, If(L > 0, p ≔ 5), 2p)` declines with the
code `'unsettled-shape'` on every target (since CE-712.1). The guide
`docs/COMPILATION-MODEL.md` does not list this example.

## Cause and options

User decision 2026-11-01, option (a): the decline is the rule, because the
value of `p` after the selection has a shape that depends on the run-time
selection (static-shape rule R3). Remaining work: add this example to the list
of declines that the static-shape rule requires in
`docs/COMPILATION-MODEL.md` (with CE-712.5). If CE-739 later gives `p` one
shape, the compiler can emit that, as a new issue.
