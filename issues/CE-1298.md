Some derivatives of special functions are NaN at a point where the derivative exists, and their series there stays unevaluated.

## Witness

On main:

```
D(EllipticK(x), x) at x = 0          // NaN; the value is π/8
D(EllipticE(x), x) at x = 0          // NaN; the value is -π/8
D(LerchPhi(x, 2, 1.5), x) at x = 0   // ~oo (reported by the reviewer); the value is about 0.16
Series(PolyLog(2, x), x, 0, 3), Series(LambertW(x), x, 0, 3)   // unevaluated
```

Before PR #575 the first three stayed unevaluated as `Derivative(...)` applications; PR #575 gave them closed forms that are 0/0 at 0, as the older `PolyLog` and `LambertW` rules are.

## Cause and options

The closed forms (`(E(m) - (1-m)K(m)) / (2m(1-m))`, …) have a removable singularity. Options: (a) a value table at the removable points next to each rule; (b) a `Limit` when substitution gives 0/0; (c) leave as is (a NaN at one point). Recommended: (a), the smallest. Size M.
