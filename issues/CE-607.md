Expanding the square of an expression that holds a random value turns one random draw into three independent draws.

## Witness

```
r declared with the random effect
Expand((r(t) + 1)^2)  ->  r(t)^2 + 2r(t) + 1   (three draws: the distribution changes)
```

## Cause and options

Each rewrite that copies a subexpression (expansion of a power or a product,
distribution, substitution of a repeated variable) has this problem when the
subexpression draws. A fix needs a rule for when such a rewrite is allowed (for
example, refuse it, or keep the power unexpanded). Also audit the rules that
compare subexpressions with `isSame` (`simplify-trig.ts`, `simplify-power.ts`,
`simplify-log.ts`, `simplify-abs.ts`, `fu.ts`, the Rubi rules). Unguarded
same-argument identities: `commonTerms()` (`arithmetic-mul-div.ts`),
`collectFactors()` (`factor.ts`), `a!/b!` and the `Binomial` form
(`simplify-divide.ts`), the `log_c` and `c^log_c` rules (`simplify-log.ts`),
`Root(x^n, n) → |x|` (`simplify-power.ts`), the grouping of sum terms
(`simplify-rules.ts`). CE-598 fixed the opposite case (two draws merged).
