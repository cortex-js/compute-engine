`LerchPhi(z, s, a)` does not end for a very large order `s`.

## Witness

At `6e06bfe87`:

| Program | Result |
| --- | --- |
| `ce.box(['LerchPhi', 0.5, 1e300, 2]).N()` | no result after 15 s |

The value is `2^(-1e300) + 0.5·3^(-1e300) + …`, which is `0` in double
precision.

A profile of the run spends its time in `upperGammaDirectSeriesComplex`
(`numerics/numeric-complex.ts`), called from `lerchContinuedWithError`
(`numerics/lerch-phi.ts`).

## Cause and options

Not investigated. The continued route calls the upper incomplete gamma
function with an order near `s`, and that series runs a number of terms that
grows with `s`. Option: as in CE-1228 (`hurwitzEMComplex`), stop the direct
sum once the bound of the rest is below half the smallest subnormal or below
1e−17 of the sum, compared in logarithms, before the continued route is
reached.
