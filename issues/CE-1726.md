The derivative of a gamma, chi-square, beta, F or t distribution function stays unevaluated instead of giving the density.

## Witness

At `11cbc632437e1816a30f8e3bf381254f69b3c749` with the CE-1590 change:

```
D(CDF(GammaDistribution(2, 3), x), x)
  → Which(x <= 0, 0, True, -1/3 * Apply(Derivative("GammaRegularized", 0, 1), 2, 1/3 * x))
D(CDF(BetaDistribution(2, 3), x), x)
  → Which(x <= 0, 0, 1 <= x, 0, True, Apply(Derivative("BetaRegularized", 1, 0, 0), x, 2, 3))
D(GammaRegularized(a, x), x)
  → Apply(Derivative("GammaRegularized", 0, 1), a, x)
```

The workaround is `PDF` of the same distribution.

## Cause and options

The differentiation has no rule for `GammaRegularized` and `BetaRegularized`
with respect to the point. The rules are
`∂/∂z Q(a, z) = −z^(a−1)·e^(−z)/Γ(a)` and
`∂/∂x I_x(a, b) = x^(a−1)·(1 − x)^(b−1)/B(a, b)`. Add them to the derivative
table (`symbolic/derivative.ts`). Size S.
