A polar region that picks its radius from a fixed list of random numbers (art/bixumi1pk6) takes 1.6 seconds to draw one frame.

## Witness

The row is `r\ge\operatorname{random}(9^4)[8\theta]`; Tycho's import gives
`WithRandomSeed(628117, RandomChoice([0, 1), 6561))` indexed by `8θ`. The seed
and the arguments are constants, so the list is the same at every call. Bare
engine, CE 0.204.3, `javascript` target, MathJSON
`["At", ["WithRandomSeed", 628117, ["RandomChoice", ["Interval", 0, ["Open", 1]], 6561]], ["Max", ["Floor", ["Multiply", 8, "theta"]], 1]]`:

| shape | µs per call |
| --- | ---: |
| the row | 23.89 |
| control: the same `At` over the evaluated list, as a constant `List` of 6,561 numbers | 0.014 |
| interpreter, `subs({theta}).N()` | 3,395 |

Ratio row / control: about 1,700. 2,048 values of `θ` over the row's domain
(−25.4 … 534.4); each arm in a fresh process, 5 trials interleaved, medians;
spread of the trials ≤ 6 %. Load 3.9 → 3.3 on 18 cores (Apple M5 Max,
Node 26.13.0).

In Tycho's renderer one frame of the row makes 50,001 calls at 30.2 µs each:
1.56 s, of which 1.51 s is in the compiled function. With the list made once,
the same 50,001 calls would cost about 1 ms.

The code that costs (record 1329 of the audit, `ce-0.204.3-all.json`, same as
the bare compile): each call draws the 6,561 numbers again:

```js
(() => {
  let v4; let v5;
  _SYS.withRandomSeed(628117, () => {
    const v3 = _SYS.randomChoice(_SYS.domainInterval('RandomChoice', 0, 1), 6561);
    …
    v5 = v3;
  });
  return _at(v5, Math.max(Math.floor((8 * _.theta)), 1));
})()
```

## Cause and options

A `WithRandomSeed` whose seed and body read no input gives the same value at
every call (draws are index-addressed from the seed, reset on entry), so it
is an invariant of the compiled function, like a constant. It is emitted in
the per-call body. Options: compute such a block once (in the per-load
preamble, or lazily on the first call) and keep the result; the value is
bit-identical to today's. A seeded block that reads an input stays per call.

READY when row / control ≤ 3 per call (the instrument's line `CE-1943:`).
