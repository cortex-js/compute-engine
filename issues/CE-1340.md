`EulerE(n, z)` of a complex `z` has no numeric value.

## Witness

On main at `fed2ad56317cc2a41f1124414bdc7c97d857d83a`:

```
ce.box(['EulerE', 3, ['Complex', 1, 2]]).N()          // EulerE(3, (1 + 2i)); -25/4 - 8i
ce.box(['EulerE', 3, ['Complex', 1, 2]]).evaluate()   // EulerE(3, (1 + 2i)); -25/4 - 8i
ce.box(['EulerE', 3, 2]).evaluate()                   // 9/4, right
```

The signature is `(integer, number?) -> number`, so a complex operand is
admitted. E₃(x) = x³ − (3/2)x² + 1/4. Probability `medium`: a rare function of
a complex operand.

## Cause and options

The handler evaluates the Euler polynomial at a real operand only. Evaluate the
same polynomial at a complex operand, exactly for an exact complex and
numerically otherwise. Size S.
