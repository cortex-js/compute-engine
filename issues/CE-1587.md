The Voronoi diagram example is drawn by the processor instead of the graphics card, so it draws slower.

## Witness

```ts
const ce = new ComputeEngine();
ce.declare('x', 'real');
compile(ce.box(['Min', ['Comprehension', ['Power', ['Subtract', 'x', 'k'], 2],
  ['Element', 'k', ['Range', 1, 16]]]]), { to: 'glsl', symbolic: ['x'] });
```

0.194.3: declines, "Comprehension(Power(Add(Negate(k), x), 2), Element(k,
Range(1, 16))): the region build (a Map, a Filter or a Range) on glsl".
0.192.0: compiles (the 16 elements written out in a chain of `min`).
Control: `Sum(Power(Subtract(x, k), 2), Limits(k, 1, 16))` compiles on
0.194.3. `Sum` of the same comprehension and `Min(Comprehension(x - k, …))`
decline the same way. `src/compute-engine/compilation/ir/README.md` says that
on GLSL a one-clause `Comprehension` over a source of a constant length of 1
to 64 is written out, and that a `Range` of such a length is the list of its
elements, so this form should compile.

Document form: the heatmap of `showcase/voronoi-diagram` is
`Which(Less(F(x, y), 0.0008), 0, Less(1.3, B(x, y)), 0, True, 0.8·H(x, y) +
0.12)`, compiled with `{to: 'glsl', symbolic: ['x', 'y', 'T', 't']}`, where
the document function `F(x, y)` is `Min(Comprehension(D(x, y, k), Element(k,
Range(1, 16))))` (the squared distance to 16 moving seeds). Both the
by-reference compile and the expanded fallback decline with this message.
Captures: Tycho `.cache/mg-evidence/codegen-full.json` record 266 (0.192.0,
compiled) and `.cache/macro-carriers-phase-a-ce1943/codegen-full.json`
records 271 and 272 (0.194.3, declined).

Tycho impact: the shipped showcase entry `voronoi-diagram` moves from the GPU
band to the JavaScript band (it still draws, more slowly).

## Cause and options

The GLSL profile has no `build` region (`profile.syntax.regions`), and the
comprehension over a `Range` reaches the lowering as a build instead of the
written-out list that the README describes. Option (a, recommended): write
out a one-clause comprehension over a `Range` of constant length up to
`SCALARIZE_LIMIT`, as for `Map`. Option (b): document the decline; Tycho then
keeps the CPU band for this entry.
