The differences of an empty list give a type error, where the differences of a one-element list give the empty list.

## Witness

```
Differences([])          // Differences(Error(incompatible-type, "collection<number>", "list<never>"))
Differences([1])         // []
Differences([1, 4, 9])   // [3, 5]
```

Measured at 8995eb986cc37d4a3f2dec2459874e9dce9bc262. The signature is
`(indexed_collection<any>) -> indexed_collection`, so `[]` is of the type of
the parameter. Workaround: test the length first.

## Cause and options

Some step of the canonical form or of the evaluation of `Differences`
checks its operand against `collection<number>`, which `list<never>` (the
type of `[]`) does not match. Find that check and admit the empty list,
giving `[]`. Size S.
