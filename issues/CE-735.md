A compiled loop that ends with a value from `Break` returns `undefined` instead of that value.

## Witness

With `x: real`, `Loop(If(x > 1, Break(3), Break(3)))` at `x = 2`: the compiled
JavaScript gives `undefined`; the interpreter gives `3`. The emitted code is
`while (true) { if (_.x !== undefined) { if (1 < _.x) { break; } else { break; } } }`.

## Cause and options

The emitted `break` drops the value of the `Break`. Fix: assign the value to a
result variable of the loop before `break`, and return that variable after the
loop.
