A power or a cube root of a number made at a higher precision has two digits fewer after the engine is set to machine precision.

## Witness

```ts
const ce = new ComputeEngine();
ce.precision = 30;
const a = ce.parse('0.3');
ce.precision = 'machine';
ce.box(['Power', a, 0.5]).evaluate(); // 0.547722557505166
ce.box(['Power', 2, a]).evaluate();   // 1.23114441334492, double: 1.2311444133449163
ce.box(['Root', a, 3]).evaluate();    // 0.66943295008217, double: 0.6694329500821695
```

The same values with the double `0.3` have 16 or 17 digits.

## Cause and options

`apply2()` (`boxed-expression/apply.ts`) calls the big-decimal kernel
whenever an operand has a big decimal, also at machine precision, and the
kernel rounds to `ce.precision`, 15 digits (`BigDecimal.pow(0.5, 15)`
from `arithmetic-power.ts`; `BigDecimal.nthRoot(4, 15)` from `root()` in
the same file for `Root(a, 4)`). One-argument functions go through `apply()`, which uses the double kernel at
machine precision, and the kernels of `BigNumericValue` (`sqrt`, `ln`,
`exp`, `inv`, `root`, `abs`) compute at 20 digits and give a double at
machine precision since CE-1138. Option: in `apply2()`, at machine precision,
call the big-decimal kernel at 20 digits and convert a result in the normal
double range to a double, as `toDouble()` in `big-numeric-value.ts` does.
