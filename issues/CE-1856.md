A limit from below written with a direction other than -1 is computed from above.

## Witness

```
Limit(Abs(x)/x, 0, -2)    // 1: read as from above
NLimit(Abs(x)/x, 0, -2)   // -1: read as from below
```

Measured at 074e6347f39717e4f6d5b44521c5c459b6d9d2b7.

## Cause and options

The symbolic path (`symbolic/limit.ts`, `dir === -1`) reads only exactly -1 as from below, while the numeric path reads the sign. The `direction` parameter is now documented as 1 or -1. Options: (a) read the sign in the symbolic path too; (b) refuse a direction other than 1 and -1.
