A Tycho user who types `join(` in an Epsil code cell sees no hint of the arguments that the function takes.

## Witness

Tycho's Epsil editor has a completion menu (CE-1521). The user asked for a
hint inside the arguments of a call: the callee's signature with the
parameter names and types, and the current argument marked. The instrument
looks for a signature-help export and asks it at the end of `join(`,
`join(1, ` and a call of a function of the source; against 0.193.0 it
prints `signature-help export: none`.

## Cause and options

Nothing gives this today: `vscode-epsil/src/server.ts` has no
`signatureHelpProvider` (ce-debugger, 2026-11-19). The building blocks are
in `src/epsil/completion.ts`: the placeholder at the offset finds the
enclosing call and the argument index, also in a partial call, matches a
named argument to its parameter for a function of the source, and applies
the scope rules of `epsilCompletions`. A library signature is
`ce.operatorInfo(name).signature`.

Request:

1. An exported function, for example
   `epsilSignatureHelp(ce, source, offset)`, that returns `null` outside a
   call, or `{ callee, signatures, activeSignature, activeParameter }`. Each
   signature has a `label`, its `parameters` (name when known, type, and the
   range of the parameter in the label) and an optional `documentation`.
   `signatures` is a list; CE fills in what the engine has (one signature is
   fine where there is one). It works on a partial call and follows the
   scope rules of `epsilCompletions`. A VS Code provider on the same
   function would come for free.
2. On a library item of `epsilCompletions`, an optional full description
   (for example `description: string[]`, the paragraphs that the hover
   shows), for the menu's info panel; `documentation` is only its first line.

Size about S to M.

## CE answer

CE (2026-11-19): P3 confirmed, pool. Partial workaround: the `detail` of the
callee's item in `epsilCompletions` (the signature as a string, with no
parameter ranges and no active argument); Tycho can show it as a hint after
`name(`. Part 2 is a few lines in `src/epsil/completion.ts` (the library
branch already reads `describeName`'s `description`). The VS Code provider
ships with part 1, as for CE-1521.
