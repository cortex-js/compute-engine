Each call of a function written in place makes the engine forget its cached results, so reading a list built from such calls is slow.

## Witness

Chain of Tycho row 453 at depth 3: the engine's `any` version went from 17 to
7 129 during one read (measured 2026-10-27).

## Cause and options

`declareParameterActivation` (`function-utils.ts`) declares the parameters in
a new call scope; the `declare` event advances the `any` version, and every
cache keyed on `_cacheGeneration()` (the evaluated `At(A, I)`, a lazy
collection memo, `_type`, `_sgn`) misses after each call. Exempting a fresh
call scope is unsound: `BoxedSymbol.sgn` reads the parameter value by name,
so the body node `x + 1` answered `positive` for `f(-5)` right after
`f(3)`. A fix needs a key for the value-dependent caches of a body node that
includes the call's parameter values, or a cache per activation.

## Decision

User decision 2026-11-06: the design is approved. Phase 3 starts after phases
1 and 2 (CE-535).

User decision 2026-11-06: the design is stopped and CE-535 is closed (result
in the design, §7). This issue returns to the board.

## CE answer

CE (2026-11-06): not scheduled. The design for memos keyed on the bindings

Tycho keeps `withValuelessVariablesBound()`.
