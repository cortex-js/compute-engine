The GPU animation needs a private board because author code could otherwise read or overwrite an earlier generation.

## Witness

Tycho's Life timer uploads a seed once and alternates two GPU textures.
When another Epsil callback reads or edits the board, it needs the latest
generation. The witness simulates a device publication with a separate
byte buffer on installed CE 0.202.0. An interpreted read through an alias
and a precompiled JavaScript reader with an array parameter both return
the old value, 10. Both return 30 after the host copies the device bytes
into `board.cells` and calls `noteStore()`. The generated reader loads
`a0._cells` directly. This is a design limitation with separate storage,
consistent with CE's current one-storage contract.

## Requested contract

Give a host a public way to associate synchronization with a mutable
array's identity and invalidate cached computations when external storage
publishes a new version. Before CPU code observes or partially overwrites
the cells, let the host materialize the latest bytes into the same array.
Cover interpreted reads and stores, public host access to cells, aliases
and record fields, and compiled JavaScript access. If a compiled function
calls back into the host and that call can publish new device data, cover
the first subsequent access too.

Prefer a guard at an access boundary or a compiled entry when sufficient.
An access that sees an already-current CPU copy should trigger no copy.
Ordinary CPU arrays should retain their current fast path, and successive
GPU generations should need no readback. A host-managed storage contract
or a bulk synchronization boundary with explicit compiler support could
meet these requirements. Tycho owns WebGL and the transfer in either case.

Acceptance: after a device update, read the new first cell through an
interpreted alias and a precompiled reader. Then write one cell from the
CPU and check that the other cell retains the device value. Neither the
alias nor the compiled reader needs rebuilding. Keep an ordinary array as
the no-hook control. CE-1892 covers compiling author-facing reads to GLSL.
