Splitting a string into its characters, joining a list of strings, and writing a color as a string still do not compile.

## Witness

On main b40a45941, javascript: `Characters(s)`, `GraphemeClusters(s)` and
`StringJoin(L)` with `L: list<string>` decline (a list of strings), and
`ColorToString(c)` declines (no string result row). 0.193.0 compiled them.

## Cause and options

Phase 1 of the string lane refuses `list<string>` in one line of the
javascript profile. Admitting it needs an audit of every list path that does
not check the lane (an out-of-range element read, `Sort`/`Unique`
order and equality, `Equal` of lists, entry checks and result
normalisation, broadcast). `ColorToString` is a row returning a string,
with 0.193.0's `colorToString` helper.
