Autocomplete inside a function suggests the library name when the program declares a variable of the same name further down.

## Witness

```epsil
let h = () => mea
let mean = (x) => x + 4
h()
```

Request completion after `mea`. `epsilCompletions()` offers `mean` as a
library function. Typing the full name refers to the local variable. With
a longer name absent from the library, completion omits the local variable.

## Cause and options

`visibleBindings()` in `src/epsil/completion.ts` filters declarations by
source position and scope span. It needs to recognize function bodies that
can read declarations further down in an enclosing scope. Keep the sequential
filter at immediate statement sites and for the declaration's own eager
initializer.
