Code can be generated for an input explicitly marked as having an unknown type.

## Witness

```ts
const expr = new ComputeEngine().box(['Add', 'external', 2]);
const result = compile(expr, { inputs: { external: 'unknown' } });
```

On main at `6537b4ab8`, compilation succeeds and emits
`_.external + 2`. Running it with `external: [1, 2]` gives the JavaScript
string `"1,22"`. The compiler should decline with `untyped-input` and include
`external` in `unsupported`. An `any` input at the same site already declines.

## Cause and options

The `inputs` route declares a temporary symbol and substitutes it into the
expression. That route must preserve the explicitly supplied contract through
reboxing and input discovery. Check the temporary binding before and after
substitution to locate the rewrite that turns `unknown` into a scalar type. A
host can supply a settled contract or skip compilation when the contract is
unknown.
