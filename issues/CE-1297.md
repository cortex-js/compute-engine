`Beta(-1/2, -1/2)` has the numeric value NaN; it is 0.

## Witness

On main:

```
ce.box(['Beta', ['Rational', -1, 2], ['Rational', -1, 2]]).N()   // NaN
```

B(−1/2, −1/2) = Γ(−1/2)² / Γ(−1), and Γ(−1) is a pole, so the value is 0.

## Cause and options

Not examined; the numeric kernel probably divides by Γ(a + b) at its pole. Return 0 when `a + b` is a non-positive integer and neither `a` nor `b` is. Size S.
