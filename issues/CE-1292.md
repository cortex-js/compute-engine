The compiled derivative of a complex-valued special function is about 0 at every point.

## Witness

On main:

```
compile(ce.box(['D', ['LerchPhi', 0.3, 'x', 2], 'x'])).run({ x: 2 })   // -1.73e-17
```

The value is about -0.219975 (central difference of the interpreter, reported by the reviewer). Before PR #575, `D(LerchPhi(x, 2, 1.5), x)` at 0.1 compiled to -1.26e-16 against 0.17795; PR #575 gave that case a closed form. `HurwitzZeta`, whose kernel is real, is correct.

## Cause and options

The numeric fallback `_SYS.nd((x) => _SYS.clerchPhi(…), 1, 'scalar')` differentiates a function that returns `{re, im}` as if it returned a number. Options: decline the numeric derivative when the differentiated kernel returns a complex value, or differentiate the real and imaginary parts. Size M.
