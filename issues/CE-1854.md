A congruence with a side that is not an integer gives false, where it should stay unevaluated or use the modular inverse.

## Witness

```
Congruent(Sqrt(2), 0, 3)   // False
Congruent(1/2, 2, 3)       // False, though 1/2 is 2 modulo 3 (2 * 2 = 4 = 1)
```

Measured at 074e6347f39717e4f6d5b44521c5c459b6d9d2b7.

## Cause and options

The code comment of `Congruent` (`library/relational-operator.ts`) says a non-integer side leaves the call unevaluated, but the handler answers `False`. Options: (a) leave the call unevaluated for a side that is not an integer, as the comment says; (b) read a rational side through the modular inverse when its denominator is invertible.
