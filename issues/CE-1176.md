For a few GLSL programs that pass caller code to the compiler, `canCompile()` says yes and `compile()` then declines.

## Witness

With `vars: { V: <a constructor in GLSL, for example "vec3(a, b, c)"> }` and
`W` caller code, each of these gives `canCompile(expr, { to: 'glsl', vars })`
= `{ ok: true }`, and `compile()` throws:

- `W + max(V)`, `(W, max(V))`, `W + sum_(k=1)^(n)(W + k)`,
  `W + sum_(k=1)^(3)(k * max(V))`: "its code would be computed in a
  statement ahead of the rest of its statement, and code supplied by the
  caller … would then run out of the order of the interpreter"
  (`gpuAssertHoistKeepsCallerOrder()`).
- `If(c, max(V), 0)`: "a conditionally-evaluated branch contains a
  multi-statement construct".
- A user function `f(u)` with a parameter named `discard` (a word that GLSL
  reserves) and no declared type: the pass predicts that the call is written
  in place, so it checks no parameter name; the emitter first writes the
  specialized definition, and `gpuCheckIdentifier()` refuses the name.

The tests are in `test/compute-engine/compile-gpu-extremum.test.ts` and
`test/compute-engine/compile-gpu-user-functions.test.ts`. The agreement run of
the GLSL tests lists 9 such expressions (11 test calls) and none in the other
direction. `compile()` declined each of them before the fragment pass too: no
program lost its GPU code.

## Cause and options

The emitter decides the order of caller code from the code it writes: whether
a statement sink is free and what the common-subexpression pass binds. The
pass runs before that code exists.

- (a) The emitter binds each piece of caller code to a local once, before its
  statement, so its order never depends on the hoisting. This also removes
  the refusals of `operandsWrittenTwice()` in `glsl-fragment.ts`. Size M.
- (b) A decision-only copy of the hoisting rule in the pass. It must follow
  the emitter at each change.
- For the `discard` case: take the specialization decision out of
  `ensureSpecializedUserCallEmitted()` in `compiler-core.ts` into a function
  that emits nothing, and call it from the pass. Size S.
