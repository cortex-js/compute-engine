A sum over a list and over a long range of integers runs out of memory and stops the process, also with a time limit.

## Witness

At `9f998cb4afacd2ad1fdb430fb77d983fd81ae8d2`, with `ce.timeLimit = 2000`:

```ts
ce.box(['Sum', ['Multiply', 'j', 'k'],
  ['Element', 'k', ['List', 1, 2]],
  ['Limits', 'j', 1, 1e8]]).evaluate();
```

The process stops after about 8 s with a JavaScript heap out-of-memory error.
Right: the time limit stops the evaluation, as for the same sum with only the
`Limits` clause, which streams its terms.

## Cause and options

`reduceElementIndexingSets` in `src/compute-engine/library/utils.ts` turns
each `Limits` clause of a sum that also has an `Element` clause into a list of
boxed numbers before the first term, in a loop that does not check the
deadline. Fix: stream the `Limits` wheels as
`indexingSetCartesianProductIterator` does in the path with only `Limits`
clauses, or at least call `checkDeadline(ce._deadlineFrame)` with a stride in
the loop that builds the list (size S).
