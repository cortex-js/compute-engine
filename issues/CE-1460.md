More special values stay unevaluated: `clausenCl(1, 2pi/3)` is `-ln(3)/2` and `besselJ(1/2, 0)` is 0.

## Witness

Epsil CLI, main 9777d22c1: `clausenCl(1, 2pi/3)` stays `ClausenCl(1, 2/3 * pi)`; its value is
`-ln(2 sin(π/3)) = -ln(3)/2`. `besselJ(1/2, 0)` and `besselJ(3/2, 0)` stay
unevaluated; `J_ν(0) = 0` for every `ν > 0`. CE-1394 added `clausenCl(1, pi/3)`
and `besselJ(n, 0)` for an integer `n`.

## Cause and options

Fix: `ClausenCl(1, θ)` with `θ` a rational multiple of π folds to
`-ln|2 sin(θ/2)|` when that simplifies (π/3, 2π/3, π/2, π, …); `BesselJ(ν, 0)`
is 0 for every real `ν > 0` and 1 for `ν = 0` (a negative non-integer `ν`
is a pole).
