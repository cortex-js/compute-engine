Applying a function to its own result several times gets slower at each level, because each level copies the whole previous result.

## Witness

Tycho reproduction `scripts/repros/2026-10-17-inert-pointlist-chain.mts` (101
points): 0.25 s at depth 9. In `inert-evaluate-memo.test.ts` the distinct
nodes are 39, 60, 95, 144, 207, 284 at depths 1 to 6. No document is blocked.

## Cause and options

The memo `_memoizedLazyCollectionValue`
(`boxed-expression/boxed-function.ts`) is keyed on the `any` axis, which each
call advances (`declareParameterActivation`, `function-utils.ts`); the result
is a new node with no entry. Do not add a test that returns the node when its
rebuilt result is the same: it costs more (692 against 230 ms at depth 9).
Possible fix: the activation advances nothing (as `parameter` in
`axisMaskOf`, `engine-configuration-lifecycle.ts`), but the body's symbols
cache their type on the `any` axis, so the type cache needs a key that the
activation does not move.
