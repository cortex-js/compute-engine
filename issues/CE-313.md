In Tycho, the derivative of a 29-piece path is rebuilt after any change of a variable, about 18 ms each time.

## Witness

`D(PointY(h(u)), u)` for Tycho's 29-piece path (a symbolic list) costs about
18 ms each time it is evaluated again after any assignment. Evaluated again
with no change in between, it is a memo hit (0.1 ms).

## Cause and options

The memo for unevaluated nodes is keyed on the `any` axis, and a result node
has no entry. Same cause as CE-321; fix it with that design. Two fixes were
considered: seed the memo of each result node with itself (this assumes that
`evaluate()` is idempotent), or test whether the rebuilt result equals the
node (CE-321 measured that this costs more than it saves).
