In a scope where the user defines a function named `Divide`, a substitution into a product with an exact radical number such as `√2/2` gives the value of the user's function.

## Witness

At commit `7b5ebf46fc30852681ff9167781295c9a28fc999`:

```ts
ce.pushScope();
ce.declare('Divide', 'function');
ce.assign('Divide', ce.expr(['Function', 1000, 'u', 'v']));
const e = ce.expr(['Multiply', 'x', ['Power', ['Sqrt', 2], -1]]);
e.json                          // ["Multiply", ["Divide", ["Sqrt", 2], 2], "x"]
e.subs({ x: 2 }).evaluate()     // 2000; must be √2
ce.popScope();
```

`crafted`: the program defines a user function with the capitalized name of
a library function and substitutes in its scope.

## Cause and options

`BoxedNumber.subs()` (`boxed-number.ts`) substitutes into `this.structural`,
which boxes `this.json` again with `ce.expr(…, { form: 'structural' })`. The
MathJSON `["Divide", ["Sqrt", 2], 2]` of the literal is then bound by name in
the current scope, to the user `Divide`. Option: return the literal itself
from `subs()` when the substitution does not name an operator of its
structural form, or build the structural form with the library operators
(`libraryFn()`, `library-shadowing.ts`, added by CE-1760). Related: CE-1760,
CE-1784.
