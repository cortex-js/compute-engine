The Epsil static check reports a value as possibly absent inside a function defined in an `if !isMissing(v)` block, where the test proves it present.

## Witness

`if !isMissing(v) { let g = () => f(v) … }` reports `v` as possibly absent.

## Cause and options

The narrowing of `src/epsil/presence-narrowing.ts` does not enter a function
literal, and it stops at a reassignment of the guarded name (§9, slice S3, of
`docs/plans/2026-10-21-presence-contracts-and-assertion.md`). A literal can run
after a later reassignment, so the fix may enter a literal only when no later
statement of the region assigns the guarded name.
