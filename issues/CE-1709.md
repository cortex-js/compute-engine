A drawing that uses a recursive definition calling itself more than once, such as a point sequence P(i) built from P(i-1) twice, takes seconds instead of milliseconds.

## Witness

CE 0.198.1. F(n) = Which(n = 0, 1, True, F(n-1) + F(n-1)), first evaluation
of F(14), median of three runs on a new engine each:

- assigned on an engine scope (`ce.declare("F", "function")`, then
  `ce.assign`), control: about 8 ms. Its type has no effect label.
- the same function as a function row of a prepared Document, with no
  stated effect: about 482 ms, type `(unknown) any -> number`.
- the row with `effects: "pure"` stated: 0.8 ms.

The body is pure, but the prepared row gets the effects `any`, so the engine
keeps no result of an application and evaluates each path: 2^n evaluations
at depth n. Expected: a recursive row whose body has no effect is inferred
`pure` (or gets no effect label, as the assigned function does) and its
applications are memoized.

The instrument prints `CE-1709: READY` when the row without a stated effect
takes at most 2 times the assigned control.

## Cause and options

Not investigated on the CE side. The effect inference of a row that calls
itself seems to give up on the recursive call and return `any`.

Mutual recursion (A calls B calls A) has the same effects `any`, and the
host has no workaround for it.

Tycho half on adoption: remove the `effects: "pure"` statement on
self-recursive function rows (`pureRows` in
`src/graph-paper/graph/document-ce-manager.ts`) and the test assertion that
pins it (`tests/node/ui/document-ce-manager-recursive-clauses.test.ts`).

## Fix

`settle()` in `src/compute-engine/document-preparation/prepare-document.ts`
gave the provisional contract of a cyclic row with no stated effect the
effects `any`, so the body's calls of the component, and then the row, had
`any`. The component now starts with no effect assumed and settles again
with the union of the assumed and inferred effects while a body's effects
are outside the assumed set: the least set that holds the body's effects.
The instrument, copied to this repository, prints READY (row 2.6 ms, control
12.0 ms, depth 14; the row's type is `(unknown) pure -> number`). A mutual recursion with pure
bodies is pure too; a body that draws a random number, or calls a row that
does, gives `random`.

Tycho half: the `pureRows` statement in
`src/graph-paper/graph/document-ce-manager.ts` and its test assertion can be
removed on adoption.
