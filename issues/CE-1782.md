The editor colors a backslash at the end of an unclosed single-line string as a valid escape, but the parser reports it as an invalid escape.

## Witness

`epsilHighlightTokens('let s = "C:\\')` gives the style `escape` to the
range `[11, 12]` of the last `\`. `parseEpsil` of the same source gives
`invalid-escape-sequence` (`\`).

## Cause and options

`escapeLength` in `src/epsil/highlight.ts` returns
`{ length: 1, valid: true }` for a `\` at the end of the line, because in a
`"""` string it is a line continuation. In a single-line string it is not.
Pass the kind of string to `escapeLength` and return `valid: false` for a
single-line string.
