The integral of `x^10 e^{-x}` waits about 1.5 s and then comes back unevaluated, although the integral of `x^8 e^{-x}` comes back as a formula in a tenth of a second.

## Witness

Measured on commit `40ba059a8444959fbcfb94fe393d1a540d423088`, on a loaded
machine (one engine, calls in sequence):

| Program | Time | Result | `antiderivativeStats` |
| --- | --- | --- | --- |
| `\int x^{8} e^{-x}\,dx` `.evaluate()` | about 100 ms | `-x^8 e^{-x} - 8x^7 e^{-x} - …` | 2,070 steps |
| `\int x^{10} e^{-x}\,dx` `.evaluate()` | about 1.8 s | unevaluated | 100,001 steps, `spent: true` |
| the same, a second time | about 1.4 s | unevaluated | the same |
| `\int x^{12} e^{-x}\,dx` `.evaluate()` | about 1.4 s | unevaluated | the same |
| `\int_0^\infty x^{10} e^{-x}\,dx` `.evaluate()` | about 1.4 s | unevaluated | |
| `\int_0^\infty x^{20} e^{-x}\,dx` `.evaluate()` | about 1.5 s | unevaluated | |
| `compile()` of either definite integral | about 1.5 s | compiles (numeric) | |
| `.N()` of `\int_0^\infty x^{10} e^{-x}\,dx` | about 50 ms | `3628800 ± 0.00003` | |

A value exists: `∫ xⁿ e^{-x} dx = -e^{-x} Σ_{k=0}^{n} n!/k! x^k`, and the
definite integral is `n!`. Each call spends the whole budget again: nothing
remembers that the search failed. `compile()` pays it before it falls back to
quadrature. Test: `test/compute-engine/integrate-log-space-product.test.ts`.

## Cause and options

`antiderivative()` (`symbolic/antiderivative.ts`) reaches
`ANTIDERIVATIVE_STEP_BUDGET` (100,000 steps): repeated integration by parts
of `xⁿ e^{-x}` grows faster than linearly in n, so the budget that n = 8 fits
in is spent at n = 10.

- (a) A rule for `p(x)·e^{ax+b}` with a polynomial `p` of any degree: the
  closed form `e^{ax+b} Σ_k (-1)^k p^{(k)}(x)/a^{k+1}`, n + 1 derivatives of
  `p`. Linear in the degree. Size S to M. The same rule covers
  `p(x)·sin`, `p(x)·cos` with a two-term version.
- (b) Remember a spent budget per integrand and variable for the life of the
  engine, so that a second call costs nothing. It does not help the first
  call. Size S.

(a) removes the case; (b) is a separate guard for the integrands that have no
elementary antiderivative.
