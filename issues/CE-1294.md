Reading a long hexadecimal numeral with a `0x` prefix loses its last digits.

## Witness

On main:

```
ce.box(['DigitsFrom', { str: '0x1fffffffffffffffff' }]).evaluate()   // 590295810358705700000
```

The value is 2⁶⁹ − 1 = 590295810358705651711. PR #528 made the other bases exact.

## Cause and options

The `DigitsFrom` handler in `library/core.ts` reads the `0x` form with `parseInt(op1str.slice(2), 16)`. Use `BigInt('0x' + …)`, or the exact `fromDigits()` route of the other bases. Size S.
