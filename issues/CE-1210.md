With binding units on, symbolic work and interpreted function calls are slower: parsing and simplifying undeclared symbols by about 1.3 times, loading the integration rules by about 1.7 times, an interpreted call in a Tycho document by 1.1 to 1.3 times.

## Witness

```
const ce = new ComputeEngine();
for (let i = 0; i < 2000; i++) ce.parse('a x^2 + b x + c').simplify();
```

Measured 2026-11-11 under the box lock, one worker, at `8868a2aba` (units
off / units on):

| Case | Off | On |
|---|---|---|
| parse-and-simplify loop of ten expressions, 2,000 rounds | 3.0 to 3.3 s | 4.0 s |
| `integration-rules.test.ts` | 8.5 s | 15 to 16 s |
| `rubi-utils.test.ts` | 6.1 s | 10.5 to 13 s |
| `integration-rules-substitutions.test.ts` | 13.5 s | 22 to 23 s |
| `ce-882-shared-copies.test.ts` (CE-1200) | 5.7 s | 27 to 30 s |

With the symbols declared, the loop is within 5 to 9% (CPU time, 3,000
rounds: 443 to 450 ms off, 477 to 483 ms on).

Tycho's codegen audit (115 documents, one run for each arm): no changed
code, no new decline; document times 41.0 s off, 52.5 s on (1.28 times).

## Cause and options

Each read of the type of a free name finds the entry of its unit and
resolves the name in the current scope (`BoxedSymbol._unitType()`); the
loop above makes 3.4 million such reads. The cached type of a compound
expression records three reads for each free name under it
(`binding-unit.ts`), and each hit of the cache computes the three versions
again and merges them (`object-deps.ts`). Without binding units a hit
compares one number (`ce._typeCacheGeneration()`).

Options:

1. One engine-wide counter that moves at every change that the type of a
   free name can depend on: a write in a unit environment, the start and the
   end of an operation or a trial, a change of the current scope, a write of
   a binding of a scope (about 60 sites), a change of a scope's parent, a
   change of the static view. A cached type is then valid with one comparison. A
   missed site gives a stale type.
2. One recorded read for each free name in place of three. It divides the
   walk at each hit by three.
3. Leave it: document that a host declares its symbols.

## Declared names (2026-11-11, from Tycho)

A document whose names are all declared also pays. Tycho's `othello`
showcase evaluates `legal(B, B[65])`, a call of a typed Epsil function, on
the interpreter: 3.2 s off, 4.2 to 4.6 s on for the document. Instrument in
Tycho: `scripts/repros/2026-11-11-ce1210-othello-prelude-call-timing.mts`.
A CPU profile of that call on CE source (`fdbbf5091`): 9.6 s off, 10.8 s
on. The added time is in the reads of the symbols of the function body,
which have definitions: the recording of reads for the caches (240 ms),
the lookup of the environments of the operation (145 ms), and the
resolution of the symbol in the current scope at each type read
(`_contextBinding()`, about 290 ms). A host declaration does not remove
it; option 1 covers it.

## Decision

User decision 2026-11-11: Tycho declares the type of its axes, then uses `ce.infer()` where it applies. If the cost remains, Tycho comes back and CE profiles and fixes. No design work on the options until then.

## Two reads removed (2026-11-13)

A count of the type reads of one `legal(B, B[65])` call, by caller
(`~/dev/compute-engine-recovery/fc-typereads/report.md`): 1,799,470 reads
and 98,227 type computations, every one a cache miss (the type version
moves 13,306 times in the call: 7,412 value writes, 5,894 scope pops).
Three callers start about 92% of the reads: the check of the arguments of a
call (`makeLambda`, `function-utils.ts`), which derived the signature of
the literal and so typed its body twice per call; the purity test of
`BoxedFunction.evaluate` (`latentEffectsOf`, `effects-of.ts`); the
element-wise test of a connective (`isCollectionShaped` under
`evaluateConnective`).

Changed, with the invalidation as it was: the check of the arguments reads
`functionLiteralParameterSignature()` (the parameters only), and
`couldBeCallable()` answers `false` for a union none of whose arms can hold
a function. One call: 98,227 computations and a median of 1,160 ms before,
42,539 and 670 ms after (9 calls for each arm, arms alternated, load
average 18.9 falling to 10.7). No test pins the count: a small program
computes the same types on both paths.

Left: the purity test (about 84% of the remaining computations, mostly on
`Block`; the memo of `_effectsOf` misses at each evaluation, cause not
determined) and the element-wise test of a connective (about 15%; no form
that keeps every value was found). The invalidation is D16 and D17 of
`docs/plans/2026-11-11-bound-once-spec.md`.
