Under `.N()`, a recursive or looping user function that returns early with `Return(Floor(x))` uses the rounded argument and gives the wrong integer.

## Witness

```
r := x ↦ Block(If(x < 30, Return(Floor(x))), r(x − 1));  r((25! − 1)/24!).N()
  gives 25, should be 24
```

The same holds, by the code, for a body with a `Loop`, a function literal or
a call of another user function, and for a written argument that reads a
variable (not probed).

## Cause and options

The fix of CE-965 binds a parameter to the exact value of its written
argument under `.N()` (`exactBoundArguments` in `function-utils.ts`) only
when the body runs each node at most once (`isStraightLineJumpBody`) and the
argument reads only constants. An exact rational that goes through a loop or
a recursion can double in size at each step (`z := 4z(1 − z)` eighteen times
took 52 s, the float 14 ms), so such a body keeps the float, and a jump in a
statement before the last one reads it. Options: a re-read of the exact
argument by a jump in any statement (the evaluation option that only the
jumps honor, CE-179 family), or close as accepted.
