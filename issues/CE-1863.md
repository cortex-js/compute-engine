An Epsil program that adds to a constant with `+=` is reported only when it runs, where the same write with `=` is reported before it runs.

## Witness

Checked at `d13f9c832b7713e8d4def65266d471f54a579efd`, with `executeEpsil`:

```epsil
const c = 1
c += 1
c
```

The value is `1` and the diagnostic is
`runtime-error: cannot assign a value to the constant c` (`constant-assignment`).

Control: `const c = 1; c = c + 1; c` gives the diagnostic
`static-type-error: cannot assign a value to the constant c`, with the source
of the statement, before the program runs. An editor shows the second one
while the user types and not the first.

## Cause and options

The static check of `src/epsil/static-diagnostics.ts` (`registerConstant()`)
reads the writes of a name from `Assign`. A compound assignment is
`AddTo(c, 1)`, which the check does not read as a write of `c`.

- (a) Read an `AddTo` whose target is a name as a write of that name
  (recommended). An `AddTo` whose target is an index of a constant that holds
  a list is the same case; one whose target is a cell of an array is a store,
  not a write of the name (`cellStoreSites()`).
