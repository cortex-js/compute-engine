A function with a pair parameter, a rest parameter or a default value, written as LaTeX and read back, is a different function.

## Witness

```
["Function", ["Multiply", "x", "y"], ["Tuple", "x", "y"]]   one pair parameter
written (x,y)\mapsto xy, parsed as two parameters (checked 2026-11-06)
((x,y)\mapsto xy)((3,4))   12; the parsed form gives (_) => (3 * _, 4 * _)
\mathrm{Spread}(x)\mapsto2x     (rest parameter) parses to an error
(x, k=2)\mapsto kx              (default value, CE-717) parses to an error
```

## Cause and options

The `Function` serializer (`definitions-core.ts`) writes the parameter as a
plain operand, and the parser has no notation for these forms
(`parameter-default-values.test.ts` records the default-value case).

- (a) Write the pair parameter `((x,y))\mapsto xy` (the Epsil spelling), a rest
  parameter `x\ldots\mapsto` or `\ldots x\mapsto`, and read `k=2` in a
  parameter list as `["Optional", "k", 2]`; teach the parser each form.
- (b) Write such literals as `\mathrm{Function}(…)` with their MathJSON
  operands, which the parser reads already.
