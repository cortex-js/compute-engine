Raising one to each entry of a matrix inside a function can give a single one.

## Witness

```js
const ce = new ComputeEngine();
const A = ['List',['List',1,2],['List',3,4]];
const f = ce.box(['Function',['Tuple',['Determinant','x'],['Power',1,'x']],'x']);
ce.box(['Apply',f,A]).evaluate().json;
ce.box(['Power',1,A]).evaluate().json;
```

Main 489125b returns scalar 1 in the second tuple component. Direct evaluation gives [[1,1],[1,1]]. Reversing the expressions in the tuple also gives a scalar. The exponent's cells are finite integers. The scalar identity in canonicalPower can discard the shape of an exponent. The direct concrete-array calculation is a workaround. This program was constructed to exercise the constant-base fold.
