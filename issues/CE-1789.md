The quotient of a number made at a higher precision by an exact integer has two digits fewer after the engine is set to machine precision.

## Witness

```ts
const ce = new ComputeEngine();
ce.precision = 30;
const a = ce.box({ num: '0.3' });
ce.precision = 'machine';
ce.box(['Divide', a, 7]).N();                    // 0.0428571428571429
ce.box(['Multiply', a, ['Rational', 1, 7]]).N(); // 0.0428571428571429
// double: 0.3 / 7 = 0.04285714285714286
ce.box(['Divide', a, 0.7]).N();                  // 0.42857142857142855 (17 digits)
```

## Cause

Not found. The quotient by a float goes through `apply2()`, which gives the
big-decimal kernel 20 digits at machine precision since CE-1761. The
quotient by an exact integer takes another path (the product with the exact
rational `1/7`), which rounds to `ce.precision`, 15 digits. Option: at
machine precision, compute that product at `DOUBLE_DIGITS`
(`numeric-value/big-numeric-value.ts`) and give a double, as the kernels of
`BigNumericValue` do.
