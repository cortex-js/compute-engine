A curve defined piecewise over a list of values is not compiled when the definition is stored under a name and the program reads the name.

## Witness

```ts
const ce = new ComputeEngine();
ce.declare('x', 'real');
ce.declare('C', {
  value: ce.box(['If', ['LessEqual', 0, 'x', 6], ['Add', 'x', ['List', 0, 4, 2]]]),
});
const options = { to: 'javascript', mode: 'strict', inputs: { x: 'real' } };
compile(ce.box(['At', 'C', 1]), options);
compile(ce.box('C'), options);
```

Today (the commit of CE-1606): both decline on `javascript`, and `At(C, 1)`
declines on `interval-js` (`{to: 'interval-js', symbolic: ['x']}`), "an If
with no else of a list arm whose value is read by other than At, First, Last,
an arithmetic operator or a reduction". 0.193.0: `At(C, 1)` compiles on both
targets and gives 1.5 at x = 1.5 and NaN at x = 7; `C` alone compiles and
gives `[1.5, 5.5, 3.5]` at x = 1.5.

The same `If` written in the program compiles since CE-1606:
`At(If(0 ≤ x ≤ 6, x + [0, 4, 2]), 1)` gives 1.5 and NaN.

Workaround: write the `If` in the program, or give it an else
(`List(NaN, NaN, NaN)`).

The probability is `medium`: a host that keeps a definition as the value of a
name and compiles a read of that name. Tycho writes the definition into the
program, so its documents do not reach this case.

## Cause and options

`nanForAbsent()` of `compilation/ir/lower.ts` accepts the list of NaN for the
missing else only for a node of the program, because it must know every
operator that reads the value: a discharge, `Length` or `Rest` must see an
absent list (`docs/COMPILATION-MODEL.md`, the restriction paragraph). The
value of a name is lowered by `expression()` at each read of the name, and its
nodes are not nodes of the program, so they have no known reader.

Option (a), recommended: treat the root of the value of a name as read by the
readers of each occurrence of the name in the program, and the nodes under it
by their readers in the value. It needs the occurrences of the name in the
values of other names and in the bodies of user functions too, because one of
them can be `Length(C)`: when one such read is found after the list of NaN was
accepted, the compilation declines. Size M.

Option (b): keep the decline and document it next to the restriction paragraph
with this example.
