An integral whose differential is written with the MathLive command `\differentialD` inside a fraction, `\int_1^2 \frac{\differentialD x}{x}`, gives an error.

## Witness

Readings of 2026-11-06, at commit `23db78e092dd67fa2ec95c360ee73dbf35e1b1ea`:

```
\int_1^2 \frac{\differentialD x}{x}   evaluate() gives Error("unexpected-command", "\differentialD")
\int_1^2 \frac{dx}{x}                 gives ln 2 (correct)
\int_1^2 \frac{1}{x}\differentialD x  gives ln 2 (correct)
```

The workaround is to write `d` or `\mathrm{d}`.

## Cause and options

`matchDifferentialOperator()` in
`latex-syntax/dictionary/definitions-calculus.ts` reads `\differentialD` at
the top level of the integrand. Inside a fraction the token goes to the
general expression parser, which has no entry for `\differentialD`. Fix:
read `\differentialD` as the symbol that `parseFinalDiffOperator()` accepts
(`d_upright`), so that the search in a sub-expression finds it.
