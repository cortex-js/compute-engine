The Buddhabrot document's step button no longer runs in time: the action that adds 5000 samples falls to the interpreter and passes its deadline.

## Witness

The instrument holds the MathJSON that Tycho passes to `compile` for the
action body (recorded on CE main 933bda7b707c8d361f14e277e9d67b8a379c6c13):
`Apply(Function(Block(Declare(L_gpBound, {value: H_gpBound}), …, Loop(…)),
Typed(H_gpBound, 'list<integer>'), Typed(n_gpBound, 'integer')), H, 5000)`,
the `step` function of the prelude bound to the document row `H`. Engine:
`H` declared `list<nan | real | signed_infinity>` (a Desmos-style row type),
no value; options `{ to: 'javascript', symbolic: ['H'] }`. Run on 90,001 zeros.

- 0.193.0: compiles; 90,001 elements, last element 5000; 3 ms.
- 933bda7: declines, at three forms in this order:
  1. "H: an argument of Apply that is not list<integer>, the type of its
     parameter H_gpBound". From CE-1469's review rule (the argument's static
     type must prove the parameter's type). For a list parameter the
     interpreter binds the list whole without checking its elements
     (compute-engine-8c's probe: a `list<real>` argument at a
     `list<integer>` parameter gives 2.5), so CE should bind it whole on the
     argument's lane rather than decline. The rule stays for a ranged scalar,
     where the interpreter errors.
  2. "the list local L_gpBound, written in place, read other than by At or
     Length (an alias)", for `let L = H` and the writes that follow: the
     alias rule of CE-1462.
  3. "Declare(L_gpBound, {value: H_gpBound}): a write to a constant … or to a
     list local other than ReplaceAt or AddTo of an element": CE-1481 item 1.

## Expected

The action body compiles on javascript as on 0.193.0. compute-engine-8c
(2026-11-18): CE's, handled with CE-1480 and CE-1481. Tycho does not retype
the parameter.
