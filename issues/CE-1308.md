A series at a finite point of a function with an absolute value, a step or a square root of a square loses a term or has the wrong sign on one side of the point.

## Witness

At commit `a0d4bde009368a0702ae5977d5b022a8d731fb32`:

```
Series(Abs(x), x, 0, 3)                       // BigO(x^4); |x| has no Taylor series at 0
Series(Floor(x), x, 0, 3)                     // BigO(x^4); ⌊x⌋ is −1 for −1 ≤ x < 0
Series(Sign(x), x, 0, 3)                      // BigO(x^4)
Series(Sqrt(x^2), x, 0, 3)                    // x + BigO(x^(9/2)); √(x²) = −x for x < 0
Series(Sqrt(x^2 + x^4), x, 0, 3)              // x + x³/2 + BigO(x^(9/2)); wrong for x < 0
```

## Cause and options

`symbolic/series.ts`: the Taylor engines differentiate `|x|` to `Sign(x)` and a step to 0, and evaluate the derivative at the point, where `Sign(0) = 0`; the Puiseux step (`puiseuxPower()`) takes `(x²)^{1/2} = x`, which holds for `x > 0` only. CE-1293 fixed the same defect at ±∞ (a decline when `x` is under `Abs`, `Floor`, `Sign`, …, `NON_SMOOTH_OPERATORS` in `series.ts`, and an expansion at `s = 0⁺` for −∞). Options: decline at a finite point when a non-smooth operator's operand is 0 (or a step's operand is an integer) at the point, and when the Puiseux step takes an even root of a leading term with an even power; or expand the two sides and keep the result only when they agree. The first is the simple sound one.
