At machine precision, a Bessel function of the second kind of a large order and a small argument is NaN instead of an infinite value.

## Witness

On main at `a11746d277bc426849143b3f64377b5a64f97f37`:

```
ce.precision = 'machine'
ce.box(['BesselY', 200, 1]).N()   // NaN
ce.precision = 30
ce.box(['BesselY', 200, 1]).N()   // -2.01954484943397321989431719094e+432
```

The value overflows a double, so the machine result should be `-oo`.

## Cause and options

Not examined. The machine kernel probably computes `Infinity - Infinity` or `0 * Infinity` in its recurrence. Return `-oo` when the recurrence overflows. Size S.
