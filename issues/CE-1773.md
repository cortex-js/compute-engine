In a Tycho notebook, a click handler or a timer callback that changes a cell variable gives a run error when it is created inside a `function`, so authors must write `let scene = () => …` instead of `function scene() { … }`.

## Witness

`store` is a library function declared with `effects: ["state"]` that keeps
its argument and does not call it, as Tycho's `figureOn` and `figureTimer`
do. On CE 0.201.2:

```epsil
let r = 1
function scene() { store(e => do { r = r + 1 }) }
scene()
```

The instrument prints:

```
let lambda (control): ok, value "True"
function: error: runtime-error,expected `non-scope effects (writes outside a function require a declared `scope` effect)`, got `scope state effects`,,incompatible-type
function with print in the callback, scope declared: error: runtime-error,expected `scope effects`, got `console scope state effects`,,incompatible-type
CALLBACK-EFFECTS: NOT READY
```

The control is the same body as `let scene = () => store(…)`. Declaring
`scope` on `scene` does not help when the callback also prints or calls a
library function with `any` effects (Tycho's `draw`): then every effect must
be declared, and `any` cannot be.

## Cause and options

Effect inference counts the effects of a lambda that appears as an argument
as effects of the enclosing function, as if the callee called it. Here the
callee stores it; the write to `r` happens later, when the host calls the
lambda in the scope it closed over.

Options:

1. A lambda that is an argument contributes its effects to the enclosing
   function only when the callee is known to call it (a library function
   could declare its function parameters as `stored` or `called`; a stored
   callback contributes nothing).
2. A lambda's writes to names it closes over are not counted as `scope`
   effects of the function that creates it.

Tycho asks for a plain `function scene() { … }` to work for event handlers
and timer callbacks. Workaround: the `let` lambda form, which the Tycho
Programming Guide uses.

Tycho half on adoption: remove the lambda-form rule from the Programming
Guide ("Respond to Clicks", English and French) and the note about it in
`src/graph-paper/notebook/drawing/prelude.ts`, and write the guide's
example with `function scene() { … }`.
