A number written in another base does not round-trip through LaTeX: `BaseForm(42, 16)` is written `\mathrm{2a}_{16}`, which parses as a symbol.

## Witness

Epsil CLI, main 412113c86: `Latex(Hold(BaseForm(42, 16)))` gives
`\mathrm{2a}_{16}`; `parse(#"\mathrm{2a}_{16}"#)` gives the symbol
`twoa_16`, while `parse(#"\text{2a}_{16}"#)` gives 42.

## Cause and options

Option (a): the serializer writes `\text{2a}_{16}`, the form the parser
reads. Option (b): the parser reads `\mathrm{<digits>}_{<base>}` as a number
too. (a) is the smaller change; (b) also reads LaTeX written by other tools.
Add a round-trip test for a base above 10.
