A list with an element that can be left out reports a count larger than the number of elements of its value.

## Witness

With `u: real`, `[If(0 < u, Nothing, (1, 1)), (2, 3)]` has `count` 2 (checked
2026-11-06). When `0 < u`, its value has one element, because `Nothing` is
dropped. A broadcast over such a list gets the count 2.

## Cause and options

The count of a list literal does not see that an element can evaluate to
`Nothing`. Fix: a count that can depend on a free variable is `undefined`, as
for `Range(1, Floor(u))`.
