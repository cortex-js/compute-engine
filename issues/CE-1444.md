When a compilation is refused because an argument has the wrong type, the message shows internal numbers in the type, such as `list<integer^v129>`.

## Witness

The corpus program `showcase/othello#1`, on main `06d6220af769606cdaf449cbd9b43aa2cce140ef`: the decline "an argument of legal that is not …" prints `list<integer^v129>`.

## Cause and options

In `ir/lower-functions.ts`, the message calls `typeToString(declared, p.tuple)` with `p.tuple` undefined; the default `false` prints the value ids. Fix: pass the flag that omits the ids (or `true` where the parameter is not a tuple), one line.
