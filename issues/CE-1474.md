On the GPU, the distance to a short list of points no longer compiles, so the plot draws on the CPU.

## Witness

`x, y: real`;
`compile(Abs(PointList(x - List(1/2, 1), y)), { to: 'glsl' })`.

0.193.0: compiles,
`sqrt(_gpu_pow2_v2(x + vec2(-0.5, -1.0)) + (y * y))`. 0.194.0: declines,
"the region build (a Map, a Filter or a Range) on glsl".

The list component has the constant length 2. The IR README ("Lists") writes a
`Map` over a source of a constant length of 1 to 64 as the list of its
elements on GLSL; `PointList` of such a component does not take that route.
Tycho's row `\min(|(x-[1/2,1], y, z+2)|)` (a Desmos form) declines the same
way.

## Expected

Compiles on glsl.
