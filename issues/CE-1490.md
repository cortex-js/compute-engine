A function taking two expressions returns a zero matrix for two matrices whose products in opposite orders differ.

## Witness

```js
const ce = new ComputeEngine();
const A = ['List', ['List', 1, 2], ['List', 3, 4]];
const B = ['List', ['List', 0, 1], ['List', 1, 0]];
const comm = ['Subtract', ['Multiply', 'a', 'b'], ['Multiply', 'b', 'a']];
const f = ce.box(['Function', comm, ['Typed', 'a', "'expression'"],
                                    ['Typed', 'b', "'expression'"]]);
ce.box(['Apply', f, A, B]).evaluate().json;
```

On npm 0.186.0 and main 489125b, this returns [[0,0],[0,0]]. AB is [[2,1],[4,3]] and BA is [[3,4],[1,2]], so their difference is [[-1,-3],[3,1]]. Both matrices are passed whole under the declared expression contract (docs/BROADCAST-MODEL.md). Using matrix, any or value annotations gives the expected answer on main.

The product-order check in boxed-expression/matrix-operand.ts excludes expression. Preserve factor order for an expression parameter that can receive a matrix. A user computing with symbolic matrices can write such a function, although explicit expression annotations are uncommon. CE-1317 settled bare parameters; this witness uses two explicit whole-argument annotations.
