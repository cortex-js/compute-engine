Under `.N()`, a user function reads the value of an argument after a later argument has changed a variable that the first argument uses.

## Witness

```
x := 1;  g := (y, w) ↦ Floor(3y);  g(x/3, Block(x := 5, 1)).N()
  gives 5, should be 1
```

## Cause and options

Under `.N()` the caller records the written argument `x/3`
(`exactArgumentSources` in `function-utils.ts`) without evaluating it, and
the one-statement route (`applyWrittenArguments`) evaluates it again after
every argument was evaluated, so it reads `x = 5`. Fix: record only a source
that reads constants (as `exactBoundArguments` does since CE-965), or
evaluate the source when it is recorded.
