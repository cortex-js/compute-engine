A sum of partial derivatives over a subscripted variable differentiates with respect to the same variable in every term, so `\sum_{i=1}^{2} \frac{\partial}{\partial x_i} x_i^2` gives `4 x_i`.

## Witness

```
ce.parse('\\sum_{i=1}^{2} \\frac{\\partial}{\\partial x_i} x_i^2').evaluate()
                                                    ->  4·x_i
expected                                            ->  2x_1 + 2x_2
```

## Cause and options

The parser reads `x_k` in the body of a sum as `Subscript(x, k)` (CE-135),
except where an inner binder binds the name (`_subscriptBoundIndexes()` in
`latex-syntax/parse.ts`). `D` is such a binder, so `x_i` stays one name, which
does not depend on `i`. Unlike the variable of an integral, the variable of
`D` occurs free in the result, so it must follow the index.

A fix needs both: the parser stops keeping the variable of `D`, and `D` reads a
variable `Subscript(x, 1)` as the symbol `x_1` once the index has a value. Today
`D(x_1^2, Subscript(x, 1))` stays unevaluated, because the signature of `D`
takes bound symbols (`variables:symbol*`, `library/calculus.ts`).
