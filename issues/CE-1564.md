A plot of a list of curves with a domain restriction draws nothing or is computed point by point.

## Witness

`x: real`, `L: list<real>`. Compile to javascript:
`If(Less(0, x), Multiply(x, L))` (no else).

0.194.3: declines, "arms of two types". The interpreter gives `[2, 4]` at
`x = 2`; 0.186.0 compiled the same value. Control: the same `If` with the else
`Multiply(0, L)` compiles. Tycho writes a Desmos restriction (`f(x) {0 < x}`)
as an `If` with no else. The list-condition form declines with the same cause
in `art/2ki2hjsouf`: `If(Less(PointX(P), 20), P)` with `P` a list of points,
"an If of a list condition with no else and a list arm".

Found by the Tycho codegen audit of 2026-11-19: the same MathJSON, with the same options, compiled to JavaScript on CE 0.186.0 and declines on 0.194.3 and on the CE main build of 2026-11-19 16:57, in the document context and on a bare engine. Tycho's instrument `scripts/repros/2026-11-19-ce1560-js-decline-regressions.mts` prints one READY / NOT READY line per issue (READY on 0.186.0, NOT READY on 0.194.3).

## Cause and options

The missing else is typed as a scalar `Nothing` and does not unify with the list
arm. Options: (a) give the missing else the shape of the other arm, filled with
`NaN` (recommended: it is what 0.186.0 compiled and what a restriction means);
(b) document that a list arm needs an explicit else. With (b), Tycho can write
the else itself (workaround).
