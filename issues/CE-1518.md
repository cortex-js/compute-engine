Reading the type of one call in a cycle of three recursive functions first takes about half a minute.

## Witness

CE-1515's definitions (`a_2`, `b_2`, `c_2` declared `function`, an integer
base case): reading `b_2(m).type` first takes 23.5 to 31 s; every other
first read takes about 0.3 s. The same on 0caa86406 (before cbd971112), so
older than CE-1515.

## Cause and options

Not investigated; likely the re-derivation of the cycle through the
in-flight reads (compare CE-1516 for heads declared `(unknown) -> unknown`).
