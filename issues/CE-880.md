A filter or an any-test whose condition is a named function is never sped up by compilation, while a map with the same function is.

## Witness

```
filter(1..20000, isEven)    with isEven(n) = n % 2 == 0
```

Each element applies the function in the interpreter, about 100 µs per
application (CPU profile of 2026-10-07). See CE-325 for the full-size Project
Euler programs.

## Cause and options

The compiled element function of `Map` (`library/map-auto-compile.ts`) takes a
named user function: the exact tier at any precision, the marked tier at
machine precision. A `Filter` or `Any` predicate returns a boolean, and no tier
takes it. Option: a tier for a boolean predicate.
