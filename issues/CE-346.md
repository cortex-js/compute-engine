Compiling the derivative of a deeply nested formula spends 1 to 2 s per derivative before it falls back to a numeric approximation.

## Witness

Tycho item 177; bare-engine reproduction `docs/scratch/d209-ce-asks-repro.mts`
in `dev/tycho`. Tycho's Taylor example pays the cost three times, once per
order. Before the fallback existed: order-1 compile 6/21/77/429 ms at depth
1/4/8/16, a throw at depth 37.

## Cause and options

Past the differentiation growth budget, the javascript compile emits an
8th-order centered-difference stencil (`_SYS.nd`), bit-identical with
interpreted `N()` (`compile-derivative-numeric-fallback.test.ts`). The failed
symbolic attempt still runs to the budget once per derivative node per
compile, and the `derivative()` call of each order runs the shared first
differentiation again. Option (CE-346.1, only if Tycho's compile-time
requirements fail): an over-budget memo keyed on the resolved function literal
(shared across sibling `Derivative(f, k)` nodes) and the semantic version. Do
not lower the budget: that changes which expressions get exact derivatives.
