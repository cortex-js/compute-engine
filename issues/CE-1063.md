A substitution into a block that reads a variable and then assigns it does not replace the variable.

## Witness

```
ce.declare('a', 'real')
Block(Assign(a, a + 1), a).subs({a: 2}).evaluate()   ->  a + 1   expected 3
```

The `unknowns` of this block are `['a']` (the fix of CE-1017), but `subs()`
does not replace `a`.

## Cause and options

`subsBinderView()` (`boxed-function.ts`) counts every statement target of a
`Block` as a local, so it never replaces the name. Replacing every `a` gives
`Assign(2, 3)`, which is not valid. A correct substitution replaces only the
reads before the first write, or adds a first statement `Assign(a, 2)`.
Size M.
