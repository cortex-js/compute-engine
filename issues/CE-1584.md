The generalized harmonic number of a very small number with a complex order evaluates to zero.

## Witness

`ce.function('HarmonicNumber', [ce.number(ce.complex(1e-30, 1e-30)), ce.number(ce.complex(2, 1))]).N()`
gives `0` with the CE-1572 fix. The value is about
`1.5520870099659352e-30 + 3.1733523581160522e-30i` (mpmath at 100 digits,
`zeta(r) - zeta(r, n + 1)`, and the first term of the series, `r·ζ(r + 1)·n`).

## Cause and options

The series near n = 0 (`harmonicNumberNearZero()`) and the exact polynomial
of an integer order r ≤ 0 take a real order only. A complex order goes to
`ζ(r) − ζ(r, 1 + n)` in machine complex arithmetic, which cancels to 0 for a
tiny n. Option: the same series with complex coefficients `(r)_j/j!` and a
complex `ζ(r + j)` (`zetaComplex`), at machine precision, for |n| < 0.1.
