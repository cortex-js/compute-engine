The limit of e^√x / x^5 as x grows without bound gives 0; the correct value is +∞.

## Witness

```
\lim_{x\to\infty} e^{\sqrt{x}}/x^5      gives 0,  should be +∞
\lim_{x\to\infty} x^5/e^{\sqrt{x}}      gives +∞, should be 0
\lim_{x\to\infty} e^{\ln(x)\ln(x+1)}/x^9  gives 0,  should be +∞
```

## Cause and options

`symbolic/limit.ts` ranks `e^g` above every power of `x` only when it proves
`g → +∞`. `tendsToInfinity` has no rule for `Sqrt`, `Root` or a product, so
the comparison uses samples at `x = 8, 30, 120` (`numericGrowthCompare()`),
which give a wrong answer.

User decision 2026-11-05: option (c), both parts:

- (a) Rules: `Sqrt`/`Root` in `tendsToInfinity`; `exponentialLevel()` ranks
  `b^g` when `g` grows like a power of `x` or like `(ln x)^p` with an exact
  degree `p > 1` (a float exponent read as its exact binary value).
- (b) The samples never decide a limit: it stays unevaluated, or the probes
  move out as in Gruntz's algorithm.

A patch for (a) alone failed three review rounds. Full text: ROADMAP.md at commit 5784d4aec.
