The series of `Arctan` or `Arcsin` takes seconds at order 9 and about 20 seconds at order 11.

## Witness

On main at `fed2ad56317cc2a41f1124414bdc7c97d857d83a`, a new engine per call:

```
ce.box(['Series', ['Arctan', 'x'], 'x', 0, 7]).evaluate()   // 1,781 ms
ce.box(['Series', ['Arctan', 'x'], 'x', 0, 9]).evaluate()   // 6,176 ms
```

The reporter measured 21,554 ms at order 11. The values are right. Impact
`major`, not `minor`: no host budget admits 20 s for a series of order 11.
Probability `medium`: a series of an inverse function at a high order.

## Cause and options

`unaryTaylor` (`symbolic/series.ts`) differentiates `Arctan(v)` once per
order, and the unsimplified derivative grows with the order. PR #589
(+236 −0, `symbolic/series.ts`, a test, CHANGELOG) expands `f'(v)` with the
coefficient arithmetic of `powerSeries` and integrates term by term, for
`Arctan`, `Arcsin`, `Arccos`, `Arccot`, `Arsinh` and `Artanh`. Work:
review the PR (the Arccot branch must follow CE-1334), then the user merges it
on GitHub or the patch lands here. Size S.
