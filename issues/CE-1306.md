At machine precision, the logarithmic integral of a huge argument has a relative error of about 2e-14.

## Witness

On main at `a11746d277bc426849143b3f64377b5a64f97f37`:

```
ce.precision = 'machine'
ce.box(['LogIntegral', 1e300]).N()   // 1.4497500526693022e+297
ce.precision = 30
ce.box(['LogIntegral', 1e300]).N()   // 1.44975005266933628905061433151e+297
```

The relative error is 2.3e-14, about 100 ulp.

## Cause and options

Not examined. The machine kernel probably sums its asymptotic series in an order that loses digits at a large `ln x`. Size S.
