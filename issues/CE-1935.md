In a scope where the user defines a function named `Divide`, the simplification of an exact radical number such as `√2/2`, or its MathJSON read back in that scope, gives the value of the user's function.

## Witness

At commit `9f998cb4afacd2ad1fdb430fb77d983fd81ae8d2` with the CE-1785 fix:

```ts
const n = ce.expr(['Divide', ['Sqrt', 2], 2]);   // the number √2/2
ce.pushScope();
ce.declare('Divide', 'function');
ce.assign('Divide', ce.expr(['Function', 1000, 'u', 'v']));
n.simplify().evaluate()                 // 1000; must be √2/2
n.structural.canonical.evaluate()       // 1000; must be √2/2
n.json                                  // ["Divide", ["Sqrt", 2], 2]
ce.expr(n.json).evaluate()              // 1000; must be √2/2
ce.popScope();
```

The same applies to a user function named `Sqrt`, `Multiply`, `Negate`,
`Rational` or `Complex`. `subs()` of the number is correct since CE-1785.

`crafted`: the program defines a user function with the capitalized name of
a library function and simplifies or serializes a number in its scope.

## Cause and options

`NumericValue.toJSON()` writes the heads `Divide`, `Sqrt`, `Multiply`,
`Negate`, `Rational` and `Complex` by name. `BoxedNumber.structural`
(`boxed-number.ts`) boxes that MathJSON with `ce.expr(…, { form:
'structural' })`, which binds each head in the current scope, to the user
function. `simplify()`, `explain()`, `replace()` and `match()` work on that
structural form, and `.json` returns the MathJSON as it is.

Options: (a) build the structural form with each shadowed head bound to the
library definition and marked as a library call (`ce._libraryCall()`,
`markLibraryCall()`, `library-shadowing.ts`), and serialize a shadowed head
as `["Apply", ["Module", "Divide"], …]` as CE-1760 does. A trial in the
CE-1785 session showed that this is not enough: the canonical rebuild of a
parent that splices the structural operand (a product holding `3/4·√2` with
a user `Rational`) and the canonical handler of `Complex` (which builds
`Add`/`Multiply` by name) still read the heads by name, and the LaTeX of an
expression holding the number changed (`\frac{1}{4}\times3\sqrt{2}`). (b) In
`simplify()` and `explain()`, return the number when a head of its MathJSON
is shadowed (`shadowsLibraryName()`), which loses the simplification of the
number in that scope only. Related: CE-1760, CE-1785.
