An integral around a circle written with the variable and the contour only is not computed; it needs a third, empty element.

## Witness

```
CircularIntegrate(1/z, (z, CircleContour(0, 1)))            // stays unevaluated
CircularIntegrate(1/z, (z, CircleContour(0, 1), Nothing))   // 2i * pi
```

Measured at 074e6347f39717e4f6d5b44521c5c459b6d9d2b7.

## Cause and options

A 2-tuple of limits is read as `(variable, upper)`, so the contour lands in the upper slot and the lower one is `Nothing` (`Limits(z, "Nothing", CircleContour(0, 1))`). Read a contour in the second element as the contour.
