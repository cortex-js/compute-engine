The standard deviation of a list no longer compiles.

## Witness

`L: list<real>`; `compile(StandardDeviation(L), { to: 'javascript' })`.

0.193.0: compiles; at `L = [3, 1, 3]` it gives 1.1547005383792515, the
interpreter's value. 0.194.0: declines, "the operator StandardDeviation is not
supported by the compiler". The IR README ("Lists") lists `Mean` and `Median`
but not `StandardDeviation` or `Variance`.

Workaround, not tested: a host can write the formula out
(`Sqrt(Sum((L - Mean(L))^2) / (Length(L) - 1))`).

## Expected

Compiles on javascript and gives the interpreter's value.
