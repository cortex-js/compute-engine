A surface built from the derivative of a function the document defines draws nothing.

## Witness

```ts
const ce = new ComputeEngine();
ce.declare('u', 'real'); ce.declare('f', 'function'); ce.declare('F', 'function');
ce.box(['Assign', 'f', ['Function', ['PointList', ['Sin', ['Multiply', 2, 't']],
  ['Cos', ['Multiply', 3, 't']], ['Sin', ['Multiply', 5, 't']]], 't']]).evaluate();
ce.box(['Assign', 'F', ['Function', ['Divide', ['Apply', ['Derivative', 'f', 1], 't'],
  ['Abs', ['Apply', ['Derivative', 'f', 1], 't']]], 't']]).evaluate();
compile(ce.box(['Apply', ['Derivative', 'F', 1], 'u']), { to: 'javascript' });
```

0.194.3: declines, "Derivative(F, 1): a derivative with no closed form of at
most 10000 nodes in radians at compile time". Control: the same program
without the two `ce.declare(…, 'function')` calls compiles on 0.194.3. 0.186.0
compiles both. Tycho's document manager declares every document function as
`function` before it assigns the body, so a document reaches only the
declining form. In `art/frthw0ihk5` (a tube along a curve: the unit tangent and
its derivative) the 4 surface rows have no route and draw nothing.

Found by the Tycho codegen audit of 2026-11-19: the same MathJSON, with the same options, compiled to JavaScript on CE 0.186.0 and declines on 0.194.3 and on the CE main build of 2026-11-19 16:57, in the document context and on a bare engine. Tycho's instrument `scripts/repros/2026-11-19-ce1560-js-decline-regressions.mts` prints one READY / NOT READY line per issue (READY on 0.186.0, NOT READY on 0.194.3).

## Cause and options

With the declaration `function`, the derivative is not found from the assigned
body, or the closed form is computed on another expression that is larger than
the 10,000-node limit. Expected: the declaration does not change the result.
The point-valued result also has no numeric stencil (`_SYS.nd` is for a number
result), so there is no fallback.
