A row that ends with `.mean`, `.median` or `.sort` after a list is not
understood, so a function defined that way is not a function.

## Witness

```js
ce.parse('a=[1,2,3].\\operatorname{mean}', { form: 'raw' }).json;
// ["Sequence", ["Equal", "a", ["List", 1, 2, 3]],
//  ["Error", "'unexpected-operator'", ["LatexString", "'.\\operatorname{mean}'"]]]
```

`.\operatorname{median}` and `.\operatorname{sort}` fail the same way;
`.\operatorname{length}` gives `["Equal", "a", ["Length", ["List", 1, 2, 3]]]`.
Checked on `b10a39a83`.

The Desmos state `ifnnzttcqg` (Tycho fixture
`tests/fixtures/documents/desmos/ifnnzttcqg.json`) has the row
`S_{wirlBG}\left(p\right)=…\right).\operatorname{mean}`. The parse gives a
`Sequence` with an error, so Tycho's `recognize` finds no definition and the
row is not a function. Tycho's plotting guide (`plotting-guide.fr.md:338`)
lists `.mean`, `.median` and `.sort` as list members. Tycho has a workaround
in its host.

## Cause and options

`COMPONENT_ACCESS_HEADS` (`src/compute-engine/latex-syntax/dictionary/definitions-core.ts`,
about line 71) maps member names to heads and has `x y z real re imag im count
length total max min`, but not `mean`, `median` or `sort`. Add `mean: 'Mean'`,
`median: 'Median'` and `sort: 'Sort'` (check the head names of the statistics
and collection libraries), with parse and serialization tests. Check
the other members that the Tycho guide lists at the same time.
