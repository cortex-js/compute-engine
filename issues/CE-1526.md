After a host replaces a helper with a scalar function, rerunning the original program restores the helper but can return a list in place of its mean.

## Witness

Run against `@cortex-js/compute-engine@0.194.2`.

```js
import { ComputeEngine } from '@cortex-js/compute-engine';

const ce = new ComputeEngine();
const items = ['List', 1, 2, 3];
const source = [
  'Program',
  ['DefineFunction', 'k', ['Function', ['h', 'xs'], 'xs']],
  ['DefineFunction', 'h', ['Function', ['Mean', 'xs'], 'xs']],
  ['k', items],
];
const program = ce.box(source);
console.log(program.evaluate().json); // 2
ce.assign('h', ce.box(['Function', ['Add', 'xs', 10], 'xs']));
console.log(program.evaluate().json); // ['List', 1, 2, 3], expected 2
console.log(ce.box(['h', items]).evaluate().json); // 2
console.log(ce.box(source).evaluate().json); // ['List', 1, 2, 3]
```

A replay without the intervening host assignment returns 2. Preparing and
running the original source in a fresh engine also returns 2. The specific
sequence requires a host assignment between runs that changes which
argument domain the helper accepts.

## Cause and options

The host assignment changes the caller's parameter contract from
`collection<number> | value` to `unknown`. The Program replay restores
the helper's original body but leaves the caller's parameter contract at
`unknown`, so the call broadcasts over the list. Check that the restored
clause invalidates the dependent contract, including when the box step
reuses the existing definitions.
