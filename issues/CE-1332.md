Two functions made by the same function with different values of a local variable compare as equal, and a list of them loses one when its duplicates are removed.

## Witness

Run at `7a4096fec40397675c079f519d10dcecfe0f8a2d` (Epsil):

```
let f = (k) => do { let y = k; x => x + y }
f(1) == f(2)                                             // True
let L = [f(1), f(2)]
listFrom(map(g => g(0), L))                              // [1, 2]
listFrom(map(g => g(0), dedup(L)))                       // [1]
```

`f(1)` adds 1 and `f(2)` adds 2. With the value read from the parameter
(`let f = (k) => (x => x + k)`) the comparison stays unevaluated and
`dedup` keeps both, because the end of the call writes the value of `k`
in each body.

## What it must give

The comparison is not `True` (unevaluated, as for the parameter form), and
`dedup(L)` keeps both functions: `[1, 2]`.

## Cause and options

Two function values of one literal have bodies that are structurally the
same; what differs is the activation that each keeps, which `isSame` does
not read. Option: `isSame` of two `Function` nodes that keep an activation
(`keepsActivation()`, `function-utils.ts`) is true only when they keep the
same activation, or are the same node.
