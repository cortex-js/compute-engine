The negation of a float zero is sometimes a positive zero and sometimes a negative zero, in the same list.

## Witness

At machine precision, with `f(v) = ce.number(ce._inexactNumericValue(v))`:

```js
const els = Array.from({ length: 100 }, (_, k) =>
  k % 20 === 0 ? f(0) : k % 20 === 1 ? f(-0) : f({ re: 0.5 + k, im: -1.25 }));
ce.assign('A', ce.function('List', els));
const r = ce.box(['Negate', 'A']).evaluate();
r.ops[0].numericValue.re;   // 0
r.ops[20].numericValue.re;  // -0, for the same element 0.0
```

The MathJSON of both is `{"num":"0.0"}`; only the numeric value shows the
sign. With 150 elements (a lazy `Map`) other cells differ in sign from the
list of 100. The CE-883 tests compare a zero result without its sign for this
reason (`test/compute-engine/complex-broadcast.test.ts`).

## Cause and options

Not traced. Find where the result of one cell depends on an earlier cell
(a shared or cached value of the zero), or document that the sign of a
float zero result is unspecified.
