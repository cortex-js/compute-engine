A transpose with an axis of 0 prints "Assertion failed" to the console.

## Witness

```
Transpose([[[1, 2], [3, 4]], [[5, 6], [7, 8]]], 0, 2)   // prints "Assertion failed", stays unevaluated
```

Measured at 074e6347f39717e4f6d5b44521c5c459b6d9d2b7.

## Cause and options

A `console.assert(axis1 > 0 && axis2 > 0)` in the `Transpose` handler (`library/linear-algebra.ts`) runs before the range checks that return `undefined`. Remove the assert: the range check already declines the call.
