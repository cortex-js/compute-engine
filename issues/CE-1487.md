A formula that gives a list with one element replaced (`ReplaceAt` used as a value) no longer compiles.

## Witness

`ReplaceAt(H, 1, 5)` with `H: list<real>` = `[1, 2, 3]`. Interpreter and
0.193.0 compiled: `[5, 2, 3]`. 736f19c: "the operator ReplaceAt is not
supported by the compiler". `ReplaceAt` under an `Assign` to a list local
compiles (CE-1462); as a value it has no compiled form.

## Expected

`ReplaceAt` as a value compiles to a copy of the list with the element
replaced.

## Instrument

`npx tsx scripts/repros/2026-11-18-ce1485-ce1486-ce1487-list-alias-loop-replaceat-probe.mts` in Tycho. `CE-1487: READY` when it compiles with the
interpreter's value. READY on 0.193.0, NOT READY on 736f19c.
