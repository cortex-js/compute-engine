The minimal polynomial of a cube root written with `cbrt` is not computed, while the same root written with `root` is.

## Witness

```
MinimalPolynomial(Cbrt(2), x)      // stays MinimalPolynomial(Cbrt(2), x)
MinimalPolynomial(Root(2, 3), x)   // x^3 - 2
```

Measured at 074e6347f39717e4f6d5b44521c5c459b6d9d2b7.

## Cause and options

The reader of algebraic numbers (`library/algebraic-numbers.ts`) reads `Sqrt`, `Root`, `i`, the golden ratio and `PolynomialRoot`, not `Cbrt`. Read `Cbrt(a)` as `Root(a, 3)`. The same reader serves `NumberFieldDiscriminant`, `NumberFieldIntegralBasis`, `NumberFieldSignature` and `IsAlgebraicInteger`.
