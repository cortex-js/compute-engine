A list of evenly spaced numbers with an infinite endpoint is empty for a sum and has three elements for a count.

## Witness

```
L = Linspace(0, +∞, 3)
loop over L        no elements
Sum(L)             0     (checked 2026-11-06)
Count(L), Length   3     (checked 2026-11-06)
At(L, 1)           NaN
Max(L)             +∞
```

A `NaN` endpoint splits in another way.

## Cause and options

The iterator of `Linspace` (`library/collections.ts`) declines an endpoint that
is not finite; `count`, `at` and the reducers do not. Compiled JavaScript gives
`[]`; `interval-js` gives no value. Question: which reading is the value?

- (a) No value: every read gives no value (`Sum` too). `interval-js` does this;
  the JavaScript target would test the endpoints.
- (b) The samples `[0, +∞, +∞]`: `Sum` is `+∞`, a loop runs 3 times.
- (c) An empty list: `Count` is 0; the targets give `[]`.

Recommended by the conversion (the old entry had none): (a), the reading of
`interval-js`. With no decision, the reads disagree.
