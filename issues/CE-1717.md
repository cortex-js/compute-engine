In Epsil, the message of an error in the second operand of a subtraction names a negation and a sum that the program does not contain.

## Witness

```
let w: any = "s"
let v = 3 - ln(w)   ->  "in Ln argument 1, in Negate argument 1, in Add argument 1"
let v = 1 - exp(w)  ->  "in Exp argument 1, in Negate argument 1, in Add argument 1"
expected            ->  "in Ln argument 1, in Subtract argument 2"
```

The underline is `w`. `test/epsil/reordered-call-error-location.test.ts` and
`test/epsil/renamed-call-error-location.test.ts` pin the present text.

## Cause and options

The canonical form of `a - t` is `Add(a, Negate(t))`, and the frames of the
error name these two calls. `renamedCallFrame()`
(`src/epsil/error-location.ts`) maps one frame of a renamed call to one frame
of the written call, and leaves a written `Subtract` out on purpose. Option:
in `locateError()`, change the pair `Negate argument 1, Add argument k` whose
canonical operand `k` is the `Negate` made from the written subtrahend into
the one frame `Subtract argument 2`, and let `errorFrameChain()`
(`src/epsil/execute-epsil.ts`) print one frame for the two recorded frames.
The index alignment of the frames of `locateError()` with the `ErrorTrace`
entries then needs a mark for a dropped frame.
