The plain-text form of `1 − (1 − t)` after a substitution is `1 - 1 - t`, which reads as `−t`.

## Witness

```ts
const f = ce.parse('1-t').subs({ t: ce.parse('1-t') });
f.json;       // ["Add", ["Negate", ["Add", ["Negate", "t"], 1]], 1]
f.toString(); // "1 - 1 - t"   (must be "1 - (1 - t)")
f.latex;      // "1-(1-t)"     (correct)
```

`ce.box(['Add', 1, ['Negate', ['Add', 1, ['Negate', 't']]]])` gives the same
form and the same string. Its value is correct (`t`).

## Cause and options

The plain-text serializer writes a `Negate` of a sum inside a sum as a
subtraction of each term, with no parentheses. The LaTeX serializer adds
them. Fix: put the sum in parentheses, as the LaTeX serializer does. Size S.
