The set of the characters of a text holds the same character twice until it is evaluated a second time.

## Witness

```ts
const ce = new ComputeEngine();
ce.assign('s', ce.expr({ str: 'hello' }));
const once = ce.expr(['SetMinus', 's']).evaluate();
// Set(o, e, h, l, l), each a CharacterFrom
once.evaluate(); // Set(o, e, h, l)
```

Read on 29a48852b, 2026-11-20.

## Cause and options

Not read. The first evaluation builds the set from the characters with no
removal of the equal elements. Workaround: evaluate the result again.
