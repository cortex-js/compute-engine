Adding a number variable to a list of points is typed as a list of points, but its value is a list of errors.

## Witness

With `Q := [(1, 2), (3, 4)]` and `x := 5`, `Q + x` is typed
`list<tuple<integer, integer>^2>` and evaluates to two `incompatible-type`
errors (checked 2026-11-06). `x + (1, 1)` is typed
`integer | tuple<integer, integer>` and evaluates to one error.

## Cause and options

The check `addsPointToNumberCollection` (`collection-utils.ts`) reads the
operand types only. A number symbol whose type was only inferred keeps such a
sum symbolic under `evaluate()`, so typing the sum `error` from the types alone
would be wrong; a fix needs the symbol's value. This file holds the former
sub-item CE-82.3, the only one left.
