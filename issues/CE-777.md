Compiling `Block(If(x < 1, b ≔ 1, b ≔ 2); b)` adds a global `b` to the engine.

## Witness

With `x: real`, compiling `Block(If(x < 1, b ≔ 1, b ≔ 2); b)` to JavaScript
created a definition of `b` in the engine's scope, so the compilation changed
the engine.

At commit `5784d4aec` this does not reproduce: the `Block` is invalid (each
branch holds `Error(ErrorCode("first-assignment-in-branch", "b"))`), the
compilation falls back to the interpreter, and `ce.lookupDefinition('b')` is
`undefined` before and after.

## Cause and options

The board decides: close it as fixed, or keep it until a form that still
declares `b` is found (for example, a form where `b` is declared before the
`If`). Recommended: close.
