The length of a reversed or sorted string is counted before the characters are grouped again, so `length(reverse("\u{301}a"))` is 2 where the string has one character.

## Witness

Epsil CLI, main 412113c86: `length(reverse("\u{301}a"))` gives 2;
`let r = reverse("\u{301}a"); length(r)` gives 1, and
`characters(reverse("\u{301}a"))` gives `["á"]`. `length(sort("\u{301}ba"))`
gives 3 for the string `"ab́"` of two characters. The witness needs a combining
mark at the start of a string, which a user rarely writes.

## Cause and options

`Length` of an unevaluated `Reverse` or `Sort` seems to answer the length of
the operand (a shortcut that is right for a list). For a string, the
characters are grouped again after reordering. Fix: take the shortcut only for
a list, or count the evaluated string.
