In a scope where the user defines a function named `Exp` or `Negate`, the square of a call of that function gives a power of e or of the argument instead of the value of the user's function.

## Witness

At commit `f208150cb6ecbe058b28b57f3cf2857067d35830`:

```ts
ce.pushScope();
ce.declare('Exp', 'function');
ce.assign('Exp', ce.box(['Function', ['Add', 'a', 100], 'a']));
const u = ce.box(['Exp', 'x']);
u.pow(2).json                     // ["Power", "ExponentialE", ["Multiply", 2, "x"]]
u.pow(2).subs({ x: 1 }).N()       // 7.389…; must be 10201
ce.declare('Negate', 'function');
ce.assign('Negate', ce.box(['Function', ['Add', 'a', 100], 'a']));
const v = ce.box(['Negate', 'x']);
v.pow(2).subs({ x: 1 }).N()       // 1; must be 10201
ce.popScope();
```

`crafted`: the program defines a user function with the capitalized name of
a library function and takes a power of a call of it in its scope.

## Cause and options

`pow()` (`boxed-expression/arithmetic-power.ts`) selects the rules
`exp(a)^b → e^(a·b)` and `(−a)^n → ±a^n` by the operator name
(`isFunction(x, 'Exp')`, `isFunction(x, 'Negate')`). Option: add
`isLibraryOperator(x, 'Exp')` and `isLibraryOperator(x, 'Negate')` to the two
tests, as CE-1792 did for `Sqrt` and `Root`. Related: CE-1114.
