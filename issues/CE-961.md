A sum written with no index, such as Σ x^k, evaluates to the single term x^k.

## Witness

```
\sum x^k     evaluate gives x^k
\sum_k x^k   sums over k = 1..∞
```

## Cause and options

`\sum x^k` parses to `Sum(x^k)` with no indexing clause. The one-operand
`Sum` adds the elements of a collection, and it reads an operand that is not
a collection as itself.

Question: is this result intended?

- (a) Yes. Document it. Cost: one paragraph in the reference.
- (b) No. Keep `Sum(x^k)` unevaluated when the operand is not a collection
  and has free variables. Cost: one change in the `Sum` handler, snapshots
  not measured.
- (c) No. Infer the index from the operand. Cost: a rule to choose between
  `x` and `k`, which is ambiguous.

Recommended: (b). A returned term looks like a correct value; an unevaluated
sum shows that the index is missing. If nothing is decided, nothing changes.

## Decision

User decision 2026-11-06: (b)

User decision 2026-11-06: (b)
