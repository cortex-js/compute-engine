The standalone TypeScript check for the VS Code extension fails on the CLI's Node types.

## Witness

From the repository root, with the root and extension dependencies installed,
run `./node_modules/.bin/tsc --noEmit -p vscode-epsil/tsconfig.json`.
At `a20d0fefe` it reports TS2724 for `ParseArgsOptionsConfig` in
`src/cli/arguments.ts` and three TS18046 errors derived from that import.
The root `npm run typecheck` and the extension build and tests pass.

## Cause and options

The extension type-checks the shared CLI source with `@types/node` 20.19.43.
The root check uses 26.6.5, which provides the type the CLI imports. Give the
CLI a type that both environments provide or align the standalone check with
the repository's shared CLI types while respecting its runtime target.
