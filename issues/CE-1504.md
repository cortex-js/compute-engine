Multiplying a literal list by zero and a second numeric factor gives one zero for the whole list.

## Witness

```js
const ce = new ComputeEngine();
const L = ['List', 2, 4, 8];
for (const args of [[0, L], [0, 2, L], [L, 2, 0]]) {
  const e = ce.box(['Multiply', ...args]);
  console.log(e.json, e.evaluate().json, e.N().json);
}
```

The binary product evaluates to `['List',0,0,0]`. Both three-factor products box to the scalar 0 and return 0 from evaluation and N(). All three have the same elementwise mathematical result. There are no variables, declarations, substitutions or Program nodes. For this input, precombining the scalar factors and passing the binary product works.

## Cause and options

In `canonicalMultiply()`, combining the two exact numeric factors takes the zero-product branch. Its collection guard covers unresolved lists. A concrete numeric list falls through to the scalar result. Preserve the result shape through coefficient folding and keep the existing exceptional-value rules. The declared-list case already has coverage in `simplify-tycho-audit.test.ts`.
