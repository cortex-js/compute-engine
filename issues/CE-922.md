A function written with an anonymous argument and called with no argument gives a function whose parameter has the malformed name `_1_0`.

## Witness

```
ce.assign('f2', ['Add', '_', 1]);   evaluate(['f2'])
->  ["Function", ["Apply", ["Function", ["Add", "_1", 1]], "_1_0"], "_1_0"]
```

The inline snapshot "Missing Param Expression" in
`test/compute-engine/functions.test.ts` locks in this result.

## Cause and options

The cause is not known: find where the parameter of the partial application is
named. Expected: a parameter with a valid name, as the call of `f1` gives
(`_1`). The entry had no witness line.
