Rounding a decimal number very close to zero runs for seconds, then fails with an internal error.

## Witness

On main `d425883ae06092f95f3d3ff03c66ff7228ba3d2e`:

```
new BigDecimal('1e-1000000000').floor()
// about 8 s, then RangeError: Maximum BigInt size exceeded
//   at pow10 (src/big-decimal/utils.ts) at BigDecimal.trunc at BigDecimal.floor
```

Through the engine, before the CE-1299 change (which no longer calls
`floor()` on such a value), `Rationalize(1e-1000000000, 1)` gave
`Error(internal-error, "Maximum BigInt size exceeded")` after about 8 s. The
answer is `0`.

## Cause and options

`BigDecimal.trunc()` (`src/big-decimal/big-decimal.ts`) divides the
significand by `pow10(-exponent)`, so it builds the bigint `10^1000000000`.
`floor()`, `ceil()` and `round()` call `trunc()`. Fix: when
`exponent + digits(significand) <= 0` (magnitude below 1), `trunc()` is `0`
with no division. Size S.
