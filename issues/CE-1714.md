If a later release changes how a library function reads the arguments of a `hold` function, a histogram in a notebook `plot()` is drawn as one point again.

## Witness

Tycho's drawing prelude defines `hold function plot(...args) { figurePlotView(figurePlotSeries(args, 2)) }`.
`figurePlotSeries` is a library operator declared with `lazy: true`. Its
handler reads the held arguments of `plot` as `ops[0].canonical.value`: a
`Tuple` of the arguments as written. For example, `plot(histogram(rolls, 1))`
gives `["Tuple", ["Histogram", "rolls", 1]]`, and the handler evaluates each
item itself. Without `hold`, the item arrives evaluated as `[(1, 4)]`, its
counts, and the plot draws one point.

On 0.200.0 the instrument reads:

```
control (not lazy, evaluated): ["List",["Tuple",1,4]]
hold + lazy (held binding): ["Tuple",["Histogram","rolls",1],5]
agent card documents it: false
CE-1714: NOT READY (works, not documented)
```

compute-engine-8f confirmed the shape on main on 2026-11-22. Its notes on what
the handler sees:
- `ops[0]` is the symbol `args`, not canonical.
- `.value` without `.canonical` is undefined.
- A caller inside a function gets its names replaced by their values when the
  argument is bound (`heldArgumentValue`, function-utils.ts).
- `core.ts` `Head` reads a hold parameter the same way (`boundExpression`).

The answer also says that a rest parameter on a hold function works but is
not documented (control-flow.md, "Hold functions").

## Cause and options

The behavior works. Neither the documentation nor the API names it, so a
refactor of hold bindings could change it without notice. The ask is to make
it a documented contract:

(a) Recommended. Document, in the `lazy` flag of `OperatorDefinition` and in
the Epsil "Hold functions" section, that:
   - a lazy operator that receives a hold function's parameter as an operand
     reads the held expression with `operand.canonical.value`;
   - each held item keeps its scope: `evaluate()` reads the caller's names;
   - a rest parameter of a hold function binds a `Tuple`.
Size S.

(b) Add a named API for the same read, for example
`ce.heldArgument(operand)`, if `.canonical.value` is an implementation detail.
Size S to M.

Tycho half on adoption (READY): cite the documented API in the header comment
of Tycho's `src/graph-paper/notebook/drawing/plot.ts` (the paragraph on `hold`)
and in EPSIL_PLOT.md § 7 ruling 6; no code change unless (b) renames the read.
