A function that receives another function and calls it on a list gets a list type, but its value can be a single number.

## Witness

Checked 2026-11-07 at `2d37a4974` with the CE-772 change:

```
Apply(Function(h([[0, 0], 5]), h), Function(Count(t), t))
  type:  list<list<unknown^2> | unknown>
  value: 2
```

## Cause and options

`boundCallType()` (`boxed-function.ts`, value-definition branch) types a call
of a name with no value and the type `unknown` as a broadcast. CE-772 types
such a call `unknown` for a block local only. The same rule for a parameter of
a function literal fixes this case; a free name that is not declared keeps
the broadcast type of `docs/BROADCAST-MODEL.md`.
