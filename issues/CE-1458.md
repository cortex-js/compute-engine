`const c` with no value is accepted, but the constant can never get a value.

## Witness

Epsil CLI, main 9777d22c1: `const c; c = 1` gives "Static error: cannot assign a value to the
constant `c`", and `const c; c` gives "Runtime error: `c` is read before it
has been given a value".

## Cause and options

`let` without a value is a valid declaration (a name typed now and assigned
later); a `const` cannot be assigned later, so a `const` with no value is
useless. Fix: the static check reports `const` with no value as an error
(`declaration-without-value` is the code that names it), and the docs say so.
