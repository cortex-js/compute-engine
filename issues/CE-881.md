Some polynomial steps used by integration can turn an exact radical such as √2 − 2 into a decimal.

## Witness

```
ce.parse('\\sqrt2').sub(ce.box(2))   → -0.585786437626904951198311; expected √2 − 2
```

Probed 2026-11-06. No integration problem that reaches it is known.

## Cause and options

The `.sub()`, `.add()` and `.div()` methods fold exact radicals to floats.
Audit the callers that use them on coefficients: `makeMonic` (`.div()`) and
`resultantRec` (`boxed-expression/polynomials.ts`) and `polyDivideX`
(`rubi/rubi-utils.ts`). `polynomialDivide` no longer uses these methods on
coefficients. The entry named all three in `rubi-utils.ts`; two are in
`polynomials.ts`.
