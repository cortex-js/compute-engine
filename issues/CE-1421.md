`NIntegrate` of the name of an operator that takes no number (`Length`, `Random`) throws a `RangeError` instead of staying unevaluated or giving an error value.

## Witness

`ce.box(['NIntegrate', 'Length', 0, 1]).N()` throws `RangeError: Length: the
operand is not a list or a set at run time` on main
(7767a8e7103d636b5144e7089acad6e8ed4d9990). `NIntegrate(Random, 0, 1)` throws
`Random: the operand is not a list at run time`. The interpreted call
`Apply(Length, 1.5)` gives the `incompatible-type` error value.

## Cause and options

`NIntegrate` wraps a function name in `t ↦ f(t)` (`functionLiteralOfName` in
`library/calculus.ts`) and runs the compiled literal. The compiled call checks
its operand at run time and throws for a number. Option: decline as `ND` does
since CE-1376: return the expression unevaluated when the body of the wrapped
literal is not pure, and when the compiled run throws a `RangeError` or a
`TypeError`.
