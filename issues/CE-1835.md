The help of about twenty library functions ends with an example written in a mix of math notation and MathJSON names, which a reader cannot run, instead of a runnable example.

## Witness

The hover of `factor` in an Epsil editor shows, at the end of its
description, `Example: Factor(x² + 5x + 6) → (x+2)(x+3), …`. The same holds for
the descriptions of these definitions, which have no `examples` field:

- `polynomials.ts`: `Factor`, `PolynomialDegree`, `CoefficientList`,
  `PolynomialQuotient`, `PolynomialRemainder`, `PolynomialGCD`, `Resultant`,
  `Cancel`, `PartialFraction`, `PolynomialRoots`, `Discriminant`,
  `Polynomial`
- `special-functions.ts`: `ChebyshevT`, `ChebyshevU`, `LegendreP`,
  `HermiteH`, `LaguerreL`
- `trigonometry.ts`: `TrigExpand`, `TrigToExp`, `TrigReduce`
- `calculus.ts`: `JacobianMatrix`, `Limit`, `Normal`
- `algebraic-numbers.ts`: `PolynomialRoot`

Search: `grep -rnE "Example: " src/compute-engine/library`.

## Cause and options

The examples were written into the prose before the `examples` field
existed. Move each one to `examples` as one line of Epsil with the MathJSON
names (`Factor(x^2 + 5x + 6)`), check that it evaluates to the value the
prose claims, and delete the sentence from the description. The editor and
the reference pages then show it in the Epsil spelling with its computed
value (CE-1813). `Series` was moved in the CE-1813 change. Size S.
