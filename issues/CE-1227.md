Compiled `Beta(a, b)` gives `NaN` for a negative integer `a` (or `b`), where the interpreter gives the finite limit.

## Witness

At `5fc85eda6`, `k`, `n` declared `integer`, `x`, `y` declared `real`
(the code is `_SYS.beta(…)`, with `cse: false, constantFold: false`; the
`numeric-kernel` profile writes the same call):

| Program, point | Compiled | `evaluate().N()` |
| --- | --- | --- |
| `Beta(x, y)`, `x = -3, y = 2` | `NaN` | `0.16666666666666666` |
| `Beta(n, k)`, `n = -3, k = 2` | `NaN` | `0.16666666666666666` |
| `Beta(x, 1)`, `x = -1` | `NaN` | `-1` |
| `Beta(x, y)`, `x = -2.5, y = 2` | `0.26666666666666666` | the same |
| `Beta(x, y)`, `x = -3, y = 0.5` | `NaN` | `~oo` (a pole: `NaN` is within the caveats) |

`B(a, 2) = 1/(a(a + 1))`: at `a = -3` the poles of `Γ(-3)` and `Γ(-1)`
cancel and the value is `1/6`.

## Cause and options

`_SYS.beta` (`javascript-runtime.ts`) computes `Γ(a)Γ(b)/Γ(a + b)` with the
double kernels, and the quotient of two infinities is `NaN`. Options: (a)
in the kernel, when `a` or `b` is a non-positive integer and `a + b` is a
non-positive integer too, compute the finite limit as the interpreter does
(a ratio of rising factorials); (b) a known-limitations line. Recommended:
(a).

The `numeric-kernel` profile declines `Beta` when an operand is not
provably positive ("… which is not provably positive, is not in the
profile"). When the kernel is fixed, remove the `domain` of `Beta` in
`REAL_CALL_HEADS` (`javascript-fragment-target.ts`).
