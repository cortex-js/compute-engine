A running fold over a list that can hold absent elements gets a type that leaves out the absent elements it keeps.

## Witness

`xs = Map(x ↦ If(x > 1, Missing, x), [1, 2, 3])` is typed
`list<integer | missing^3>`. `Scan(xs, Add)` is typed `vector<integer^3>` and
evaluates to `[1, Missing, Missing]` (checked 2026-11-06). The type must have
the `missing` member.

## Cause and options

The `Scan` type handler receives the source type without its `missing` member:
the member is dropped before the handler runs. A fix inside the handler cannot
see it; find where the operand type loses it. The old entry declared the source
`list<integer | missing>`, a declaration that the engine now refuses.
A `Missing` inside a list literal is typed `nan`, so
`Scan([Missing, Missing], Add)` typed as a numeric list is consistent.
