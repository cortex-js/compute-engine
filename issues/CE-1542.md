The numeric inverse of a singular matrix with integer entries gives huge numbers instead of saying that the matrix has no inverse.

## Witness

`ce.box(['Inverse', ['List', ['List', 3, 2, 1], ['List', 1, 1, 1], ['List', 4, 3, 2]]]).N()`
(row 3 = row 1 + row 2): entries of about ±4.5e15 and 9e15.
`evaluate()` leaves the call unevaluated, the exact path, which is right.
In a sample of 20,000 rank-deficient 3×3 and 4×4 matrices with integer
entries in −9..9, 36% got finite entries. `Determinant` gives exactly 0 for
all of them.

## Cause and options

The double-precision elimination tests the pivot for exact 0; rounding
leaves a pivot of about 1e-16. A pivot test relative to the scale of the
matrix (for example `|pivot| ≤ n·ε·max|aᵢⱼ|`) would leave the call
unevaluated, as `evaluate()` does. The compiled `Inverse` (CE-1529) uses
such a test and gives a matrix of NaN.
