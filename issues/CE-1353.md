The derivative of some special functions, written as a formula and then given the value 0, is NaN although the derivative exists there.

## Witness

On main after the CE-1298 fix:

```
D(EllipticK(x), x), then subs x = 0, evaluate          // NaN; the value is π/8
Apply(Function(D(EllipticK(x), x), x), 0)               // NaN
Apply(Derivative(Function(EllipticK(2x), x)), 0)       // NaN; the value is π/4
Apply(Derivative(Function(2·EllipticK(x), x)), 0)      // NaN; the value is π/4
```

The CE-1298 fix gives the value at 0 only for `Apply(Derivative(f, n), 0)`
when `f` is `EllipticK`, `EllipticE`, `LambertW`, or a function literal whose
body is exactly a call of `EllipticK`, `EllipticE`, `LambertW`, `PolyLog(s, x)`
or `LerchPhi(x, s, a)` (`symbolic/removable-points.ts`). The same holds for
these functions in place of `EllipticK`.

## Cause and options

The closed forms of the derivatives (`(E(m) − (1 − m)K(m))/(2m(1 − m))`, …)
are `0/0` at 0. After `D` returns the formula, the substitution does not know
that the formula came from a derivative. Options: (a) for a function literal
of `Derivative` applied at an exact point where the closed form is not
finite, take `n!·cₙ` from `computeSeries(body, p, a, n)`, which reads the same
table and covers composed and scaled bodies; it must refuse a Laurent,
Puiseux or logarithmic series; (b) a `Limit` when a substitution gives `0/0`,
for every formula (large, slow); (c) leave as is: the formula is right, and
Mathematica gives `Indeterminate` for the substitution too. Recommended: (a)
for the `Derivative` spellings, (c) for the substitution into the formula.
Size M.
