The LaTeX of an annotated expression writes a color with its string quotes (`\textcolor{'blue'}{\pi}`) and ignores a `mathStyle` or `fontWeight` given as a string.

## Witness

Epsil CLI, main 412113c86:

- `Latex(Hold(Annotated(pi, {"color" -> "blue"})))` gives
  `\textcolor{'blue'}{\pi}`; it must give `\textcolor{blue}{\pi}`.
- `Latex(Hold(Annotated(x, {"fontWeight" -> "bold"})))` and
  `{"mathStyle" -> "normal"}` give `x`; they must give `\textbf{x}` and
  `{\displaystyle x}`.

## Cause and options

The `Annotated` serializer (`latex-syntax/dictionary/definitions-other.ts`,
around line 670) reads the values of `dictionaryFromExpression(…)`, which are
MathJSON: a string is `'blue'` with its quotes, so each `=== 'bold'` test
fails and the color is written with the quotes. Fix: read each value as a
string (strip the MathJSON quotes) before the tests, and add a round-trip test
for each key.
