A curve that is offset along its own slope draws nothing when its formula adds a point that has a name.

## Witness

Plain engine, `p` declared as the point (1, 2), `g(t, z) = t^2 z`:

| Input                          | Expected | Today (0.176.0, 0.178.0, 0.183.0) |
| ------------------------------ | -------- | --------------------------------- |
| `D(PointY(p + (sin u, u^2)), u)` | `2u`     | `D(…)` unevaluated                |
| `D(PointY(u^2 p), u)`            | `4u`     | `D(…)` unevaluated                |
| `D(PointY(g(u, p)), u)`          | `4u`     | `D(…)` unevaluated                |
| `D(PointX(p + (sin u, u^2)), u)` | `cos u`  | `D(…)` unevaluated                |
| `D(PointY(u^2 S), u)`, `S` the list `[(1, 2), (3, 4)]` | `[4u, 8u]` | `D(…)` unevaluated |

The same holds for a name bound to a list of points (`S`), and for a name
bound by a `Block` (`Declare(p, "unknown", value)`, the form of a Desmos
`with` or `where` binding).

Controls that work: the literal point `(1, 2)` in the same place gives `2u`;
`D(PointY(p), u)` gives 0; a point read from a named list, `u^2 L[2]`, gives
`8u`; `g(u, (1, 2))` gives `4u`.

Corpus: the "Sorry" text of Desmos document `art/2ki2hjsouf` is filled by two
rows that offset each point of a 29-piece curve `S(u)` along its normal,
`\frac{d}{du} S(u).y`. Two pieces add the named points `p_1` and `p_2`, three
read the named list `S_q`, and pieces bind `p` with `where`. The derivative of the whole list stays
unevaluated, so `evaluate()` of the row returns an `Add` after 2 to 5 s, and
Tycho draws nothing for these rows (Desmos draws the fill).

## What it must give

The derivative of a coordinate of a point expression with the named point
read as the point it holds: `D(PointY(p + q(u)), u)` is `D(PointY(q(u)), u)`
when `p` does not depend on `u`.

## Cause and options

Not traced. The rule that differentiates `PointX` / `PointY` seems to need a
literal point (`Tuple`, `PointList`) or a list element (`At`) as its operand
after evaluation, and gives up on a symbol of point type inside a sum, a
product or a call argument. Options: (a) read the value of a named constant
point before the rule; (b) differentiate a coordinate of a sum, a product and
a call by the coordinate of each operand, with 0 for an operand that does not
depend on the variable.

Tycho half on the fix: run the instrument; the row also needs CE-1116 and a
Tycho change (the expansion of the row passes Tycho's size limit), recorded
in ROADMAP row LJ.
