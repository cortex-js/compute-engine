A sum with no index whose lower bound is an expression loses its bounds when its LaTeX is read again: `\sum_{a+1}^5 x` reads as a sum with no range.

## Witness

At `c6d2ba6be7fc29fb97fd8f8ea987e95cd08b7466`, with
`ce.box(mj, { canonical: false }).latex` and
`ce.parse(latex, { canonical: false }).json`:

```
["Sum","x",["Limits","Nothing",["Add","a",1],5]]
  latex: \sum_{a+1}^5x     back: ["Sum","x"]
["Sum","x",["Limits","Nothing",1,5]]            (control: a number bound)
  latex: \sum_1^5x         back: ["Sum","x",["Tuple","Nothing",1,5]]
```

The witness is crafted: a range with no index and a symbolic lower bound.
The workaround is to name the index (`\sum_{i=a+1}^5 x`).

## Cause and options

`getIndexAssignment()` (`latex-syntax/dictionary/definitions-arithmetic.ts`)
keeps a subscript that is not an index only when it is a number
(`isNumberExpression`), so it drops `a+1` and the superscript with it.
Option: keep a subscript that is not an index as the lower bound of an
index-less range, as for a number.
