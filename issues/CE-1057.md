A function that calls another function defined in the same block is applied to each element of a list argument, and gives errors in place of its value.

## Witness

Checked 2026-11-07 at `2d37a4974`:

```
Block(Assign(h, t ↦ Count(t)), Assign(q, a ↦ h(a)), q([1, 2]))
  → [Error(incompatible-type, collection, 1, "while applying 'q' element-wise …"),
     Error(incompatible-type, collection, 2, …)]
  expected: 2
```

With `DefineFunction` (Epsil `function`) for `h` or `q`, or with both
assigned by `ce.assign()`, the value is `2`.

## Cause and options

Not traced. Probably the signature of `q` is inferred when the block is
boxed, while `h` has no value, so `a` is read as a scalar and the evaluation
maps `q` over the list.

Impact `major` or `minor`: an error where a value is expected; the
workaround (`function`) exists, but the error does not point to it.
