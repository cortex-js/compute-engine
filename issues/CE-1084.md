In Epsil, an error in the argument of `Exp` or in the numerator of a division underlines the whole call, not the argument.

## Witness

```
let w: any = "s"
let v = Exp(w) + 1   ->  frames Power argument 2, Add argument 1; underline Exp(w)
let v = w/2 + 1      ->  frames Multiply argument 2, Add argument 1; underline w/2
expected             ->  the underline w
```

The message also says `in Power argument 2` for the written `Exp(w)`.

## Cause and options

The canonical form of `Exp(w)` is `Power(ExponentialE, w)`, and that of
`w/2` is `Multiply(1/2, w)`, so the frames name `Power` and `Multiply`.
`locateError()` (`src/epsil/error-location.ts`) matches a frame to a written
call by operator name, and finds no written `Power` or `Multiply`. Option:
map a frame of `Power` with the base `ExponentialE` to a written `Exp`, and a
frame of `Multiply` to a written division, through the source range that
each canonical operand keeps.
