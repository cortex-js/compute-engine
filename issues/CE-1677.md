The black-hole function of the Tycho showcase takes about 27 seconds for one point when every coordinate is a whole number.

## Witness

The prelude of `BLACK_HOLE_ENTRY` in Tycho's
`src/graph-paper/onboarding/showcase-nature.js` (the Epsil function
`blackhole(x, y, a)`: five locals, then a `for n in 1..12` loop that updates
`radius` with `max(…)`, `sqrt` and trigonometric functions). With the
prelude run by `executeEpsil` and the CE-1359 fix in place:

```ts
ce.box(['Power', ['blackhole', 'x', 'y', 'a'], 0.6]).subs({ x: 5, y: 3, a: 84 }).N();
// 0.7365…, correct, after 27 to 33 s
```

At `x: 5.5, y: 0.5, a: 84` the same call takes about 15 ms. A heatmap grid
point or a value typed by a user can have integer coordinates, and the slider
`a` is an integer.

## What the user sees

A host that evaluates the function with the interpreter waits half a
minute for such a point. The workaround is to compile, which every target does
for this program.

## Cause and options

The statements of a function body before the last one run exactly, also
under `.N()` (`resultStatementRequest` and `evaluateStatements` in
`src/compute-engine/function-utils.ts`: an intermediate value must not be
rounded on the way). With exact inputs, `radius` holds an exact expression
that each pass puts into the next one twice, so its size doubles with each
pass, and the time goes to the `.N()` of that expression and to the
`max(…)` comparisons of it (a profile puts 22 of 33 s in
`exact-operands-under-n.ts` and the guard digits of `.N()`).

Options:

1. Under `.N()`, an assignment in a loop body stores the numeric value when
   the expression it computes is larger than a bound. This changes the
   documented rule that intermediate statements run exactly: a decision.
2. Keep the rule, and make the `.N()` of an expression that shares
   sub-expressions compute each shared node once (a memo per `.N()` call).
   The exact value would still grow in size, but the time would be linear in
   the number of passes.
3. Keep both, and document that an iteration on exact inputs is a symbolic
   computation, with the advice to give a float input (`5.0`).
