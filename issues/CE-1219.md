With `constantFold: false`, the compiled derivative `D(f, x)` reads its variable `x` as an input when `x` holds a value.

## Witness

At `114403d0b44156730f1f943b12362d0c74f90fc8`, `ce.assign('x', 4)`:

```ts
const e = ce.box(['D', ['Power', 'x', 3], 'x']);
compile(e).code;                                          // 48
compile(e, { cse: false, constantFold: false }).code;     // 3 * (_.x * _.x)
compile(e, { cse: false, constantFold: false }).run({ x: 0.7 }); // 1.47
```

The interpreter gives 48, and `x³` alone compiles to `_SYS.pow3(4)` with
the same options.

## Cause and options

The closed form of `derivativeClosedForm()` is boxed in a child scope
where `x` is the bound variable of `D`, so its `x` is compiled as a free
input, where the parent compilation folds the value of a symbol with a
value. Option: substitute the values of the variables of `D` that hold
one in the closed form before it is compiled, or compile the closed form
in the scope of the caller. The numeric-kernel profile declines this case.
