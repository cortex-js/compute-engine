`Rationalize` with a tolerance below double precision ignores the tolerance.

## Witness

On main:

```
ce.box(['Rationalize', { num: '0.12345678901234567890123' }, { num: '1e-25' }]).evaluate()   // 4115227/33333339
```

That rational is 1.9e-16 from the operand (computed by the reviewer with Python `fractions`).

## Cause and options

The evaluate handler calls `rationalize(f.re, tol.re)` on doubles. Use the bignum value of the operand and tolerance when the tolerance is below about 1e-15. Size S.
