A function mapped over a list that is chosen by a condition gives an empty list, and its sum is 0, with no error.

## Witness

```ts
const ce = new ComputeEngine();
const f = ['Function', ['Add', 'k', 1], 'k'];
const pick = ['If', 'True', ['List', 4, 5], ['List', 1, 2, 3]];
ce.box(['ListFrom', ['Map', f, pick]]).evaluate().json; // ["List"], expected ["List", 5, 6]
ce.box(['Sum', ['Map', f, pick]]).evaluate().json; // 0, expected 11
ce.box(pick).evaluate().json; // ["List", 4, 5]
ce.box(['ListFrom', ['Map', f, ['List', 4, 5]]]).evaluate().json; // ["List", 5, 6]
```

The same with `c: boolean` assigned `True` and `L: list<real>` assigned
`[4, 5]` in `If(c, L, [1, 2, 3])`. `Map(f, pick).evaluate()` stays
`Map(f, If(…))`. Run with `npx tsx` on
`8c329038e1218e0a817cb1b5acbbe6b4cb2d6e7a`.

## Cause and options

Not read. The lazy `Map` seems to iterate its second operand without
evaluating the `If`, and an `If` is not a collection, so it yields no
element. Options: `Map` (and the other lazy collection operators, to check:
`Filter`, `Zip`, `Comprehension`) evaluates a source that is not a
collection before it iterates; or the iteration of a conditional iterates
the arm that the condition selects.
