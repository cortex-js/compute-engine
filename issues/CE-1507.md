A function that changes its own parameter and then returns a list built from it gives a list of the wrong length and the wrong elements.

## Witness

On CE main 0caa86406:

```
F(p) := Block(Assign(p, [1, 2]), Comprehension(At(p, k), Element(k, Range(1, Length(p)))))
F([10, 20, 30])
// [[1, 2], [1, 2], [1, 2]]; expected [1, 2]
Length(F([10, 20, 30]))   // 3; expected 2
Sum(F([10, 20, 30]))      // [3, 6]; expected 3
```

An Epsil function that reassigns its parameter and then returns a
comprehension over it reaches it. The lazy view keeps the activation of the
call, and the end of the call does not give it the written value of `p`
consistently: the length reads the argument (3 elements), each element
reads the written list.

## Cause

Measured on a8ca1ac1b7e98f52d953ff2fc4467580cb368a24. The lazy view is not
the cause: the body with `ListFrom(…)` around the comprehension gives the
same `[[1, 2], [1, 2], [1, 2]]`, and so does the body
`Block(Assign(p, [1, 2]), p)`. The call maps `F` over the elements of the
list argument, and each of the three calls returns `[1, 2]`.

The boxing of the literal sets the type of a parameter that the body
assigns to a non-inferred `unknown`, and removes the requirements of its
uses, because a use after the write describes the written value, not the
argument (`function-utils.ts`, the loop after the comment "A use describes
the incoming argument"). The slot of `p` is then `unknown`, which is a
scalar parameter, and rule 1 of `docs/BROADCAST-MODEL.md` maps a function
with a scalar parameter over a list argument. The value of the witness
follows that rule. It is the value of `p ↦ [1, 2]` for the same argument,
and of a body that copies the list into a local instead of into `p`. The
Epsil form gives the same value:
`function F(p) { p = [1, 2]; [p[k] for k in 1..length(p)] }` then
`F([10, 20, 30])` is `[[1, 2], [1, 2], [1, 2]]`.

So `[1, 2]` is the value only if a written parameter binds a list argument
whole, which changes the documented contract. That is the decision.

The two routes that derive the slot also disagree for a written parameter.
`wholeCollectionParameterType()` (`effects-inference.ts`) reads the body
syntactically and counts a use after the write:

```
g(n) := Block(Assign(n, Range(1, n)), Sum(n))     // slot collection<any> | value
g([3, 4])   // Error(incompatible-type, number, vector<integer^2>)
h(n) := Block(Assign(n, Range(1, n)), Length(n))  // slot unknown
h([3, 4])   // [3, 4]
g(3)        // 6
```

## Options

A. Keep the mapping, as rule 1 says: a write erases the argument, so the
   uses after it give no evidence about the argument, and the slot stays
   `unknown`. `F([10, 20, 30])` stays `[[1, 2], [1, 2], [1, 2]]`. Make
   `wholeCollectionParameterType()` agree: a use of a written parameter is
   not evidence (as a copy into a local is not, user decision 2026-11-14), so
   `g([3, 4])` gives `[6, 10]`, as `h` maps. The remedy for a body that
   wants the list whole is a declaration: `F(p: list)` gives `[1, 2]`
   (measured). Document the rule with the `F` example in
   `docs/BROADCAST-MODEL.md`, rule 1.
B. A written parameter binds a list argument whole: its slot is
   `collection<any> | value`, as for a parameter that the body consumes
   whole. `F([10, 20, 30])` gives `[1, 2]`, `g([3, 4])` stays an error, and
   a scalar function that writes its parameter stops mapping: with
   `function c(n) { while n > 1 { n = n / 2 }; n }`, `c([8, 4])` is now
   `[1, 1]`, and with the list bound whole (measured with `n: any`) it is
   `Error(incompatible-type, boolean, 1 < [8, 4])`.
C. Lift the slot from the uses after the write too (the requirements that
   the boxing now removes). `F([10, 20, 30])` gives `[1, 2]` (`Length(p)`
   and `At(p, k)` lift it), `h([3, 4])` becomes `[3, 4]` bound whole
   (`Range(1, [3, 4])`), and the type of the argument becomes a guess from
   the written value.

Recommendation: A. It keeps one rule for the slot (the evidence is a use
of the argument), it is the rule that the boxing already states for the
inferred type, and the fix is the removal of one path in
`wholeCollectionParameterType()`. B and C change rule 1 for a case whose
only witness is this review, and B breaks scalar functions that update their
parameter in a loop.
