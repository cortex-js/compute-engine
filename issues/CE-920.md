In Epsil, an error in one of two calls of the same function underlines the whole expression instead of the call that failed.

## Witness

```
let v = Ln("a") + Ln(2)
runtime error        ->  underlines the whole call
static-type-error    ->  underlines the whole statement
expected             ->  both underline Ln("a")
```

## Cause and options

The `Ln` frame matches two written calls, so `locateError()`
(`src/epsil/error-location.ts`) treats it as ambiguous. The error carries the
offending value `"a"`, and `cannotBeValue()` already tells that `Ln(2)` cannot
have made it: use it to drop the call whose argument differs before the match
is called ambiguous. Related: CE-105, CE-921.
