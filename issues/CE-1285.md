A sum over all integers, from minus infinity to infinity, takes about 2 s for `2^{-|n|}`, while each half of it takes a few tens of milliseconds.

## Witness

Measured on commit `40ba059a8444959fbcfb94fe393d1a540d423088`, on a loaded
machine, `ce.expr(json).N()`:

| Sum | Time | Value |
| --- | --- | --- |
| `Σ_{n=0}^{∞} 2^{-\|n\|}` | about 55 ms | 2 |
| `Σ_{n=-∞}^{0} 2^{-\|n\|}` | about 25 ms | 2 |
| `Σ_{n=-∞}^{∞} 2^{-\|n\|}` | about 1.8 s | 3 |
| `Σ_{n=-∞}^{∞} 0.5^{\|n\|}` | about 1.1 s | 3 |
| `Σ_{n=-∞}^{∞} sinc³(n)` | about 3.5 s | 2.3561944901923635 |
| `Σ_{n=1}^{∞} sinc³(n)` | about 0.8 s | 0.678097245096189 |

The values are right. Test: `test/compute-engine/calculus.test.ts`
("DOUBLY-INFINITE SUMS").

## Cause and options

The review traced the doubly-infinite sum to `extrapolatedInfiniteSum`
(`library/utils.ts`), which computes the terms with the big-decimal `pow`;
the one-sided sums take a faster path. This file did not profile it again.

- Split a sum over ℤ at 0 into two one-sided sums (`Σ_{n≥0} + Σ_{n≤-1}`) and
  evaluate each with the one-sided path. Size S. The sum over ℤ then costs
  about the sum of its halves.
