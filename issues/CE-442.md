Evaluating the same derivative of a Tycho path again computes the derivative again, about 0.5 s each time.

## Witness

Evaluating the same `D(PointY(h(u)), u)` node of Tycho's 29-piece path again
differentiates again each time: about 0.5 s per evaluation on a loaded
machine.

## Cause and options

`D` is `lazy`, so the memo of inert evaluations leaves it out, and
`withDeclinedDerivativeMemo` (`library/calculus.ts`) records only declines.
Possible fix: record a successful result with the same dependency stamps as a
decline.
