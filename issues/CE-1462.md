On 0.194.0 the `step` function of Tycho's `buddhabrot` prelude does not compile to JavaScript, so `const H_1 = step(H_0, 1200000)` runs on the interpreter, and Tycho's prelude deadline cancels it.

## Program

The whole prelude is the `prelude` field of the entry `buddhabrot` in
Tycho's `src/graph-paper/onboarding/template-data.js`. In short:

```
const N = 90001
const H_0 = [0 for k in 1..N]
function step(H: list<integer>, n: integer) -> list<integer> {
  let L = H
  const r = H[90001]
  parallel for k in 1..n {
    const p = 3 * fract(0.7548776662 * (r + k)) - 2
    const q = 3 * fract(0.5698402910 * (r + k)) - 1.5
    ...
    for m in 1..5000 {
      (a, b) := (a^2 - b^2 + p, 2*a*b + q)
      ...
    }
    ...
    L[c] += 1          // the cell of the orbit point, in each plane, and its mirror
  }
  L[90001] += n
  L
}
const H_1 = step(H_0, 1200000)
```

Target: javascript. Sequential execution is acceptable; a worker pool is
not required.

## Observed (0.194.0)

The compile declines (compute-engine-8c's reading, CE 9d9931734; the first
is the one the compiler reports):

1. `ParallelLoop`: "the operator ParallelLoop is not supported by the
   compiler".
2. `(a, b) := (…)`: an `Assign` of a `Tuple`.
3. `L[c] += 1`: `AddTo` of a list element, also in a plain `for`.
4. any write to a list local (`L = replaceAt(L, …)`): "a write to a
   constant (the interpreter refuses it) or to a list local".

The scalar rest of the body compiles. The instrument prints
`route: interpreted` and the diagnostic "the statement gives an error:
Operation canceled".

## Expected

The statement compiles and runs in about the time of 0.193.0: 333 ms on one
thread, 123 ms on 8 workers (Tycho's measurements before this adoption). The
interpreter exceeds Tycho's 30 s prelude deadline.

The compiled float64 values may differ from the interpreter's: the
interpreter keeps `0.7548776662*(r+k)` exact, and the orbits are chaotic.
0.193.0's compiled values differed in the same way; Tycho does not need them
equal.

## Design

compute-engine-8c's draft: `docs/plans/2026-11-18-ir-parallel-for-and-list-locals.md`
(not approved yet).

## CE answer

CE (2026-11-18): P1 (major, high, one step up for the `regression` flag: the table value). Disposition: needs-design. The
design is `docs/plans/2026-11-18-ir-parallel-for-and-list-locals.md`, a
draft that waits for the user's approval of its scope (D1: the four pieces;
D2: no worker pool in this version); it is proposed for the next release
once approved. The program compiles on JavaScript only: GLSL declines `H`,
a list of run-time length. A workaround that CE has not tested: compute
`H_1` once outside the document and ship it as a constant list of 90,001
integers, or keep the entry on the interpreter with fewer samples until the
fix lands.

CE (2026-11-18, later): the user approved the design (D1: all four pieces).
The worker pool is a fast follow under this issue, since 0.193.0 had it
(design note, section 6): the issue stays open until `runAsync()` runs the
step on the pool.
