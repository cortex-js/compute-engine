The interval of gcd(0, −2) is [−2, −2], where the value is 2.

## Witness

At `7c74ab286`, with `n` and `m` declared `integer`:

```ts
const r = compile(ce.box(['GCD', 'n', 'm']), { to: 'interval-js' });
r.run({ n: { lo: 0, hi: 0 }, m: { lo: -2, hi: -2 } });
// { kind: 'interval', value: { lo: -2, hi: -2 } }
ce.box(['GCD', 0, -2]).N(); // 2
```

`GCD(6, -4)` and `GCD(-6, 4)` give `[2, 2]`, which is right: the sign is
kept only when one operand is 0. A plotted `GCD(Floor(x), Floor(y))` meets
the case on every cell where one coordinate is in [0, 1) and the other is
negative.

## Cause and options

`_IA.gcd` (`gcdRaw()` in `src/compute-engine/interval/elementary.ts`)
enumerates the integer points of its operands and calls `scalarGcd` on each
pair; `scalarGcd` returns the other operand as it is when one operand is 0.
Take the absolute value of the result. The interval library is the runtime
of the existing `interval-js` target and of the interval mode of the IR
pipeline, so both give the wrong enclosure. The mode's containment test
pins the case in its `KERNEL_DEFECTS` list
(`test/compute-engine/ir-interval-containment.test.ts`, when batch 1 of
`docs/plans/2026-11-15-ir-interval-mode.md` has landed): remove the entry
with the fix. Size S.
