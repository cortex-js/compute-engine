The Traffic and Nature showcase documents compute a function of a slider value with the interpreter, so they are slower.

## Witness

`a` declared `real | signed_infinity | nan` (the type Tycho gives a value
row):

```
Apply(Function(Multiply(2, p), Typed(p, 'real')), a)
```

compiled on javascript, run at a = 3.

- Interpreter: 6; with `a` = NaN it gives NaN (it accepts the value).
- 0.193.0 compiled: 6.
- 4779733 (0.194.0): "a: an argument of Apply that is not real, the type of
  its parameter p".

Control on 4779733: `a` declared `real` compiles, 6.

## Expected

The IR README ("The contracts", inputs) reads an input of type
`nan | real | signed_infinity` as a real, and a parameter declared a scalar
takes a scalar of its lane. CE-1483 admitted the same union as the element of
a list argument at a `list<integer>` parameter. The call compiles with the
interpreter's value.
