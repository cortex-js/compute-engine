The list of unknowns of a block that assigns two names at once from a tuple includes those two local names.

## Witness

```
Block(Assign(Tuple(a, b), Tuple(1, 2)), Add(a, b)).unknowns  ->  ['a', 'b']   expected []
Block(Assign(c, 1), Add(c, 1)).unknowns                       ->  []
```

The first block evaluates to 3 and declares neither name outside the block.

## Cause and options

The free-variable walk (`collectReferences`, `abstract-boxed-expression.ts`)
does not count the symbols of a `Tuple` target of `Assign` as locals of the
block. Fix it there. The same on main before CE-597.
