The Lambert W function does not compile for the GPU or for interval plots.

## Witness

`LambertW(x)`, `x: real`, on `glsl` and `interval-js`: 0.193.0 and 0.194.x
decline ("LambertW … on glsl", and the interval mode has no kernel).
`javascript` compiles it (`0.5671432904097838` at 1). It never compiled on
these targets, so it is not a regression.

## Cause and options

No GLSL helper and no interval kernel for `LambertW`. A GLSL helper is a
Halley iteration from an initial estimate (the JavaScript runtime's
routine); an interval kernel needs an enclosure of `W` on its two
monotone branches.
