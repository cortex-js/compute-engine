Asking whether `x > 0` can be true gives false, because the analysis treats `x` as a true-or-false value.

## Witness

```
IsSatisfiable(x > 0)   // False, where it must be True or stay unevaluated
TruthTable(x > 0)      // [["x","Result"],["False",0 < "False"],["True",0 < "True"]]
```

Measured at 074e6347f39717e4f6d5b44521c5c459b6d9d2b7.

## Cause and options

The truth-table analysis (`library/logic-analysis.ts`) takes every free symbol as a boolean variable, also a symbol inside a comparison. A proposition whose atoms are not all boolean symbols must stay unevaluated (or its comparisons be read as atoms). The same holds for `IsTautology`, `TruthTable`, `PrimeImplicants`, `MinimalDNF` and the other functions of that module.
