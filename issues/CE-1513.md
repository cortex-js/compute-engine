A call of a function over a value of unknown type and a list of two numbers is typed as a list of two numbers, but its value can be a list of lists.

## Witness

```
U := (a, b) ↦ a + b
ce.declare('g', '(number) -> unknown')
U(g(2), [1, 2])                  typed vector<2>
U([[1, 2], [3, 4]], [1, 2])      value [[2, 3], [5, 6]]
```

A value of `g(2)` can be `[[1, 2], [3, 4]]`, and the value of the call is then
a 2×2 matrix, which `vector<2>` does not hold. The same call over `y` declared
`number | tuple | list<number | tuple | list<any>>` is typed `any`, which
holds it (CE-545 kept that answer for this case).

## Cause and options

`lambdaBroadcastType` (`boxed-function.ts`): the list `[1, 2]` participates,
the operand of type `unknown` does not, and the mapped branch types the call
with the shape of the list alone. Option: when an operand of type `unknown`
(or of the open form) is beside a mapped list, wrap the result with
`list<R | list<any>>` at the inner level, or answer `any`. Size S.
