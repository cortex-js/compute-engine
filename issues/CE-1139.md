In Epsil, the message of an error in the argument of `Exp` or in the numerator of a division names an operator that the program does not contain.

## Witness

```
let w: any = "s"
let v = Exp(w) + 1  ->  "in Power argument 2, in Add argument 1"
let v = w/2 + 1     ->  "in Multiply argument 2, in Add argument 1"
expected            ->  "in Exp argument 1, ..." and "in Divide argument 1, ..."
```

The underline is `w` in both programs (CE-1084); only the text of the frames
names the canonical call.

## Cause and options

`errorFrameChain()` (`src/epsil/execute-epsil.ts`) prints the frames of the
`ErrorTrace` as recorded, and the canonical form of `Exp(w)` is
`Power(ExponentialE, w)`, that of `w/2` is `Multiply(1/2, w)`.
`renamedCallFrame()` (`src/epsil/error-location.ts`) already maps such a frame
to the frame of the written call through the source ranges of the canonical
call and its operand. Option: return the mapped frames from `locateError()`
and print them in the message; a frame recorded outside the statement (the body
of a called function) stays as recorded. Tests that pin the message text of
such errors change.
