The generalized incomplete gamma function with exact arguments is not computed, although the difference of two upper incomplete gammas that it equals is.

## Witness

```
GammaRegularized(2, 1, 3)                        // stays unevaluated
GammaRegularized(2, 1) - GammaRegularized(2, 3)  // -4/e^3 + 2/e
```

Measured at 074e6347f39717e4f6d5b44521c5c459b6d9d2b7.

## Cause and options

The three-argument arm of `GammaRegularized` (`library/statistics.ts` or `special-functions.ts`) evaluates only numerically. Give it the exact value `Q(a, z0) - Q(a, z1)` when both two-argument forms evaluate exactly.
