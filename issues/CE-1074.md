With `diagnostics: true`, when the domain of a set-builder uses the name of its variable, every use of the variable is reported as an undeclared symbol, not only the free use in the domain.

## Witness

`ce.parse('\\{x \\mid x \\in [0, x]\\}', { diagnostics: true }).parseDiagnostics`
gives three `undeclared-symbol` diagnostics for `x`. Only the last `x`, in the
domain `[0, x]`, is free (`freeVariables` is `["x"]`). The same applies to
`\{S \mid S \in S(t)\}`.

## Cause and options

`pruneSetBuilderVariables()` (`latex-syntax/dictionary/definitions-sets.ts`)
reads the MathJSON result, which has no source spans, so it cannot tell a use
in a domain from a bound use. It keeps every diagnostic of such a name.
Fix: record the token span of each membership domain while the condition is
parsed, and let `_pruneUndeclared()` keep only the diagnostics inside those
spans. Size M.
