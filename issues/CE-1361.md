Dividing a host-declared constant zero by itself gives 1 instead of NaN.

## Witness

```ts
ce.declare('z', { value: 0, isConstant: true });
ce.box(['Divide', 'z', 'z']).json; // 1
ce.box(['Divide', 0, 0]).json;     // 'NaN'
```

Both the frozen baseline ffff1d44fc and the Program candidate give these exact
results. A host can pass a computed constant that happens to be zero; the
medium probability reflects this combination. The workaround is evaluating
its operands before constructing the quotient.

## Cause and options

The existing constant-symbol self-quotient rule assumes a nonzero value in
`boxed-expression/arithmetic-mul-div.ts`. This behavior predates the Program
patch; its runtime-local guard preserves the separate Program-initialization
case without changing this host rule. The older defect is P2 and is recorded
under the repository rule for older findings in rewritten code. No numeric
context change is proposed as part of Program consolidation. Exact two-arm
control output is `program-host-zero-control.jsonl` in the Program measurement
folder.
