A series at 0 of the logarithm of a square, or of the logarithm of minus the variable, is off by 2πi for negative values of the variable.

## Witness

At commit `ce77809c8a52177728a4b19e85ea5b204b29ea91`, the value is `f − Normal(Series(f))` at x = −0.5:

```
Series(Ln(x^2), x, 0, 3)     // 2ln(x) + BigO(x^4);          f − series = −2πi
Series(Ln(-x^2), x, 0, 3)    // 2ln(x) + ln(−1) + BigO(x^4); f − series = −2πi
Series(Ln(-x), x, 0, 3)      // ln(x) + ln(−1) + BigO(x^5);  f − series = −2πi
Series(Ln(x), x, 0, 3)       // ln(x) (correct on both sides)
```

## Cause and options

`symbolic/series.ts`, `lnLaurent()`: it writes `ln(c₀·t^m·(1 + h)) = m·ln(t) + ln(c₀) + log1p(h)`, which holds for `t > 0` only. For `t < 0` and a real `c₀`, the two sides differ by `2πi·k`, with `k = ⌊m/2⌋` when `c₀ > 0` and `k = ⌈m/2⌉` when `c₀ < 0` (the same argument count as `puiseuxHoldsBelow()`, added by CE-1308 for roots). Option (simple, sound): when `bothSides` is set (a `Series` at a finite point), decline unless `k = 0` and, when `c₀ < 0`, every coefficient is real (`hasRealCoefficients()`). The expansion at ±∞ (in `s` at `s = 0⁺`) and `laurentData()` keep the present expansion.
