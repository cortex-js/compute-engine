The `epsil` tool prints an absolute value as `|a|` and a norm as `||M||`, which Epsil cannot read back.

## Witness

Epsil CLI, main 6be5b5f52: `abs(a)` prints `|a|`; `norm([a, b])` prints
`sqrt(|a|^2 + |b|^2)`; the unevaluated `norm([[1, 2], [3, 4]], 3)` prints
`||[[1,2],[3,4]]||` (its second operand is lost). `let x = -3; |x|` is
`error: Unexpected symbol "|"`.

## Cause and options

The Epsil printer writes `Abs` and `Norm` in math notation. Fix: print
`abs(a)` and `norm(M, 3)`, the function call forms, and add a round-trip test
for both. Related: CE-1380 (booleans printed in quotes).
