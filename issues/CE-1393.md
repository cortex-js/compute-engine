The `epsil` command line tool refuses a program that starts with a minus sign: `epsil -e '-5 % 3'` fails with "Option '-e' argument is ambiguous".

## Witness

`npx tsx src/cli/epsil.ts -e '-5 % 3'` (main 1e146ff55) prints
"Option '-e' argument is ambiguous. Did you forget to specify the option
argument for '-e'?". `-e=' -5 % 3'` is read as `=-5 % 3`. The same program
with a leading space, `-e ' -5 % 3'`, prints 1 (workaround). The cortexjs.io
script `verify:details` passes each example in the same way, so the reference
cannot show such a program alone.

## Cause and options

The option parser takes a value that starts with `-` for an option. Fix:
accept `--eval=<program>` and `-e <program>` whatever the first character
(the parser's option for a value that may start with a dash), and document
`--` if the parser needs it.
