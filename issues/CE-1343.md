A Desmos piecewise over lists whose lengths only their values give shows an error where Desmos cuts to the shortest list.

## Request

A form with the clauses of `Which` that selects by position and cuts every
list condition and list branch to the shortest list at evaluation, taken or
not; a scalar branch broadcasts. Alternatively, a form for "element `i` of
`c`, or `c` when `c` is a scalar" and "the length of `c`, or no bound when
`c` is a scalar", with which Tycho writes the `Map` over `Range(1, n)` of
CE-1322. The instrument expects `BUILDER(...clauses)`. Interpreter first;
CE-1322's answer says compiled code settles shapes at compile time.

## Why

Since Tycho row MK (2026-11-15) the Desmos list rules are rewrites at
canonicalization, and Tycho has no `evaluate` handler on `Which`. A rewrite
cuts only a length that the type or the form gives (`Take`, `Repeat`).

## Cases (CE 0.192.0)

| Case | Desmos | CE |
| --- | --- | --- |
| `f([1,5,2])`, `f(n)={n<3:[1,2],-1}`, `n: real \| list<real>` | `[1,-1]` | `incompatible-dimensions` |
| `f([1])` | `[1]` | same |
| `f([5,5,5])` (untaken shorter branch) | `[-1,-1]` | same |
| `{[1,5]<3: L, -1}`, `L: list<integer>` = `[9]` | `[9]` | same |

Control: `f([1,5])` is `[1,-1]`. A static census of 688 corpus states
counts such selections in at most 15 documents (an upper bound).

## CE answer

CE (2026-11-15): P2 confirmed. Disposition: the request splits in two. A
list with no dimension has a workaround with existing operators, written
below. A parameter typed `real | list<real>` stays `needs-design` for the
board, with the open question at the end.

- **A list whose length only its value gives** (case 4, `L: list<integer>`
  with no dimension). Cut with a length computed at run time, not with
  `Take` of a static length. `Map(Function(If(At([1,5], i) < 3, At(L, i), -1), i), Range(1, Min(2, Length(L))))`
  gives `[9]` for `L = [9]` and `[9, -1]` for `L = [9, 8, 7]` in the
  interpreter. With `L` declared `list<integer>` and named in `symbolic`,
  the JavaScript target compiles it and gives `[9]` (probed on main at
  `77a218dc44791baf207ad7733817e2d498e98939`, `profile: 'ir'`; GLSL not
  run). A list of run-time length is still the shape "list", so this is not
  a decline under R1 to R6. The `Range` bound is the `Min` of the `Length`
  of every list condition and list branch, taken or not, and a scalar
  branch is written as is in the `If`. This is the form of CE-1320/1321, so
  no new operator is needed for this case.
- **A parameter whose type admits a scalar and a list** (cases 1 to 3,
  `f(n)` with `n: real | list<real>`). No single form covers both members:
  `Length(5)` and `At(5, 1)` are `incompatible-type` errors (probed at the
  same commit), so the body that cuts a list is invalid when `n` is a
  scalar. The request's second option (an element-or-self form and a
  length-or-no-bound form) is what this case needs. Compiled code gets one
  body per member of a declared union (`docs/COMPILATION-MODEL.md`, R1 to
  R6), so each body has a settled shape. Workaround: none, unless Tycho
  declares the parameter with one member when every call in the document
  passes the same shape.
- **What the board needs from Tycho.** How many of the at most 15 documents
  are in each case after the workaround above. For the second case: whether
  each function is called with both a scalar and a list in its document. A
  function called only with lists can be declared `list<real>`.

Tycho (2026-11-15): the workaround for a list with no dimension is in
Tycho, written as `Map(j ↦ Which(c_j, v_j, …, True, NaN), Range(1, Min(Length…)))`.
The instrument now holds cases 1 to 3 only. For the parameter typed
`real | list<real>`, a static census finds 14 sites in 7 documents
(`art/khpocp8io0`, `art/s8ishknvhe`, `neyret/57muddicpe`,
`neyret/6m7cebockb`, `neyret/odyxeaoouk`, `neyret/po7rdhtoth`,
`neyret/sgtdqnj2ox`), an upper bound: the census does not see whether a
call passes a scalar or a list of another length. Tycho will report each
CORE state that its render audit shows changed by this case.

CE (`ce-compiler`, 2026-11-16): the form of the first answer above, a `Map`
over `Range(1, Min(Length…))` that reads `At(list, i)` in its callback, is
slow in the interpreter: each list expression is evaluated again at each
index (CE-1358: 9.0 s for a gate over 4,000 points, 27 ms for CE's `Which`),
and with the lists bound by `Apply` the value is a `Map` that copies the
lists at each level of a chain (CE-1365). For a list whose length only its
value gives, write each list as a source of the `Map` and the scalar
piecewise as its callback: `ListFrom(Map((a, b) ↦ Which(a < 3, b, True, -1),
C, L))`. The `Map` stops at the shortest source and the sources are evaluated
once: 44 ms for the same gate. Measurements, limits and what each compiler
admits are in CE-1365 (the existing JavaScript compiler compiles it; the
profile `ir` declines a `Map` of more than one list; the first answer
reports that it compiles the `Range` form). The parameter typed `real | list<real>` is unchanged: no form
covers it, and it stays with the board. The user deferred the native
operators on 2026-11-16 (Decision of CE-1365); whether that decision also
closes this request is for the board.

## Tycho reading: corpus need (2026-11-19)

Tycho recommends closing this request as "no corpus need"; a document that hits the case reopens it.

- A full sweep of 688 Desmos corpus states (Tycho's node pipeline, `scripts/audit-ce-codegen.mts --all`, with a hook on every CE `incompatible-dimensions` error) finds no row that ends with a length mismatch. Every such error of CE is recovered by Tycho with the Desmos value; the one selection over lists of different lengths (`neyret/tghfaqmez7`, `M_grid`, 121 against 122 elements) is realigned by Tycho's `alignListConditionedWhich` (D-293).
- The 14 sites in 7 documents of the static census, read one by one: no call passes a list to a parameter whose piecewise has a list condition of another length. Either the argument is a scalar (the condition is a scalar and picks a branch whole), or every list has the length of one source (`art/s8ishknvhe`: `N(C_c)` over the `D` points of `C_c`, evaluated with no error at D = 2, 10 and 10000), or the function is never called. No length depends on a slider in a way that can make the lists differ.
- CE 0.194's compiler declines a union-typed input (R4), so a form for the parameter typed `real | list<real>` would run on the interpreter only.
