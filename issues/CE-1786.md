In Epsil, an error in the body of a function that an operand of `Range` or `Union` calls underlines another operand.

## Witness

```
function g(x) { Ln(x) + 1 }
let y = 5

let v = Range(y + 1, g("a"))             underline -> y
let v = Union(Set(y + 1), Set(g("a")))   underline -> y
expected: g("a") or the statement
```

## Cause and options

`Range` and `Union` record no frame for the operand that holds the error, so
the error has only the frames of the body of `g`, and the frame
`Add argument 1` selects the `y` of `y + 1`. The fix of CE-1752
(`isAcrossElements()`, `src/epsil/execute-epsil.ts`) uses the range of the
statement for the same case in a list, a tuple or a set literal, which also
record no frame for their elements.

- (a) Add the frame of the operand in `Range` and `Union`, as other calls do.
- (b) Add `Range`, `Union` and the other calls that record no frame for an
  operand to the heads that `isAcrossElements()` reads.
