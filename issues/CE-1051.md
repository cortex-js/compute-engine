The LaTeX of a sum over a set with a condition leaves out the condition, so the LaTeX parsed again gives another value.

## Witness

```
const s = ce.box(['Sum', 'k', ['Element', 'k', ['Set', 1, 2, 3], ['Greater', 'k', 1]]]);
s.latex                      ->  \sum_{k\in \lbrace1, 2, 3\rbrace}k
s.evaluate()                 ->  5
ce.parse(s.latex).evaluate() ->  6
(probe 2026-11-07, HEAD 5ab79553c01efb59ebfbc53e0298267fb7bea620)
expected  ->  \sum_{k\in \lbrace1, 2, 3\rbrace, k>1}k, which the parser reads back
```

## Cause and options

Not traced. The serializer of `Sum` and `Product` writes the index and the
collection of an `Element` clause and leaves out its third operand. The
parser already reads the form `k \in S, k > 1` (`getIndexes()`,
`definitions-arithmetic.ts`). Size S.
