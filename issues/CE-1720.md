A replacement inside a block that declares a local variable loses the value of that variable.

## Witness

```js
ce.box(['ReplaceAll',
  ['Block', ['Declare', 'a', 'integer'], ['Assign', 'a', 5], ['Add', 'a', ['Sin', 'b']]],
  ['Rule', ['Sin', '_a'], 1]]).evaluate();
// ➔ a + 1; it must be 6
```

The same result with the rules `[b → 3, Sin(_a) → 1]`, and at
e272640e151d3d3f3ec4d4cda9d098eb22647758, before CE-1691.

## Cause and options

`replaceTopDown()` and `replaceAllMixed()` (`library/core.ts`) rebuild each
node above a replaced part with `ce.function(operator, ops)`. For a `Block`,
the read of `a` in the rebuilt body is not bound to the scope of the new
block. (a) Rebuild a scoped node onto its own scope, as `subs()` and `map()`
do (`scopeForRebuild`). (b) Decline (leave `ReplaceAll` unevaluated) when a
part to rebuild has a local scope.
