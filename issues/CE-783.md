The compiled function of `Apply(D(x ↦ sin(nx), x), 1)` throws "is not a function" when it runs.

## Witness

`Apply(D(x ↦ Sin(n·x), x), 1)` compiles on JavaScript (`success: true`); the
compiled code throws `(_.n * Math.cos(...)) is not a function` when it runs.
The interpreter gives a function expression, not an error. Checked at commit
`5784d4aec`.

## Cause and options

Not traced. The compiled derivative is an expression (`n·cos(n·x)`), and the
`Apply` calls it as a function. Options: lower the derivative of a function
literal as a function literal, so that `Apply` calls it; or decline an `Apply`
whose head does not compile to a function.
