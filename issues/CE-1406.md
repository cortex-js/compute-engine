A quantifier nested in a quantifier of the other kind gives the wrong answer: `forAll(x in {1, 2}, exists(y in {1, 2}, y == x))` is False.

## Witness

Epsil CLI, main 0417d3034:

| program | gives | must give |
| --- | --- | --- |
| `forAll(x in {3}, exists(y in {1, 2, 3, 4}, y > x))` | False | True |
| `forAll(x in {1, 2}, exists(y in {1, 2}, y == x))` | False | True |
| `exists(x in {1, 2}, forAll(y in {1, 2}, x > y))` | True | False |
| `forAll(x in {1, 2}, forAll(y in {1, 2}, x >= 1))` | True | (right) |

The MathJSON form `ForAll(Element(x, Set(1, 2, 3)), Exists(…))` gives the same
wrong values.

## Cause and options

The results are those of the outer quantifier over the Cartesian product of the
two domains: the inner quantifier seems to be merged into the outer one
(`evaluateQuantifier`, `library/logic-analysis.ts`). Merging is right only
when both quantifiers are of the same kind. Fix: merge only `ForAll` into
`ForAll` and `Exists` into `Exists`; otherwise evaluate the inner quantifier
for each value of the outer variable. Tests: the four rows above.
