With the profile `ir`, a list expression or a sum that a program writes several times is computed once per occurrence, so the program runs up to 2.5 times slower than on the existing compiler.

## Witness

`neyret/odyxeaoouk` #0 of Tycho's run t13 (`At(X, X ≤ X)` with `X` a
`Comprehension` written three times): 1.46 to 1.53 times the existing
JavaScript compiler at list lengths 10 to 50 (under the bound at lengths 3 and
4). Reduced, `L: list<real>` of 20 elements:

```json
["Add", "X", ["Multiply", "X", "X"]]
```

with `X` standing for
`["Comprehension", ["Multiply", 3, ["At", "L", ["Ceil", ["Divide", "i", 2]]]], ["Element", "i", ["Range", 1, ["Multiply", 2, ["Length", "L"]]]]]`
written out at each place: 2.47 times the existing compiler, which shares `X`
through `_cse`. On the interval seam (`ce-interval`): `neyret/zrklhsz34x` #4
and `neyret/n3nirm8khz` #4 compute the same `Sum` loop twice, 1.41 and 1.39
times the existing interval target; one loop by a hand edit gives 1.00.
Measured on main `7fbb0870f4179f70bad96eba412f1381407a6944` (G29's tree) and
`476f3757dd4017ea1ced5d453274d34f13bf0f00`.

More JavaScript witnesses, 2026-11-16: `neyret/lg5hblqpel` #8 and #9, which
compile since `79e249839991b6832843b8f11f6efa34f894e291` (G30), repeat
`Min(Map(…))` and build each copy again: 2.0 to 2.1 times the existing
compiler, re-timed alone (76 and 79 µs a call). In the replay of that head,
`neyret/odyxeaoouk` #0 and `neyret/nqfechxzqp` are at 2.9 and 2.7 times.

## Cause and options

The pass `cse` of `ir/passes.ts` merges an INSTRUCTION with an earlier one of
the same operation and operands. A `build`, a `filter` or a `loop` holds a
region, and two regions with the same body are not compared, so each
occurrence keeps its own loop. The lowering's structural memo shares a node
that is written once and read twice; it does not share two nodes of the same
structure when their lowering opens a frame.

Options:
- (a) a structural key for a region instruction in `cse` (the inner values
  numbered in order of definition, the outer values by identity), so that two
  equal `build`, `filter` or `loop` instructions with no effect merge. About
  50 lines by the estimate of the agent that diagnosed the interval programs.
- (b) the structural memo of the lowering also keys a node whose lowering
  opens a frame, when the frame reads nothing but the node's own names. Not
  sized.
- (c) no change: the programs stay listed as exceptions to the 1.1 bound.

Count first: the replay gives three corpus programs so far (one JavaScript,
two interval). Not started.
