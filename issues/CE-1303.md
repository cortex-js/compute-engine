An Epsil program whose `while` condition compares with a name that has no value never returns when a host runs it with `executeEpsil`.

## Witness

Run on main at `b3a2ae1065d1b8483bc5124e5ebbde813af6289a` (by the agent of the investigation; not run again by the session):

```
let i = 1
while i <= n {
  i = i + 1
}
i
```

`executeEpsil(new ComputeEngine(), source)` does not return in 20 s (stopped
by `timeout 20`). With `ce.iterationLimit = 50` it returns `52` and the
diagnostic `evaluation-canceled` / `iteration-limit-exceeded`. `npx epsil`
stops at its default 10 s deadline with "Evaluation canceled (timeout)".
With the bound `3` the program returns `4` in 25 ms. `while i <= length(L)`
with `L` free hangs the same way.

A program with a syntax error reaches the case too:
`fn f(L: list<real>) { let total = 0; let i = 1; while i <= length(L) { total = total + L[i]; i = i + 1 }; total }; f([1, 2, 3])`.
`fn` is not a keyword. The parser reports `unexpected-symbol "f"` and drops
the function header, so the loop runs at the top level with `L` free. A
diagnostic does not stop the run (`docs/errors.md`), and the host never sees
the diagnostics, because the call does not return. The run stopped at the
60 s timeout. With `function` in place of `fn` the program returns 6 in
58 ms.

## Cause and options

The parser lowers `while c { b }` to `Loop(Block(If(Not(c), Break), b))`
(`src/epsil/parser.ts`, `parseWhile`). `If` takes the `Break` only when
`Not(c)` is `True`. An undecided comparison never is, so the loop goes on,
and an Epsil run has no iteration limit (`iterationLimit`,
`src/compute-engine/index.ts`). `docs/control-flow.md` says that `while`
"repeats its body until the condition becomes false" and does not say what
an undecided condition does.

- (a) A condition that is neither `True` nor `False` ends the loop with an
  error value (`incompatible-type`, expected `boolean`, at the `while`),
  reported as a runtime error. Recommended: the program stops and says why.
- (b) Lower to `If(c, b, Break)`. An undecided condition then ends the loop
  with no error, and the variables keep the values they have.
- (c) No change: the host passes a deadline (`ce.withTimeLimit`), as the
  CLI does.

Each option needs a sentence in `control-flow.md`.
