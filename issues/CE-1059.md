A numeric integral of an integral can say that it met its tolerance when its own error estimate is far larger than the tolerance.

## Witness

```ts
const coarse = { maxIntervals: 2, initialPanels: 1 };
const inner = (lo, hi) =>
  adaptiveQuadrature((x) => Math.sqrt(x), lo, hi, coarse).estimate;
// ∫₀¹ y^(−1/2)·I(y)/y^1.5 dy with I(y) = ∫₀^y √x dx; the value is 4/3.
adaptiveQuadrature((y) => inner(0, y) / y ** 1.5 / Math.sqrt(y), 0, 1,
  { nestedErrors: true });
// at b97dc8d9b: estimate 1.3333428, error 0.016, converged: true
```

The tolerance is about `1.3e-10`, so the result must not be converged.

## Cause and options

`reportNestedResult()` (`numerics/gauss-kronrod.ts`) adds
`tolerance/|estimate|` of each inner integral to `relativeTolerances`. Near
`y = 0` the inner value is very small and its tolerance is the absolute
`atol`, so this ratio is very large, and `withNestedErrors()` adds
`|v|·relativeTolerances` to the tolerance sum. Option: use the relative
tolerance only when the inner tolerance is the relative one
(`rtol·|estimate| ≥ atol`). Size S.
