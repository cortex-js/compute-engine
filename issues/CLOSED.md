- CE-690 (2026-11-06, was P3; error, minor, high, corpus; GitHub #494): A numeric integral next to a singular bound is much less accurate than in release 0.170.0, with a correct but wide error. Witness: `N(Integrate(t ↦ cos(t/2)/√(cos t − cos ½), [0, ½])) today: 2.2214414411509225 ± 0.0007 (true error 2.8e-8) 0.170.0: 2.221441469078394 ± 8.3e-12 (true error 7.9e-13)`. Closed: user decision 2026-11-06: not fixed (verified 2026-11-06: still 2.2214414411509225 ± 7e-4, true error 2.8e-8), but the result is correct within its error bar. The 0.170.0 extrapolation gives a wrong finite value next to a step of the integrand, so it stays refused. Workaround: remove the cancellation in the integrand, cos t − cos ½ = 2 sin((½+t)/2) sin((½−t)/2), which gives 2.2214414690791946 ± 1.9e-13 (true error 1.2e-14).
- CE-51 (2026-11-06, was P2; design, confidence, low, crafted): The engine has three separate answers to "is this a collection", so some operators check twice and an Epsil program cannot define a new kind of collection. Witness: `op.isCollection || op.type.matches('collection<any>')`. Closed: user decision 2026-11-06: not done. The check `x.isCollection || x.type.matches('collection<any>')` is not a duplicate: `isCollection` asks whether the elements can be walked now, the type match asks whether the operand is collection-shaped (doc of `isCollection` in src/compute-engine/types-expression.ts). A protocol conformance answers from the type only, so it is true for `L` declared `list<number>` and not assigned, which has no elements to walk; moving the checks to conformance would make `Sum(L)` give a value where it now stays unevaluated. User-defined collections in Epsil (Iterable/Indexable conformance accepted by Map, Count, …) are a feature with no real program that needs them; not recorded.

- CE-960 (2026-11-06, was P3; design, confidence, medium, corpus; CE-141.3): `simplify()` of a definite integral with an exact value returns the integral, not its value, while `evaluate()` gives the value. Witness: `simplify(\int_{-\infty}^{\infty}\frac{x^2-1}{(x-1)(x^4+1)}dx) gives ∫_{-∞}^{∞} (x+1)/(x⁴+1) dx evaluate gives π·√2/2`.
