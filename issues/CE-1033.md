A factor `d` written after an integral, `\int_0^1 \frac{x\,dx}{2} + 1 \cdot d`, disappears from the result.

## Witness

Readings of 2026-11-06, at commit `23db78e092dd67fa2ec95c360ee73dbf35e1b1ea`:

```
\int_0^1 \frac{x\,dx}{2} + 1 \cdot d   parses to Add(Integrate(x/2, Limits(x, 0, 1)), 1)
                                       evaluate() gives 5/4; the value is 1/4 + d
```

## Cause and options

The body of the integral stops where `matchDifferentialOperator()` in
`latex-syntax/dictionary/definitions-calculus.ts` matches; it skips `\cdot`
and matches the `d`. `parseIndexes()` then reads the `d` as a differential
operator, finds no variable after it, and returns with the `d` consumed.
Fix: in `parseIndexes()`, when no symbol follows the operator, move the
index back to the position before the operator, so that the `d` is read as
a symbol.
