A chain of variables that each hold the previous one takes a time that grows about 3.5 times with each variable: nine variables do not finish in 60 seconds.

## Witness

At 475f63233d0d627b92d9239b4c70bc4320c59339:

```js
const ce = new ComputeEngine();
ce.assign('A0', ce.parse('\\sin(x)'));
for (let i = 1; i <= n; i++) ce.assign(`A${i}`, ce.symbol(`A${i - 1}`));
ce.expr(['Multiply', 2, `A${n}`]).unknowns;
```

Measured times of the loop of `assign`: 25 ms for `n = 3`, 1100 ms for
`n = 6`, more than 60 s for `n = 9`. The read of `unknowns` of `2·A6` takes
1400 ms more. A chain of sums (`K_i := K_{i-1} + K_{i-2}`, 60 variables)
takes 650 ms, so the cost is particular to a value that is a lone symbol.

## Cause and options

Not found. The cost is in `ce.assign()` of a symbol whose value is a symbol
with a value, and in boxing an expression that reads the last symbol of the
chain; each level multiplies the work, which suggests that the value of each
symbol of the chain is read again once per path. Start with a profile of
the loop for `n = 6`.
