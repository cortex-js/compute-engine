The linear algebra guide shows a scalar inverse example that returns an error.

## Witness

In the `Inverse` section of the linear algebra guide
(`cortexjs.io/docs/compute-engine/17-guide-linear-algebra.md`),
`ce.expr(['Inverse', 4]).evaluate()` is shown as `0.25`. It returns an
`incompatible-type` error because `Inverse` expects a matrix.

## Cause and options

Remove the scalar example or use `ce.expr(['Divide', 1, 4]).N()` to show a
scalar reciprocal.
