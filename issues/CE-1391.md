`isCenteredSquare` tests the wrong formula: it answers False for 13, 25 and 41, which are centered square numbers, and True for 17 and 37, which are not.

## Witness

Epsil CLI, main 1e146ff55: `[n for n in 1..120 if isCenteredSquare(n)]` prints
`[1, 5, 17, 37, 65, 101]`; it must print `[1, 5, 13, 25, 41, 61, 85, 113]`
(OEIS A001844, `2t(t+1) + 1 = t² + (t+1)²`). `isCenteredSquare(25)` prints
False.

## Cause and options

`IsCenteredSquare` in `src/compute-engine/library/number-theory.ts` (around
line 2668) tests `n = 4t² + 1`. Fix: `n` is a centered square number when
`n ≥ 1`, `n ≡ 1 (mod 4)` and `2(n − 1) + 1 = 2n − 1` is a perfect square
(`(2t + 1)² = 4t(t + 1) + 1 = 2n − 1`). Add the first eight members and a few
non-members as tests, and check the compiled form if it has one.
