The list of unknowns treats some bound names as free, so a substitution can replace a name that a quantifier or a set-builder binds.

## Witness

```
Exists(y < x, x)                    ->  x reported free (Exists(y < x, Element(x, S)) binds it)
{x² | x ∈ ℤ}, Set(x², Condition(Element(x, Integers)))  ->  x free; subs({x: 3}) replaces it
raw Sum(j·k, Limits(k, 1, k))       ->  only j free; the upper bound k is free too
If(z > 0, Assign(z, 5), 0).subs({z: 7})  ->  an Error node
```

## Cause and options

The free-variable walk (`collectReferences`, `abstract-boxed-expression.ts`),
which `subs()` follows, misreads these binders. Fixes: in a raw `Sum`, the
index is bound in the body only, not in the bounds; in `Exists`, a bare
symbol as the quantified variable is bound; for a set-builder, use the rule of
the parser (`setBuilder()`, `latex-syntax/dictionary/definitions-sets.ts`).
Open question: does `subs()` keep the target of an `Assign` outside a `Block`
(a write to an outer symbol)?
