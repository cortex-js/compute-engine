The harmonic number of a very small complex number evaluates to the wrong value.

## Witness

With the CE-1559 fix, `ce.function('HarmonicNumber', [1e-30 + 1e-30i]).N()`
has a real part of `−7.8e-16`; the value is about
`1.6449e-30 + 1.6449e-30i`. (The real-n cases, including r ≤ −5, are fixed
with CE-1559.)

## Cause and options

The small-n series and the raised-precision path of CE-1559 are real-only;
for a complex n the ψ/ζ route cancels. Options: the same series in complex
big decimals, or, for an integer r ≤ 0, the polynomial in n (Faulhaber).
