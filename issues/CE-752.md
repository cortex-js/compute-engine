A list returned from a block shows the global value of a name where the block declared a local of that name with no value.

## Witness

```
y := 5;  f := x ↦ NumericApproximation(x)
Block(Declare(y, 'real'), Map(f, [y]))             ->  [5]        expected [y]
Block(Declare(y, 'real'), [y])                     ->  [y]; evaluated again: [5]   expected [y]
Block(Declare(y, 'real'), Map(x ↦ x + 0.5, [y]))   ->  [5.5]      expected [y + 0.5]
```

## Cause and options

The block returns a lazy view, and its elements are read after the scope of
the block is popped. A binding from a popped scope reads its name in the
current scope (the rule in the `bindingInContext` comment,
`boxed-expression/binders.ts`), which is the global `y`.

User decision 2026-11-05, option (a): a binding that a block run removed reads
as its own valueless definition once the scope of the block is no longer live.
This changes the written rule for a popped scope. Rejected: (b) read the
elements before the block ends (`[y]` evaluated again still gives `[5]`); (c)
no change.
