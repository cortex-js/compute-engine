An integral, a limit or a numerical derivative of a lone variable that holds a formula, with no variable written, gives a wrong number or no number.

## Witness

At 3bb1068d3c31e88ef808537917a13f3ceed82034, with `G := sin(x)`:

```
\int_0^1 G             Integrate(G, Limits(Nothing, 0, 1)).N()   0.5      (must be 1 − cos(1) ≈ 0.4597)
\int G                 Integrate(G, Limits(Nothing, …))          G²/2     (must be −cos(x))
Limit(G, 0).N()                                                  NaN      (must be 0)
let G = sin(x); ND(G, 1)                                         ND(G, 1) (must be cos(1) ≈ 0.5403)
let G = sin(x); NIntegrate(G, 0, 1)                              NaN
let G = sin(x); NLimit(G, 0)                                     NaN
```

With the variable written, each one gives the right value
(`\int_0^1 G\,dx`, `\lim_{x\to 0} G`, and, after CE-1434,
`ND(x => G, 1)` and `NIntegrate(x => G, 0, 1)`).

## Cause and options

In the implicit form (`Integrate` with `Limits(Nothing, …)`, `Limit(f, a)`,
`NLimit`, `ND`, `NIntegrate`), a bare symbol operand is not given an implicit
variable from the symbols of its body (`canonicalImplicitLimitFunction`,
`implicitLiteralParameters`, `library/calculus.ts`): it names a function or,
for `Integrate`, it is its own variable (∫ G dG). The value of `G` is not
read, because the variable whose formula it would be is not known.

- (a) Recommended. When the bare symbol holds a formula (a value that is not
  a function literal and not a constant), read the operand as that value at
  evaluation, and choose the implicit variable from the symbols of the value
  with the rule of the implicit form (the first in sorted order): `G` is
  `sin(x)`, the variable is `x`. A symbol that names a function (`Sin`, a
  user function) keeps its reading. Write the rule in
  `docs/SCOPING-MODEL.md`, "The variable of a formula".
- (b) Keep the bare symbol as it is, and document that the variable must be
  written (`\int_0^1 G\,dx`, `ND(x => G, 1)`). The `Integrate` value 0.5
  stays a wrong value for a user who reads `G` as `sin(x)`.
