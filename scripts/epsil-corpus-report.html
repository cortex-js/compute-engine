The interpreted time is the whole run of executeEpsil on a fresh engine. The compiled columns are the compile() call and the run of the generated code; parsing and canonicalization are shared and not counted. Compiled arithmetic is machine arithmetic, so a compiled value is a float where the interpreter gives an exact number, and a program that stays symbolic cannot compile.
