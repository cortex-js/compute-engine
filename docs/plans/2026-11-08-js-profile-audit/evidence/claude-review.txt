2. **Low: `buddhabrot-partition.mts:116–118`. The cursor negative control does not exercise the check that it is meant to support.**
   - Line 118 compares two numbers that the instrument computes: the sum of private cursors and the serial cursor. With two or more partitions, they always differ.
   - No merged array with summed cursors goes through the `deepEqual` at line 117.
   - Line 116 writes `merged[90000]`, so the cursor of the merged result is correct by construction.
   - No line asserts that a partition's own returned cursor (`result[90000]`) equals `startExclusive + count`.
   - The serial cursor against the reference is a real check, and the histogram equality would detect a wrong sample range. The README wording "the deliberately incorrect cursor-summing reducer failed every control" says more than this control shows.
