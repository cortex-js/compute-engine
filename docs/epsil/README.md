# Epsil Internal Documentation

This directory contains maintainer-facing Epsil status and forward-looking
work. It is not the public language reference.

- Public, executable language documentation: `src/epsil/docs/`
- Implemented lowering and runtime invariants: `docs/LANGUAGE-MODEL.md`
- Effects shared with the Compute Engine: `docs/EFFECTS-MODEL.md`
- Open Epsil work: [`ROADMAP.md`](./ROADMAP.md)
- Initiative-level history: `docs/STATUS_REPORT.md` and Git history

The former `roadmap/cortex/` directory recorded the July 2026 language revival
under the language's old name. Its completed phase plans, audits, and progress
logs are historical and are intentionally not mirrored here.
